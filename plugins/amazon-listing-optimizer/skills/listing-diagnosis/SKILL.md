# Amazon Listing Diagnosis

## 目标

诊断 Amazon 商品 Listing 的标题、卖点、描述、关键词、图片、合规风险和转化阻塞点。

## 适用场景

用户提供公开商品链接或合成 Listing 数据，希望获得优化建议和诊断报告。

## 输入

- 商品链接；
- 平台；
- 站点；
- 类目；
- 目标语言；
- 可选的公开 Listing 字段。

## 输出

输出结构应引用 `yijie-contracts/jsonschema/ecommerce/listing.schema.json`，并包含诊断摘要、问题列表、优先级、证据和建议动作。

## 可调用工具

- 公开 Listing 抓取工具；
- 知识库检索工具；
- Citation 构建工具。

## 禁止行为

- 不直接发布或下架商品；
- 不直接修改标题、图片、描述、价格、库存或变体；
- 不调用需要平台 token 的工具，除非用户已授权且审批通过；
- 不使用真实商家数据作为示例。

## 审批要求

诊断和建议不需要审批。任何写入平台的动作都必须通过审批策略。

## 失败处理

数据不足时输出缺失字段清单；平台抓取失败时提示用户提供 Listing 内容；知识库无结果时明确说明证据不足。

## 示例

参见 `examples/input-001.json` 和 `examples/output-001.json`。

## 评测标准

- 诊断问题是否具体；
- 建议是否可执行；
- 合规风险是否有 citation；
- 是否避免未经审批的写操作；
- 是否说明证据不足。
