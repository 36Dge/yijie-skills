# 商品评估、上架与推广链路

版本：0.1.1。对应原 ecommerce-pipeline-advisor、scoring-guide 与 listing-checklist。

## 评估

输入品类、市场、平台、预算、价格币种、供货/物流/平台/广告/退款成本、供应交期与证据时间。按趋势、竞争、利润条件、供应稳定四维列判断及证据，未提供数据标待补；没有统一尺度和输入时不输出伪精确总分。原包 35/25/25/15 权重仅为自定义决策框架，未经经验验证，默认不计算；如用户要评分先约定量纲、权重和未知项处理。

已知售价 P 和供货 C 时，可以算商品价差 P−C 与价差率 (P−C)/P，明确它们未扣其他成本。可写条件公式：单件贡献=P−C−物流−平台/支付−广告−退货等已纳入费用；不把未知费用当零。不套用“毛利低于20%就不做”等固定阈值，阈值由完整成本、测试目标和用户风险偏好决定。

结论采用“当前证据支持什么 → 关键风险 → 需补数据 → 最小验证”。建议投入需对应实际证据，缺数据时只给有条件方案，不造竞品价格、销量和市场热度。

## 上架准备

通用检查：标题核心词、可证实卖点、图片/视频素材、规格和变体、价格币种、库存来源、发货/退货约定、品牌/资质证据。缺品牌资料代表待确认，不等于无品牌。

Shopify 可准备 Title、Description、Vendor、Product type、Tags、Price、SEO 等字段草稿；CSV 的实际列名/导入格式需按用户当前模板核对。TikTok Shop/微信小店可准备类目、目标市场语言、品牌与资质、主图/短视频一致性、履约与售后字段。以上是资料组织参考，具体必填/数量/比例/政策以当前后台或可靠官方资料确认，不编造“已通过平台审核”。

## 推广与执行闭环

按目标和渠道给三至十个关键词方向、文案角度、内容排期和 A/B 假设。预算分为测试/探索/保留项时核对总额及币种，说明分配是建议而非平台保证。表格列动作、负责人（未知写待定）、截止时间、输入、观测指标、停止/继续条件和完成证据。CTR/转化率的分子分母必须明确；没有点击、曝光、访客或订单不能随意套名。用户在平台实际操作，本专家不自动发品、投放、下单或采集。
