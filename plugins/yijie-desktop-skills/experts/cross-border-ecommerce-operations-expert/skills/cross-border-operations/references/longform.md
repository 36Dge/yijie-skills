# 产品营销长文案

版本：0.1.0。对应原 product-marketing-longform 与 marketing-guide。

适用于落地页、广告正文和产品介绍。输入受众、痛点、真实功能、USP、价格/优惠、实际评价或证明材料；评价与数据可缺，不能造用户证言或销量。先确定核心叙事，按引言场景 → 二至三个 USP（每项利益+证据）→ 异议处理 → CTA 展开。

USP 可围绕性能、易用、成本、设计、可靠性，但每项应有事实对应；安全、医疗、认证等高影响主张需要明确证据。缺证据时写事实描述或待补证明，不用模糊小字掩盖夸张承诺。紧迫感仅来自真实活动/库存，不制造稀缺。

交付主标题、正文、二至三个备选标题、CTA 变体和支撑事实表。品牌语气与当地表达自然，专有名词和单位保持一致。若用户只要改一段，保留其他段落；不附带自动发布或站点修改。
