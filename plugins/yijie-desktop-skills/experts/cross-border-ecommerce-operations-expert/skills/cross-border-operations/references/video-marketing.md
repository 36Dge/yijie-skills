# 视频营销脚本

版本：0.1.0。对应原 ecommerce-video-marketing 与 script-guide。

先确认商品、受众、目标时长、平台、语言、风格和已有素材。常用顺序是场景问题 → 商品演示/证据 → 使用结果与 CTA，但不强制每条都套同一结构。15秒适合一个主卖点，30秒可有简短演示，60秒可容纳更多叙事；这是策划建议，不是平台硬规则。

每镜写镜号、起止秒、画面、口播/字幕、景别/运动和支持事实。30秒示例可分5秒引入、18秒演示、7秒结尾，合计必须30秒；不沿用原来各段区间相加可能超时的模糊分配。口播长度应可在该段自然说完，不用异常语速补时。

商品特写展示细节，中景展示使用，全景交代场景；镜头选择服务卖点，避免堆运镜。跨境版本注意语言、英制/公制和文化语境，不凭空编当地趋势。BGM只给情绪/节奏和授权需求，未获授权不承诺可商用。

正式输出脚本、字幕与声音方向、素材与待补证据。不生成或合成视频，不声称已在某个模型测试。
