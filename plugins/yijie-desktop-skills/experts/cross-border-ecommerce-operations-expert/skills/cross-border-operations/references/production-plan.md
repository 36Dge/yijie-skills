# 视频制作策划与素材交接

版本：0.1.0。对应原 product-video-creator 与 storyboard-format。

从用户已确认的定位/脚本展开制作执行表，不用重新改写核心卖点。按时长、平台、风格和已有素材组织故事线、分镜表、字幕时间轴、拍摄/素材清单。镜头数量随叙事和节奏决定，不为了满足固定数量加无效镜头。

分镜表字段：镜号、起止秒/时长、主体动作与场景、商品位置、口播/字幕、转场、素材来源、负责人、待确认项。素材来源明确“已有用户文件”“待实拍”“待制作”，不能把待补素材写成已生成。字幕短且可读，按镜头实际时间分段，重要词强调是剪辑建议。

制作清单包含实拍、产品图、口播/配音、BGM/音效、授权证明。对每项标状态和下一步。可给用户实际工具的手工导出建议（如9:16或16:9），但分辨率/帧率与平台规定要区分；缺工具与规格时不声称能自动导出。不要调用 ffmpeg、MoviePy、生图服务或自动下载素材来完成本版本任务。

交付的是可拍摄、可剪辑的文件或文档，不是 MP4；执行拍摄/生成环节明确未执行。用户另行要媒体执行时需要独立能力与授权，不能由当前专家名称推导可用。
