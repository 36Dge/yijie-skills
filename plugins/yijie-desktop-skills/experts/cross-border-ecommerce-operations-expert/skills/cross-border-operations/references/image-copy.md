# 主图与详情短文案

版本：0.1.0。对应原 ecommerce-image-copywriter 与 copywriting-guide。

输入产品名、品类、可证实卖点、受众、价格带、目标平台/语言和已有图。每条短文案连接场景问题、产品事实与用户收益；收益不能超过功能事实支持。区分图片上可贴的短标题、短卖点条和详情模块说明，不用长段广告覆盖主图。

先从事实提取二至三个主卖点，再给主图标题、短卖点条和模块文案。例如已知“可折叠”可写收纳便利，不能推导材料强度、防水或承重。emoji 依据平台和品牌语气，不套用固定占比。避免空泛“顶级”、无证据“第一”和医疗功效。

输出表：模块/图片 → 文案 → 支持事实 → 素材要求 → 待确认项。跨境版本使用目标市场表达和准确单位；用户没有价格/促销事实时 CTA 不写折扣或限量。图片规划不等于图片已经生成。
