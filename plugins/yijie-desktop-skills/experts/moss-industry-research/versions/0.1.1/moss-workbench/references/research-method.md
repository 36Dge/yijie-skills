# 研究与计算方法
先收束决策、行业纳入/排除、地域、执行日、统计年度、币种/单位和约束。战略视角关注进入条件/客户/竞争/渠道/能力；数字化关注流程问题/预算证据/部署约束/量化收益；投资研究关注行业结构/现金流来源/风险/反证，不替代证券建议；营销关注细分需求/触点/定位证据/验证。无资料模块写缺口，不凑全景。

来源保留发布/取得日期、定位、全文摘录、事实quote。quote在content出现仅是机械一致，不证明数字解释和来源真实。声明synthetic的资料始终是样例；未知状态只能null。概念、事实、机构观点、推断、假设、建议分开。政策/最新统计没有当前可靠原始资料时明确未核验。冲突的年份、样本、边界、币种不强合并。

本版本自有四类计算，所有输入通过fact_id关联：
1. market-size：customers × annual_spend得年度TAM；乘serviceable_share得SAM；再乘capture_share得SOM。比例是0–1小数；不默认额外能力系数为1。仅明确的自下而上年度情景，人口不是已付费客户。每个派生量单独传播缺值；如capture缺失，TAM/SAM仍可算，SOM为N/A。
2. growth：同地域/边界/单位，正整年间隔；(end/base)^(1/years)-1。base为0/缺失时N/A，end=0且base>0时-1。输出小数，0.1代表10%；历史区间不外推最新年度。
3. concentration：0–1份额不重新归一化；full要求总和1，partial要求≤1。CRn取已观测最大n项和，HHI=平方和×10000。partial只给观测下界，不把其余份额当单一公司、不把样本集中度当全市场值。
4. weighted-score：权重明确合计1，量表min/max和benefit/cost方向确定。归一化×权重×100；任一缺值则该对象不排序，不重分配缺失权重；并列共享名次。情景来自用户假设，不能称客观评级。

敏感性用多条命名market-size计算引用明确的低/中/高比例事实；不擅自生成范围。报告引用实际结果模板，解释需原文支持。未实现任意预测/行业因果识别/通用统计模型/上游所有经营计算类型，不允许换名冒称完成。
