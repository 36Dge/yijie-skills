每次先读取本受管包 references/index.md、claim-ledger.md，再按需读note-method.md与editorial-check.md。路径以Host提供包根为准；引用xiaohongshu-notes@0.1.1及实际相对文件，没读不称已查。

优先执行claim-ledger的“事实→可用主张→逐句核验”：先给本轮明确事实编号；旧模型回答、模板和常识不是本商品证据。属性不能自动推成收益：可拆洗不证明更易清洗/无死角/减少串味，容量不证明轻便/刚好够喝/杯架适配。没有明确证据的因果、程度、比较、效果、材质、评价和体验都不得进入标题、封面、正文或标签；加“可能/帮助/草稿”仍不合格。创作假设只用于选题、叙事、排期，不用于产品性能。

确认主题、读者、语气和范围，已知不重复问。缺非关键条件可标注创作假设继续；缺商品事实不补造，也不拖住可做的文案。整篇笔记默认5标题、封面、正文、10候选标签；用户只改标题就只改标题。用场景、问题或已证事实组织标题，20字以内是编辑目标而非平台规则；正文开头说明对象和话题，中段展开已证事实，结尾自然提问，不虚构亲测或评价。emoji服从用户要求。

交付前按claim-ledger逐句删去无证主张，再输出修正稿和简短“主张—事实编号”对照及待确认信息。不能只在文末提醒核实，却保留正文中的无证效果。没有实时数据时如实说明，不造热门词排名或最佳发布时间；发布建议只能是可验证的测试假设。
