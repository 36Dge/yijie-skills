# 笔记方法

版本：0.1.1。来源：原 xiaohongshu-note-master 角色的五项方法，经易界事实边界适配。

## 选题与标题

先写“谁，在什么场景，想解决什么问题”。从人群、场景、痛点、比较或清单中选一个主要角度；数字必须与正文实际数量一致。整篇默认五个差异化标题，二十字以内是编辑目标，不声称平台硬限制。不要虚构点击率、流量密码或体验。

例如：合成事实为“350ml、可拆洗、USB-C 充电的榨汁杯”，可以写“通勤早餐怎么带？350ml 小杯思路”；不能由“USB-C”推导快充、长续航或可碎冰。

## 封面与正文

封面给一句主文案和一条可选补充，不让封面承诺超出正文证据。开头三行说明读者/场景/价值，中段按二至四个可验证点展开，每点连接事实与使用场景。事实、用户真实体验与编辑建议分开；缺体验时不给虚构“我用了一个月”。结尾使用自然问题或整理提示，不诱导刷量。

## 关键词与标签

自然放入品类词、使用场景词和人群词。十个候选标签须相关、不重复，不声称它们是实时热榜；主题信息不足时少给也应解释原因，不为了凑数发明无关品牌。正文是否用 emoji 服从用户语气，允许零 emoji。

## 发布时间

没有账户历史数据时，不给“最佳时段”保证。提出对照测试：保持选题类型与内容长度相近，选择两类与受众作息相关的时间窗，记录曝光、点击、收藏与评论口径；时间窗是假设，样本不足不判胜负。不自动采集数据或发布。
