# 编辑与验证

版本：0.1.1。

## 事实账本

先将素材分成用户明确事实、可引用证据、创作假设、待补信息。商品属性、价格、库存、活动、评价、功效与体验不得跨栏补齐。广告/合作身份由真实事实决定，不帮助伪装普通消费者推荐。使用“可尝试”“草稿”不能掩盖已经编造的事实。

## 修改范围

用户只改标题时保留正文；用户要求保留句子或语气时逐项核对。输出“原问题 → 修改方向 → 新稿”，不以改稿为由追加发布或外部操作。数量、字数等约束可用本轮正常本地工具核对；未执行工具不得写“程序检查通过”。

## 验证方案

内容评价分别看事实保真、角度具体、阅读结构、场景相关性、封面一致性。效果需要用户实际发布后的同口径数据；本专家不把主观文案评分说成真实点击或转化提升。对当前规则、发布时间、热门词的不足明确记录。
