# 流程
先确认美国站目标、规格、采购数量和可外传范围。Keepa商品查询获取产品事实，productSeries单独获取价格采样。SIF关键词/汇总可用于竞品线索；需要备用来源时说明原因与费用，再取得当前工具的单次审批，不自动调用SellerSprite。Amazon搜索返回候选，不自动将第一条替换为目标；新增目标须独立请求与来源绑定。

货源主路径为已授权公开PNG/JPEG图片的alibaba1688/imageSearch，另可用明确中文品类词的dld/productSearch。Google检索只提供研究线索，不把stdout链接或建议当真实供应商报价。每次查询使用显式页码；不循环翻页、自动扩量或自动上传。方法schema/资料与当前服务不符时记录unsupported，不尝试不同参数收费探测。

observe不选offer_id时输出candidates_only；比对规格后明确选择offer_id再核对该原回执，不需要重做网络检索。细分市场同样必须选nicheId，不根据相似标题/第一条自动匹配；市场ACoS、退货率仅为参考，不自动用作商品参数。

形成单SKU报价确认：每采购单位的CNY价、采购单位与Amazon销售单位比例、起订数量、预计采购数量、价格阶梯和确认时间。原最低价不能代表指定SKU价格。原始回执与差异表一起交付；真实询价/资质和合规审查未做时必须明示。

完整成本输入后本地计算，缺项仍生成有用报告。税费、包装、固定费用分摊在other_usd说明覆盖/不覆盖；费用由用户适用资料或明确情景给出。汇率无默认，US售价用USD。报告路径是本地生成结果，不暗示真实账号或供应商已经验收。
