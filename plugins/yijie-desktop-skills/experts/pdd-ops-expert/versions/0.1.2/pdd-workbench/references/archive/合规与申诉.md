# 合规与申诉　规则红线、处罚判罚与申诉举证实操

**本模块导语**：合规不是成本，是店铺的护城河。一次严重违规可能带走你的保证金、货款、流量和整店链接，而且大部分是不可逆的。本模块把拼多多的违规分级、售假判定、知产侵权、虚假交易、极限词、价格欺诈、阴阳SKU、站外导流、售后与客服违规、无照经营与税务、申诉SOP、证据准备、申诉话术、恢复节奏、自查清单全部拆成可照着做的动作，看完就能对自己的店铺做一次完整体检。

## 01 违规分几档、罚到什么程度：先分清轻重再谈应对

典型状态：后台突然弹出一条违规通知，你不知道这条是“改一下就行”还是“这条链接要没了”。有的商家看到扣分不当回事，结果下一档处罚直接扣保证金。

> **问**：拼多多的处罚一共分几档

平台的实际处罚是从轻到重逐级加码的，一共六档：

1．警告：站内通知加限期整改，不扣钱不扣分，给你一次机会。

2．扣分：按违规类型扣店铺分，分数累积后触发搜索降权、活动驳回。

3．降权：商品或店铺搜索权重下调，表现为自然流量明显下滑、关键词排名下移。

4．限制功能：分级禁用发品、推广、提现、活动报名等能力，其中限制提现对现金流打击最直接。

5．扣保证金与扣款：直接从保证金或货款中扣划，罚款金额可能远超这一单利润。

6．清退：关店、商品全部下架、保证金和未结货款处理，属于不可逆处罚。

> **问**：哪些违规只是扣分，哪些会直接走到清退

**三档分类记住就行：**

| 档位 | 典型违规 | 主要处罚 |
| --- | --- | --- |
| 一般违规 | 极限词、类目错放、重复铺货、延迟发货、描述不符 | 警告、扣分、商品下架、限制推广 |
| 严重违规 | 虚假发货、虚假宣传、知识产权侵权、低价引流、导流 | 扣分、降权、限制提现、扣保证金 |
| 极严重违规 | 售假、虚假交易、泄露买家信息 | 清退、扣保证金、资金冻结、法律责任 |

**分步实操**

1．打开商家后台，进入“违规记录”，按时间倒序逐条查看，只看两列：违规类型、处理状态。

2．把“待处理”的条目单独抄到一张表里，记下违规编号、商品ID、通知时间。

3．对每条判断属于哪一档：一般违规当天整改，严重违规24小时内提申诉，极严重违规当天停下所有推广。

4．计算累积扣分，看是否已经贴近下一档处罚的阈值，贴近就优先保店铺主体而不是清单条链接。

5．导出近90天的违规记录，检查有没有“严重违规”字样，这个结果直接决定你能不能报大促。

6．把每条违规的处理截止日写进表格，设置提前1天的提醒。

**正确做法**

- 把违规当预警看，不当“运气问题”。平台给你通知的时候，惩罚还没走完，这时候动作最有效。

- 分角色判断后果。搜索和活动权限受影响，是运营岗的痛；限制提现和扣保证金，是老板的痛；客服侧的骚扰辱骂，是客服岗的痛。同一张违规单，不同岗位感受到的压力完全不同。

- 违规记录里的每一条都要走完两种动作之一：整改或申诉。挂着“待处理”的条目迟早会升级。

- 严重违规优先处理，不要因为金额小就先放着。

**常见错误**

错误示范：看到违规通知先关掉，想着“反正只是扣分”。

错在哪：扣分是累加制，同一类型反复触发会逐档升级，最终走到扣保证金和限制提现。你以为的“小事”是升级路径上的前两级。

错误示范：把违规记录里带“待处理”字样的条目留着，等客服那边闲了再一起改。

错在哪：整改有截止时间，超时未处理直接升级处罚。而且待处理条目在后台是打折店铺权重的依据之一。

> **【规则提示·2026规则修正】** 拼多多的处罚以“扣款加限制提现加流量降权加下架清退”为主，对现金流的打击往往超过流量损失。合规的前提是保护资金通道，不是保链接。

**实操检查清单**

- [ ] 在“违规记录”里把待处理条目全部导出成表

- [ ] 给每条违规标注档位、整改截止日、申诉截止日

- [ ] 检查近90天是否有严重违规

- [ ] 给严重违规设提前1天提醒

- [ ] 把违规台账共享给运营、客服、财务三个岗位

- [ ] 每周固定时间复查一次待处理条目

## 02 哪些行为会直接清退或冻结资金：红线一张表贴墙

典型状态：你心里知道刷单、导流、卖假货有风险，但不确定“一旦被查到究竟会怎样”。多数人被罚之后才发现，代价不是扣分，是钱和店铺一起去掉。

> **问**：拼多多最不能碰的红线有哪几条

一共八条：售假、虚假交易、导流到站外、知识产权侵权、极限词与虚假宣传、低价引流、资质缺失、虚假发货。这八条一旦被认定，处罚都会走到扣分以上的档位。

> **问**：每条红线对应的处罚是什么

| 红线 | 典型行为 | 处罚 |
| --- | --- | --- |
| 售假 | 卖仿牌、假冒品牌 | 假一赔十、劣一赔三，按历史销售总额10倍罚，清退 |
| 虚假交易 | 刷单、代写评价、拍大单 | 清销量、删评价、扣分、限流、清退 |
| 导流 | 聊天或包裹卡引导站外交易 | 保证金直接加收10万元，再犯没收 |
| 知识产权 | 盗图盗视频、未授权用品牌名 | 下架、扣分、赔偿、多次侵权清退 |
| 极限词虚假宣传 | 最、第一、100%有效、包治 | 下架、扣分、罚没、职业打假人索赔 |
| 低价引流 | SKU塞0.01元诱饵价 | 商品下架、扣分、限权 |
| 资质缺失 | 无证卖食品、化妆品、医疗器械 | 下架、处罚、清退 |
| 虚假发货 | 无真实揽收、空包、虚拟单号 | 扣款、降权、扣分、清退 |

> **问**：私下交易的处罚有多重

这是单条最重的经济处罚。聊天里发支付宝、微信或其他平台链接引导站外交易，店铺保证金直接加收10万元。半年内不再犯可以退，再犯直接没收并再交10万元。不交则强制关店，且货款无法提现。

**分步实操**

1．把上面这张红线表打印出来，贴在打包区、客服工位、运营工位各一张。

2．打开后台“违规记录”，按红线表逐条对照，看近90天有没有命中。

3．做一次全店扫描：商品标题、主图、详情、SKU名、客服快捷语、包裹卡文案、直播脚本，六个位置全部扫一遍。

4．把命中的问题分成两类：能当天改的当天改（文案、图片、SKU），需要资质或授权才能改的立刻下架商品。

5．建立一个“红线检查”记录表，每次上新前由运营签字确认六项都没问题。

6．把导流、售假、虚假交易三条单独列成“零容忍”清单，写进员工手册。

**正确做法**

- 把红线理解成“资格线”而不是“风险线”。碰了红线是丢资格，不是多交学费。

- 处罚会叠加。虚假交易往往同时带来清销量、删评价、降权、扣分四个后果，不是只吃一个。

- 涉及资质的产品，先办齐再上架，不要边卖边补。缺证下架发生在你已经在备货的时候，损失最大。

- 保证金加收和货款冻结会直接打断你的现金流，判断一件事能不能做，先看它会不会动到资金通道。

**常见错误**

错误示范：觉得“我这个类目小，平台查不到”。

错在哪：稽查是系统自动跑的，不看类目大小，看的是行为特征。类目越小，同类商家越少，异常反而更容易被识别。

错误示范：把红线表当资料收起来，不贴到工位。

错在哪：客服口头说一句“加微信便宜”只需要一秒，但赔付按10万元算。红线必须在被触发之前就拦住，事后解释没有意义。

> **【规则提示·2026规则修正】** 2025到2026年，虚假交易和售假的处罚明显加重，导流和极限词的查验明显更严，活动作弊零容忍。旧认知里“罚一点就算了”的判断已经不成立，涉及行为轨迹的违规一律按最重档处理。具体门槛与罚则以商家后台实时提示为准。

**实操检查清单**

- [ ] 把八条红线表打印并贴到打包区、客服工位、运营工位

- [ ] 对商品标题、主图、详情、SKU名做一次全量红线扫描

- [ ] 检查客服快捷语与自动回复里有没有站外联系方式

- [ ] 检查包裹卡文案是否含导流内容

- [ ] 把导流、售假、虚假交易三条写进员工手册并让全员签字

- [ ] 检查所有在售商品的类目资质是否齐全且在有效期内

- [ ] 建立上新前红线确认签字流程

## 03 售假判定与三振出局：处罚最重的一条

典型状态：你从供货商那里拿货，对方口头说是正品，你没要授权书也没要发票。链接卖起来之后，一条售假通知把整店都悬在半空。

> **问**：平台靠什么判定售假

主要看四类证据：买家鉴定或品牌方出具的鉴定报告、商品与正品的实物比对、你提交的授权与进货凭证链是否完整、以及历史销售数据与进货数据的匹配度。任何一类成立，都足以支撑判定。

> **问**：三振出局是什么意思

平台按被认定售假的次数累计计算。

1．第一次：下架商品，要求你提交资质证明与进货凭证，扣分。

2．第二次：加重处罚，罚款加扣分，限制提现与推广。

3．第三次：直接清退，保证金处理，货款冻结。

三振看的是“次数”，不是“同一条链接”。换链接、换商品只要主体关联，都算在同一次数累计里。

> **问**：售假要罚多少钱

假一赔十、劣一赔三，并且会按历史销售总额的10倍处罚。举例：一件衣服成本20元，已经卖出2000件，销售额20×2000＝40000元，按10倍计算，判罚可达400000元。这还没有算每个买家那一份假一赔十。

**分步实操**

1．先核对你的货源授权链：品牌方到一级授权到二级授权再到你的公司，每一层都要有盖章文件，缺一层就是断链。

2．检查授权书内容：必须写清品牌名、授权商品、授权渠道（必须含线上及本平台）、授权有效期。

3．检查进货凭证：优先用增值税发票，发票上要有商品名称、规格、数量、单价、金额、开票方全称与纳税人识别号。

4．没有发票的，用“进货单加盖供货方公章加付款流水加供货方营业执照复印件”三件套替代，付款流水要能看到收款方名称。

5．核对三处一致性：凭证上的商品名称型号规格，与你后台在售商品一致；进货数量与销售数量匹配；进货日期早于销售日期。

6．把上述材料按品牌归档成一个文件夹，纸质件全部扫描成电子件，文件名写清品牌加日期加供货商。

7．收到售假通知后24小时内提交申诉，同时把该商品下架，避免继续产生新的销售记录。

**正确做法**

- 授权链要连续完整。断链等于售假风险，不管你自己知不知道货是真的。

- 授权书到期前提前续，不要等到期之后才联系品牌方。到期当天的授权就是断链。

- 进货凭证优先发票，其次进货单加付款流水，最次是手写收据。手写收据在申诉里基本不被采信。

- 未授权品牌货不要上架，也不要在标题里写品牌词。品牌词只写你自己被授权的品牌。

- 同一批货如果来自多个供货商，每个供货商都要有独立凭证。只备一家，另一家就是缺口。

**常见错误**

错误示范：觉得“改个水印、换个背景就不是仿牌了”。

错在哪：判定看的是商品本体与权属，不看图片怎么处理。改图只会让你在“售假”之外再多一条“规避审查”。

错误示范：申诉时只提交一张手写收据，上面写着“某某品牌服装若干”。

错在哪：凭证要能证明“这一批货就是这个商品”。品名、规格、型号、数量、日期缺一项，这条凭证就废了。

错误示范：以为对方是“原单”或“代工厂流出”就没问题。

错在哪：没有品牌方授权的代工厂流出货，同样按售假处理。“原单”“尾单”“厂货”这些说法在平台判定里不构成合法来源。

> **【规则提示·2026规则修正】** 售假是拼多多处罚最重的一条，直接清退加法律责任，没有一次警告的缓冲。合规替代只有一个：完整授权链加真实进货凭证，货源拿不出凭证就不上架。

**实操检查清单**

- [ ] 建立进货凭证编号台账，记录供货商、批次、日期、品牌授权有效期

- [ ] 每批次进货凭证扫描归档，末页加盖公章

- [ ] 授权书到期前60天、30天、7天各做一次提醒

- [ ] 每月核对一次销售额与进货量的匹配度

- [ ] 核对在售商品的进货单价是否明显低于市场价（明显异常就是风险信号）

- [ ] 收到品牌方或买家质疑时，24小时内调齐凭证

- [ ] 把无凭证的货源从在售清单中全部清出

## 04 知识产权侵权：商标、专利、著作权、盗图分别怎么罚

典型状态：你的主图是“参考”同行做出来的，详情里的图片是网上下载的，标题里带了一个你觉得“通用”的品牌词。三个月后四条知产投诉一起打过来。

> **问**：四类知产侵权分别是什么

1．商标侵权：用了别人的注册商标、品牌名、LOGO，或者卖假冒品牌商品。

2．专利侵权：外观设计专利、实用新型专利、发明专利被他人在本平台主张权利。

3．著作权侵权：盗用他人图片、视频、文案、包装设计、字体。

4．盗图投诉：属于著作权里最高发的一类，因为图片最容易比对，也最容易判定。

> **问**：分别怎么罚

- 商标：商品下架删除，扣分，搜索降权；假冒的按售假处理，走到清退。

- 专利：商品下架删除，扣分，赔偿投诉方损失。

- 著作权与盗图：商品下架、扣分、赔偿；多次侵权累计后清退。

- 通用后果：被投诉记录本身会影响活动报名，大促要求近期无严重违规。

> **问**：被投诉了怎么申诉

**按侵权类型准备对应的权属反证：**

1．商标：提交商标注册证或合法授权链，证明你有权使用。

2．专利：提交专利证书、专利权评价报告，或者不侵权技术比对说明。

3．著作权：提交原始素材与创作时间戳，比如拍摄原片、PSD源文件、创作时间记录。

4．素材来源合法的，提交购买记录、授权协议、素材网站的授权凭证。

**分步实操**

1．收到投诉后先确认投诉对象：是商品链接、主图、详情图，还是视频。

2．把被投诉的素材和你的原始文件放在一起比对，确认到底是不是你的原创。

3．是原创的，整理原始文件加时间戳，走申诉通道提交。

4．不是原创的，立刻删除或替换素材，同时下架商品，避免投诉升级为多次侵权。

5．能联系上投诉方的，争取一份授权或撤诉说明，这份说明对后续处罚判定很有用。

6．处理完之后复盘素材来源，把全店素材按“原创”“已授权”“待替换”三类重新标注。

**正确做法**

- 原创加授权是唯一底线。没有第二条路。

- 品牌词只写自己取得授权的品牌。别人的品牌名、别家的系列名，都不要出现在标题和属性里。

- 每张主图、详情图、视频都要留下可追溯的创作时间证据，最省事的做法是保留拍摄原片和项目源文件，并且不覆盖修改。

- 收到投诉立即下架，别拖。拖一天就多一天新的销售记录，赔偿金额按销售记录算。

- 把素材库管理制度化：谁用的、从哪来、有没有授权，一张表说完。

**常见错误**

错误示范：认为“我改了水印，或者重新裁剪拼接一下就没事了”。

错在哪：判定比对的是图像内容本身，不是水印。裁切、加滤镜、换背景都不改变内容同一性，照判侵权。

错误示范：把知产投诉当“随手举报”来用，看谁不顺眼就投诉一次。

错在哪：恶意投诉要承担法律责任，明知对方有授权还反复投诉可能被认定不正当竞争，投诉账号的权重也会下降。

错误示范：被投诉后先下架商品，但详情里其他有问题的图片留着不动。

错在哪：投诉方通常会一次性扫全店素材，留下没换的素材就是下一次投诉的入口，第二次就是“重复侵权”。

> **【规则提示·2026规则修正】** 平台对原创素材的保护更强，同时对恶意投诉的处罚也在加重。把主图、详情图的源文件与拍摄原片保存三年以上，是申诉和维权两件事的共同基础。

**实操检查清单**

- [ ] 全店图片视频过一遍，标注原创、已授权、待替换

- [ ] 每个素材保存可追溯的发布时间证据

- [ ] 品牌词只保留有授权文件的品牌

- [ ] 建立素材库授权登记表并指定维护人

- [ ] 每周看一次知产投诉与站内信，做到当天响应

- [ ] 遇到投诉24小时内完成下架或替换

- [ ] 每季度做一次全店素材抽查

## 05 盗图被投诉了怎么申诉，自己作为权利人怎么投诉别人

典型状态：两种情况常常同时发生在同一个商家身上。你收到别人的盗图投诉，同时你也发现自己的原创主图被好几家同行搬走了。

> **问**：被投诉盗图，申诉要提交什么

核心是证明“这张图是我做的”。按证据强度从高到低排序：

1．拍摄原片：相机或手机里的原始文件，保留EXIF信息，未经过任何导出压缩。

2．设计源文件：PSD、AI、CDR等分层文件，图层结构要能看出创作过程。

3．创作过程记录：拍摄花絮、灯光布置照片、拍摄时间与地点信息。

4．时间证据：作品登记证书、云端上传时间记录、首次发布的后台时间。

5．授权证据：如果图是买的，提交素材网站的购买记录与授权协议。

> **问**：自己作为权利人，怎么投诉别人盗图

先在平台的知产保护入口完成权利人备案。

1．备案材料：商标注册证、专利证书或著作权登记证书，加营业执照。

2．备案通过后，才能以权利人身份发起投诉。

3．找到侵权链接，复制商品ID，进入知产投诉页面。

4．上传权属证明加侵权比对说明，比对说明要指出具体相似点，比如构图、背景、道具、光线角度。

5．提交后平台审核，审核通过会对侵权商品做下架处理。

**分步实操**

1．先固定证据。用截图工具连续操作保留侵权页面，要能看清店铺名、商品ID和当前时间，最好再录一段屏。

2．核对你的权属证书与授权范围，确认维权有依据。没有登记的作品，用原片加创作记录替代。

3．进入知产保护入口提交投诉，一次只投诉一条链接，理由写具体，不要笼统写“盗图”。

4．记录每条投诉的编号与结果，通过的归档，被驳回的看驳回原因再决定是否补充材料。

5．把维权成本算进运营预算。批量监测加逐条投诉是一份持续工作，不是一次动作。

6．每季度做一次主动监测：在自己的品牌关键词下按图片搜索，看有没有新的盗用。

**正确做法**

- 维权要持续做，不是出了大事才做。盗图一旦形成规模，你的主图点击率优势就被别人分走了。

- 投诉理由要具体。“同样是白底加一支口红”不构成投诉理由，“构图、道具、光影角度完全一致”才是。

- 备案是前提。没有完成备案，你能走的只有普通举报通道，效率低很多。

- 被投诉和投诉别人的材料都按同一套标准归档：权属加来源加时间。这一套档案两头都能用。

**常见错误**

错误示范：申诉时写一篇长文解释“我这张图是自己拍的”，但一张原始文件都拿不出来。

错在哪：申诉是靠证据，不是靠说明。没有原始文件，说再多也是无效申诉。

错误示范：被投诉后只盯着“这条链接能不能救回来”，不处理素材来源。

错在哪：素材来源不改，第二个投诉迟早来。第二次投诉的处罚档位比第一次高。

错误示范：一次提交几十条投诉，里面还夹着错误投诉。

错在哪：投诉错误率过高会降低你账号的投诉权重，后续真实侵权反而投诉不动。

> **【规则提示·2026规则修正】** 以原创或已获授权素材为底线。搬运、二改、去水印这三类做法都在治理范围内，不要再用“改一改就看不出”这个思路做素材。

**实操检查清单**

- [ ] 全店图片视频的来源逐条登记

- [ ] 每张原创图保留原片或源文件并注明拍摄日期

- [ ] 完成权利人备案，取得投诉资格

- [ ] 每月做一次品牌词加图片的盗用监测

- [ ] 投诉提交前做一次权属与授权范围核对

- [ ] 侵权证据截图与录屏按日期归档

- [ ] 每季度复盘一次维权投入与效果

## 06 虚假交易（刷单）的判定与处罚

典型状态：新链接一点流量都没有，你想找熟人下几单快速破零。三天后销量显示上去了，第五天链接开始掉流量，第七天违规通知来了。

> **问**：平台靠什么判定刷单

系统同时看多个维度，命中两个以上就会被标记：

1．同一个收货地址或同一地址段出现多笔订单。

2．多笔订单来自同一设备、同一IP段或同一支付账号。

3．下单时间过于集中，比如几笔订单间隔几分钟。

4．物流轨迹异常：空包、虚拟单号、无中转记录、签收地与收货地址不一致。

5．评价内容高度相似，或评价时间过度集中。

6．账号只在你店铺下单，且没有正常的浏览加购行为。

> **问**：处罚是什么

按次数升级：首次清销量、删评价并警告；第二次清销量加扣分加限制功能；三次及以上扣保证金并可能清退。虚假评价还可能导致店铺评分与体验分重新计算，推广消耗也不会退还。

> **问**：申诉能成吗

虚假交易的判定依据是行为轨迹，不是单条证据，所以申诉成功率偏低。能申诉成功的通常是这几种情况：同一地址是真实的公司批量采购、老客集中团购有真实聊天记录、真实亲友复购且有完整物流与聊天佐证。没有这类证据，硬申诉没有意义。

**分步实操**

1．停掉所有补单动作，包括找亲友、找第三方、找所谓“资源”。

2．用真实路径破零：开通多多进宝设佣金10%到20%，目标是3天内出10到20单真实订单。

3．同时报官方活动拿活动位流量，哪怕利润很薄，也要让系统看到真实成交曲线。

4．有老客资源的，用站内消息或合规短信通知复购。注意不能出现引导好评的表述。

5．对确实存在的真实团购订单，整理买家真实聊天记录、公司采购证明、物流签收记录，再考虑申诉。

6．检查全店是否还有“代写评价”“补单”“资源”这类词出现在客服话术或员工沟通里，全部清理。

**正确做法**

- 把破零理解成“验证产品”,不是“制造数据”。前20单宁愿微亏甚至零利润，也要真实成交。

- 用多多进宝走真实CPS出单，配合包裹卡引导真实评价。包裹卡文案写“晒图有礼”,不写“返现换好评”。

- 老客复购走站内工具。站内消息、店铺关注、会员、优惠券都是合规路径。

- 新店前30天列一张禁忌清单贴在工作区，每天对照。

- 记录每一天的真实成交曲线。真实的曲线有波动、有高峰低谷；刷单的曲线是几根突兀的柱子，一眼就能看出。

**常见错误**

错误示范：觉得“多换几台手机、多用几个地址就查不到”。

错在哪：系统关联的维度包括支付账号、设备指纹、收货人习惯、下单间隔。换设备不换资金流，照样命中。

错误示范：第一次被警告后，再刷一批新单把数据“冲一冲”。

错在哪：处罚按次数升级，第二次的档位比第一次重得多。补单等于主动跳级。

错误示范：用低价空包单号充物流信息。

错在哪：空包在物流系统里没有真实的中转和派送轨迹，一查就露。这条同时会触发虚假发货，处罚叠加。

> **【规则提示·2026规则修正】** 靠“同步竞品销量和评价”让新品秒变老链接的做法，全部属于虚假交易与虚假评价治理范围，后果是清销量、删评价、扣分、限流直到清退。合规替代：多多进宝真实CPS破零加包裹卡引导真实评价。新店前30天不得触碰虚假交易、代写评价、批量拍大单三项。

**实操检查清单**

- [ ] 开通多多进宝，设佣金10%到20%

- [ ] 3天内完成首批10到20单真实订单

- [ ] 全店禁止出现代拍、代写评价、补单相关表述

- [ ] 每周导出订单明细，检查有无异常地址聚集

- [ ] 包裹卡文案检查，只写晒图有礼，不写返现换好评

- [ ] 客服与运营全员明确：任何形式的代拍与补单都不得接

- [ ] 每月看一次近30天成交趋势是否平滑无异常脉冲

## 07 虚假宣传与极限词：违禁词清单与合规替代表述

典型状态：你的标题里写着“全网最低价、销量第一”，详情里写着“三天见效”。这不是夸张手法的问题，这是两条独立违规。

> **问**：违禁词分哪几类

1．极限词：最、第一、唯一、顶级、国家级、全网最低、史上最。

2．绝对化承诺：100%有效、零风险、永不、绝对、彻底解决。

3．功效夸大：普通商品不得出现医疗、减肥、美白、治病类承诺；化妆品只能写备案过的功效。

4．虚假背书：虚构国家认证、权威检测、销量第一、获奖。

5．谐音变体：把“最”写成“醉”，把“第一”写成“第①”，这类变体已经被纳入识别范围。

> **问**：哪些位置要排查

一共七个位置：商品标题、主图文字、详情页、SKU名称、属性填写、客服快捷语与自动回复、包裹卡与直播话术。只查标题是漏检率最高的做法。

**分步实操**

1．打开商家后台“商品管理”，用商品预审工具对标题和详情跑一次违规词排查。

2．对全店在售商品做一次批量排查，把命中结果导出成表。

3．用第三方图文检测工具做二次校验，重点查图片上的文字。

4．自建词库，把命中的词和相邻的近义词一起收进去，形成替换对照表。

5．把替换对照表发给美工和文案，作为固定模板使用。

6．每周对新上架商品跑一次预审，结果为零违规才允许上架。

**合规替代对照**

| 违规表述 | 合规替代 |
| --- | --- |
| 全网最低价、史上最低 | 本期特惠（配合真实券后价展示） |
| 销量第一、销量冠军 | 月销过万件（需与实际数据一致） |
| 100%有效、三天见效 | 用后肤感清爽、穿着舒适 |
| 国家级认证、权威推荐 | 如实写检测报告编号与检测机构名称 |
| 顶级面料、顶级工艺 | 面料成分与克重写具体数值 |
| 包治、根治、治疗 | 营养补充、日常护理 |
| 永久、终身、绝对 | 按说明书正常使用 |

**正确做法**

- 说效果只能指向使用感受，不能指向功效结论。“肤感清爽”“穿着舒适”“容量500毫升”都是合规的，“修复”“治疗”“美白”都不行。

- 数据类表述必须有依据。“月销过万件”要能和后台订单数对上，对不上就是虚假宣传。

- 词库一次建好长期用。平台词库每个季度都在更新，你的词库也要季度更新一次。

- 客服快捷语和自动回复要一起排查。这一块最容易被忘，也最容易被截图举报。

- 主图上的文字控制在十字以内，且不遮挡主体，同时不含任何极限词。

**常见错误**

错误示范：只在标题里排查极限词，详情页和主图文字不动。

错在哪：投诉人截图取证时，截详情页和主图的效率比截标题高得多。漏检的位置就是被抓的位置。

错误示范：把“最”改成“醉”、“第一”改成“第1”，以为能绕过去。

错在哪：谐音、变体、符号替代都在识别范围内。看到这类“小聪明”就当违规处理。

错误示范：上架前查过一次就再也不查了。

错在哪：平台词库季度更新，去年合规的表述今年可能已经命中。定期复查是必做项。

> **【规则提示·2026规则修正】** 平台对夸大宣传与绝对化用语的判定趋严，2026年新增可识别的谐音违规词。推广素材同样要过检，素材违规会导致推广计划下线并扣分。

**实操检查清单**

- [ ] 用商品预审工具对标题与详情跑一遍，结果为0违规词

- [ ] 建立违禁词库，覆盖极限词、绝对化、功效词、误导词、谐音变体五类

- [ ] 词库每季度更新一次

- [ ] 把替换词表固化到美工与文案模板

- [ ] 客服快捷语与自动回复每月过一遍词库

- [ ] 包裹卡与直播脚本上架前由专人过检

- [ ] 每次新上架商品由运营签字确认无违规词

## 08 虚构原价与虚假优惠折扣：划线价怎么标才安全

典型状态：你把标价填成99元，用券后成交29.9元，报表很好看。过了两周发现报活动时报不上，系统提示价格不符合要求；再过一周收到虚构原价的违规通知。

> **问**：划线价和原价的法律口径是什么

标价、原价、吊牌价，必须是该商品促销前7日内在本平台的最低成交价。凭空抬高的数字不能当作原价展示。历史最低价的口径以近30天真实成交最低价为准。

> **问**：虚假优惠折扣怎么判定

典型形态是先涨价再打折。大促前把价格提上去，大促当天打折，实际成交价和平时一样甚至更高。百亿补贴等活动中，价格竞争力是硬性考核项；2026年新版规则已把原来的“不得高于全网最低价”调整为“具备较强的价格竞争力”，但先涨后补始终是重点稽查对象，两者不是一回事。

> **问**：处罚是什么

从警告、商品下架、要求整改，到扣保证金、限制功能、清退，按情节和次数升级。

**分步实操**

1．导出近90天的价格记录和成交记录，逐条看每件商品的历史最低成交价。

2．核对每个在售商品的标价与真实吊牌价是否一致。标价与实际不一致的，当天改成真实吊牌价。

3．让利通过真实券实现：标价39.9元，全站营销设满39.9减8，真实成交31.9元。

4．记录每次改价的时间与前后价格，形成一份改价台账。

5．大促报名前先做一次价格校验，确认真实成交价低于近30天最低成交价，且库存深度达标。

6．活动期间不调价、不减库存，避免触发保证金扣划与清退条款。

**算例**

某商品成本16元，目标成交价20元。

- 错误做法：标价填99元，发一张79元券，券后成交20元。这属于虚构原价，因为99元从未在本平台真实成交过。

- 正确做法：标价填真实吊牌价20元，直接成交20元；或者标价29.9元、发满29.9减9.9的券，券后成交20元，其中29.9元有真实吊牌依据。

**正确做法**

- 标价填真实吊牌价，券后价等于目标售价，不虚高。

- 拼多多上大量合规商家直接标最终成交价，不做划线价折扣。这是最省事的做法，也不会有争议。

- 要用划线价，就必须有真实成交依据，且能拿出记录。

- 活动价一旦报低，会影响后续所有活动的历史最低价卡控，报名之前先算清楚价格结构。

- 别把吊牌价当“原价”去证明打了多少折。打折的计算基础是真实成交记录。

**常见错误**

错误示范：跨平台比价时，以为“我在别家平台卖得贵，就能当原价”。

错在哪：原价口径看的是本平台的成交记录。别家平台的价格不构成本平台的原价依据。

错误示范：先虚高到99元卡高投产门槛，靠投产比倒逼资源位。

错在哪：这是典型的虚构原价加价格异常。2026年比价系统按SKU、规格、主图跨店铺跨平台实时比对，虚高不仅拿不到资源位，还可能被下架整改。

错误示范：为了报名活动，把价格临时改成低价提交，指望“不计历史最低价”。

错在哪：历史最低价按近30天真实成交最低价计算，提交记录同样会进入卡控。临时改价只会让后续活动门槛更难满足。

> **【规则提示·2026规则修正】** 虚高标价加优惠券守利的做法，已属虚构原价与虚假优惠折扣。依据是《商品管理规则》中关于原价与优惠折扣标示的要求。合规替代：真实吊牌价加真实券，例如标价39.9元、满39.9减8、真实成交31.9元。百亿补贴等活动另按新版规则考核价格竞争力，报名前以后台报名页的价格提示为准。

**实操检查清单**

- [ ] 导出近90天价格记录，逐条核对历史最低成交价

- [ ] 在售商品标价与真实吊牌价逐条对齐

- [ ] 让利全部通过真实券实现并截图留存

- [ ] 建立改价台账（改价时间、改前价、改后价、原因）

- [ ] 大促报名前做一次价格校验

- [ ] 活动期间不调价、不减库存

- [ ] 全店无空白依据的划线价

## 09 阴阳SKU、炮灰SKU与规避比价：都是违规

典型状态：你曾把副规格的文字和场景图换一换，以为系统会当成不同产品，比价就不生效了。也设过一个0.01元的炮灰SKU，想卡住价格锚点。

> **问**：阴阳SKU是什么

同一条链接里，用文字和图片把规格做得看起来完全不一样，但实际卖的是同一个东西。目的是让比价系统认不出来，从而维持较高售价。

> **问**：炮灰SKU是什么

用一个远低于主款的价格做诱饵。常见形态有三种：一是0.01元的假SKU，实际不发货；二是低到不合理的规格，比如“单只袜子”“一片试用装”，用来把前台展示价压得很低；三是库存留1的引流款，用来拿价格锚点和活动流量。

> **问**：处罚是什么

判定为低价引流或规避比价的，商品下架、扣分、限制功能；情节严重的判扰乱价格秩序，链接断流甚至清退。

**分步实操**

1．检查全店每个SKU的可成交性：每个SKU都要能独立下单、能发货。不能成交的全部删除。

2．检查价格分布，把价格低于主款30%的SKU逐一核对，看差异是不是来自真实规格。

3．检查SKU名称与规格图：文字和图片必须真实反映规格，不能用不同的图片描述同一个规格。

4．检查主图：所有主图都拍真实使用场景，不使用AI生成的、与实物不符的场景图。

5．做一组真实差异，用来拉开价格逻辑：不同容量、不同件数、不同组合、真实赠品。

6．建立价格差异化台账，写下每个SKU与竞品的真实差异点。

**正确定价示例**

一条卖收纳盒的链接，三个SKU做真实的规格差异：

| SKU | 规格 | 价格 | 差异来源 |
| --- | --- | --- | --- |
| 单只装 | 1只，容量8升 | 19.9元 | 基础规格 |
| 两只套装 | 2只，容量8升 | 34.9元 | 件数差异 |
| 两只加厚装 | 2只，容量10升，加厚材质 | 49.9元 | 规格与材质差异 |

三个SKU都能单独成交、都能发货，价格差异来自真实的产品差异。这就是合规的差价格局。

**正确做法**

- 理解比价的机制：2026年的比价系统已经跨店铺、跨平台，按SKU规格、主图、标题语义实时聚类。靠改文案已经躲不开了。

- 差异化必须是真实的：不同规格、不同件数、不同组合、真实赠品、品牌授权差异、真正不同的使用场景图。

- 把价格优势建立在供应链成本上，不要建立在规则漏洞上。成本优势别人抄不走，规则漏洞随时会堵。

- 用后台的价格诊断与商品体检功能看自己的价格竞争力，而不是想办法躲比价。

- 库存留1的用法要分清：单纯用于活动提报流程本身可以，但用低到不合理的价格做诱饵就是低价引流。

**常见错误**

错误示范：设一个0.01元的SKU挂半年，指望它一直帮自己压住前台展示价。

错在哪：这是低价引流，商品会下架并扣分。而且0.01元的展示价会吸引大量咨询和无效流量，拉低转化率。

错误示范：只换SKU文字和场景图，不做真实的规格差异。

错在哪：换文字换图被认定为阴阳SKU与规避比价的变种，平台已把这类做法点名为价格陷阱重点治理。

错误示范：用AI生成与实物完全不符的场景图来“做差异化”。

错在哪：场景图与实物不符本身就是虚假宣传，而且拍摄场景造假会被买家评价反证。

> **【规则提示·2026规则修正】** 阴阳SKU、只改文字加场景图躲比价、炮灰SKU卡价、隐藏活动ID原价卡大促，全部属于规避比价的治理范围。依据是比价系统已按SKU规格、主图、标题语义跨店铺跨平台实时聚类。合规替代是真实差异化：规格、件数、组合、真实赠品、真实使用场景图。强付费靠不报活动躲比价也不成立，标品日常就处在实时比价环境里。

**实操检查清单**

- [ ] 删除全店所有不可成交的SKU

- [ ] 核对每个SKU的规格图真实可发货

- [ ] 后台商品体检中确认无异常低价SKU

- [ ] 建立价格差异化台账，标明每个SKU的差异来源

- [ ] 用后台价格诊断查看整体价格竞争力

- [ ] 主图、场景图全部为真实拍摄

- [ ] 上新前核对SKU价格梯度是否与规格梯度一致

## 10 诱导第三方与站外导流：什么算导流，怎么罚

典型状态：你觉得买家加微信之后复购更方便，于是在包裹卡上印了“加微信享优惠”。客服也习惯在聊天里留手机号，说是“方便售后”。

> **问**：哪些行为算导流

一共六类，只要命中一类就算：

1．聊天中发送微信号、手机号、二维码。

2．聊天中发送其他平台链接、支付宝账号、收款码。

3．包裹卡、商品标签、说明书上印联系方式或二维码。

4．主图、详情、SKU图中出现其他平台标志、网址、二维码。

5．客服引导买家到其他平台下单，或引导线下交易。

6．物流面单上出现商家自己的联系方式。

> **问**：处罚是什么

最轻是扣分加限流。最重是私下交易：聊天里引导站外交易的，店铺保证金直接加收10万元。半年内不再犯可以退，再犯没收并再交10万元。不交则强制关店，货款无法提现。

> **问**：想留住老客，合规的办法是什么

**只有站内路径：**

1．引导“关注店铺”，配合站内消息触达。

2．用店铺会员体系做复购权益。

3．用平台优惠券做老客专享，比如新客券、回访券、直播券。

4．用评价有礼等官方工具引导真实评价。

5．包裹卡写“晒图参与抽奖”“领取店铺券”这类引导，落地页必须是平台内的活动页。

**分步实操**

1．逐条检查店铺介绍、客服自动回复、快捷语，看有没有站外联系方式。

2．检查主图与详情图，看有没有其他平台标志、二维码、网址。

3．检查包裹卡与外包装，检查商品标签。

4．打开客服禁用词库，把微信、手机号、QQ、加我等词逐步加入拦截。

5．给客服做一次培训：任何时候都不主动提供私人联系方式。

6．每月抽查客服聊天记录，看有没有导流行为。

7．老客复购全部走站内工具。

**正确做法**

- 把私域理解成“平台内的私域”。关注、会员、站内消息、优惠券，都是合规的触达路径。

- 售后需要联系买家的，全部在平台聊天窗口里完成，留下完整记录。这既是合规要求，也是日后申诉的证据。

- 包裹卡是导流的高发位置，因为印刷量大，一印就是几千张。文案定稿前让运营和客服各过一遍。

- 导流的处罚是直接从保证金里加收10万元，一次就够伤筋动骨。这个数量级的代价不需要用“能不能被查到”来衡量。

- 长期看，“把买家留在平台内”并不吃亏，因为平台会根据你的复购行为给你更多推荐流量。

**常见错误**

错误示范：包裹卡上印“加微信享优惠”，理由是“发货量太大，客服忙不过来”。

错在哪：这是典型导流，必罚。包裹卡是稽查的重点位置，因为它可以被买家直接拍照举报。

错误示范：客服在聊天里说“售后问题加我微信，处理得快”。

错在哪：聊天记录本身就是证据，平台可以直接调取。好意也要看路径，路径错了就是违规。

错误示范：详情页写“工厂直发，可加微信议价”。

错在哪：引导议价等于引导脱离平台成交，属于站外交易导向，处罚最重的一档。

> **【规则提示·2026规则修正】** 商品、客服、包裹卡引导“加微信”“去另一个平台”“线下交易”，留手机号与二维码，都会被扣分加限流。合规替代只有平台内的关注店铺、会员、站内优惠券和评价有礼。

**实操检查清单**

- [ ] 检查店铺介绍与客服自动回复有无站外联系方式

- [ ] 检查主图、详情是否有“加微信”类字样

- [ ] 检查包裹卡文案是否含站外引导

- [ ] 检查物流面单是否有商家私人联系电话

- [ ] 客服禁用词库加入微信、手机号、QQ等拦截词

- [ ] 客服培训确认：不主动给任何私人联系方式

- [ ] 每月抽查一次客服聊天记录

## 11 售后与客服违规：恶意拒绝、骚扰买家、泄露信息

典型状态：买家申请仅退款，你判断是白嫖，于是拖着不处理，或者在聊天里直接说了几句难听的话。同一天客服把一张订单截图发到群里，上面有买家的完整手机号。

> **问**：哪些行为算恶意拒绝售后

1．商品确实存在质量问题，却反复要求买家提供超出必要范围的举证。

2．收到退回件后不确认、不处理，拖到系统超时。

3．无正当理由拒绝退货退款。

4．收到货不退款，或退款金额与协商内容不一致。

5．以“影响二次销售”为由拒绝明显有质量问题的退货。

售后处理窗口是买家发起后48小时，超时未处理系统默认同意直接退款。买家寄出并填写单号后，你需要在收到退回件后48小时内确认。

> **问**：骚扰、辱骂、泄露信息的处罚是什么

前两项按客服服务违规处理，扣分加投诉受理，情节严重叠加降权。泄露买家信息属于极严重违规，包括把买家姓名、电话、地址、订单内容泄露给第三方，或用于与履约无关的用途，会导致扣保证金、限制功能，情节严重直接清退。

**分步实操**

1．检查客服聊天记录里有没有情绪化的表述，包括反问句、嘲讽句、“你是不是想白嫖”这类话。

2．建立客服话术库，把高频争议场景的标准回复写好，客服直接复制，不自由发挥。

3．开启小额自动退功能，拦截恶意秒退。路径是后台搜“小额自动退”，开启后单日与单笔退款上限设1元，勾选所有退款原因，添加全部商品。

4．已发货且超过上限的订单平台不会自动同意，可以到售后申诉入口提交聊天截图追回。

5．每天上午、下午各清一次售后待处理，确保48小时内处理完毕。

6．建立信息保护规则：买家信息的截图只在售后专用资料里存放，禁止发到任何群聊，禁止带出工作电脑。

7．每周抽查一次客服聊天记录，重点看争议单。

**可直接复制的客服话术**

**面对情绪激烈的买家：**

很抱歉给您带来不好的体验。您的问题我已经记录，这边马上为您核实。请您放心，只要符合平台规则，我们一定给您处理好。

**买家要求仅退款但拒绝提供凭证：**

理解您的心情。为了能准确判断问题在哪，麻烦您提供一张清晰的商品照片或一段视频。您也可以选择退货退款，退货运费由我们承担。

**买家在聊天里辱骂：**

非常抱歉让您不满意。请您把具体问题告诉我，我们按平台规则为您处理。如果您同意退货退款，运费我们承担。

**正确做法**

- 客服三原则：尊重、耐心、同理心。聊天时间长不等于服务好，把问题一次解决才算。

- 有争议也别拖着。超时系统默认同意退款，事后再申诉的成功率远低于当场协商。

- 该给的证据提前给。买家一上来就说质量有问题，你直接回复“支持退货退款、运费我方承担”并截图，这一步既是诚意，也是后续申诉的关键证据。

- 买家信息只用于履约。发货、售后、开票三件事以外的任何使用都是越界。

- 把“情绪管理”具体化成可执行的规则：任何情况下不评价买家动机，不反问，不追问隐私。

**常见错误**

错误示范：和买家在聊天里对骂。

错在哪：所有聊天记录平台都能看到。对骂的结果是你从“有理”变成“违规”，罚款之外还影响店铺评分。

错误示范：客服为了“让同事帮忙看看”，把带买家手机号的订单截图发到工作群。

错在哪：这是泄露买家信息，属于严重违规，处罚级别远高于一次售后纠纷。要同事协助就用不含个人信息的订单号沟通。

错误示范：收到退货后想拖几天，指望买家放弃。

错在哪：退回件确认有48小时时效，超时系统默认退款并计入售后体验分。

> **【规则提示·2026规则修正】** 沟通中不得人身攻击、侮辱、骚扰；买家个人信息仅可用于履约。恶意拒绝售后与恶意骚扰买家都在扣分范围内，泄露信息属于极严重违规。退款时效与默认同意规则以后台实时提示为准。

**实操检查清单**

- [ ] 开启小额自动退，上限设1元并勾选全部退款原因

- [ ] 客服话术库覆盖退款、质量争议、催发货三类高频场景

- [ ] 每天分上午下午两次清空售后待处理

- [ ] 争议单全程保留完整聊天截图

- [ ] 所有买家信息截图只存放于售后专用资料，禁止外发

- [ ] 每周抽查客服聊天记录并做一次点评

- [ ] 建立情绪管理规则并让客服全员签字

## 12 无照经营、亮照与税务风险

典型状态：你用个人身份开了店，销售额涨起来之后发现需要补资质；联合营销功能被开启了，你既没关也没开票，结算时发现货款被冻了一部分。

> **问**：亮照是什么

拼多多要求商家在店铺内公示主体信息，包括营业执照信息、许可信息。个人店按平台要求提供真实身份信息，企业店上传营业执照。主体信息与实际经营者必须一致，用他人营业执照开店、借用他人身份开店都属于高风险行为。

> **问**：无照经营的后果是什么

1．平台侧：限制功能、限制提现，严重时清退。

2．监管侧：涉及需许可的类目，无证经营会被查处。

3．店铺侧：用同一身份证反复开个人店会形成关联店铺，一处违规全盘受影响。

> **问**：税务上有哪些坑

1．联合营销功能开通后必须开票，否则平台冻结货款，冻结额大约是开票额的30%。税率参考：一般纳税人6%，小规模1%。

2．平台结算金额与申报销售额不一致会带来风险。

3．用个人账户承接经营款，长期会形成主体与资金不匹配。

**分步实操**

1．打开后台“店铺资质”页，逐项核对主体信息是否完整、是否与营业执照一致。

2．核对营业执照上的经营范围是否覆盖你在售的类目。

3．经营范围或资质不全的，先去工商变更或注销对应类目商品。

4．打开联合营销设置，评估是否需要保留。不靠活动吃饭的中小卖家可以关闭；保留的，建立开票流程，按开票时间逐笔记录。

5．把开票成本计入定价，产品毛利里预留足够的税负空间，不要靠事后加价。

6．每季度核对一次平台结算金额与税务申报金额。

7．把结算单、发票、进货发票、银行流水按年度归档保存。

**正确做法**

- 有经营行为就按主体经营，营业执照、店铺主体、收款主体三者一致。

- 亮照信息主动核对，不等平台通知。信息过期、变更后没更新的，都算异常状态。

- 需要许可的类目，证照先办齐再上架。食品要许可、化妆品要备案、医疗器械要经营许可与注册证。

- 联合营销开不开要提前决策，不要开了以后放着不管。冻结货款对现金流的伤害是直接的。

- 把税当成成本项写进定价模型，而不是利润跑出来以后的意外支出。

**常见错误**

错误示范：用个人身份一直经营，觉得“反正是小生意，不用管主体”。

错在哪：一旦销售额上来，主体问题会同时影响提现、活动和后续升级企业店。这是隐形成本，越晚处理越贵。

错误示范：为了省成本，用别人的营业执照开店。

错在哪：主体不一致属于高风险管理问题，涉及资质与税务两条风险，店铺随时可能被限制。

错误示范：把发票成本转嫁给买家，在详情页写“需要发票需加价”。

错在哪：开票是法定义务，不能作为加价理由。这一句话本身还会被投诉。

> **【规则提示·2026规则修正】** 联合营销自2026年4月13日起强制开通但可手动关闭，路径是店铺营销、平台优惠、右侧关闭活动。开通后必须开票，否则平台冻结货款，冻结额约为开票额的30%。不靠活动驱动的中小卖家建议关闭。

**实操检查清单**

- [ ] 核对店铺资质与主体信息是否完整一致

- [ ] 核对营业执照载明的经营范围覆盖全部在售类目

- [ ] 评估联合营销保留还是关闭并做出决策

- [ ] 保留的建立开票台账（每笔记录开票时间与金额）

- [ ] 每季度核对平台结算金额与税务申报金额

- [ ] 结算单、发票、进货发票、银行流水按年度归档

- [ ] 需要许可的类目确认证照齐全且在有效期内

## 13 违规通知通用申诉SOP：入口、时效、五步法

典型状态：收到违规通知的第一反应是慌，第二反应是到处找人问。等你终于决定申诉，发现申诉入口已经关了。

> **问**：申诉入口在哪

后台的“违规记录”或“违规管理”里逐条查看，每条违规都有对应的“申诉”或“我要申诉”按钮。部分场景需要走独立的申诉通道，比如知识产权投诉走知产保护入口，售后争议走售后申诉入口。

> **问**：时效窗口有多长

申诉窗口从处罚通知送达时开始计算，一般类违规的申诉期是若干天，售假、导流、虚假交易这类严重违规的申诉期更短。窗口一过，申诉入口永久关闭，已产生的处罚不可逆。所以收到严重违规通知的第一件事不是问人，是先看剩余时间。

> **问**：超时了会怎样

超时将失去申诉机会，处罚按原判定执行完毕，扣分计入累积，严重违规还会影响后续90天的活动报名资格。

> **问**：申诉五步是什么

1．定位：在违规记录里找到具体条目，复制违规编号与商品ID。

2．判断：确认违规类型与判定依据，判断自己属于“确实需要整改”还是“被误判”。

3．备料：按类型准备证据清单，这是决定成败的一步。

4．提交：在申诉页选择正确的违规原因，写明申诉理由，上传证据。

5．跟踪：每天查看一次申诉状态，被驳回的看驳回原因，决定是否补料再提。

**分步实操**

1．收到通知当天，把违规编号、商品ID、通知时间、申诉截止时间抄进台账。

2．判断是误判还是确有问题。误判走申诉，确有问题走整改，两条路不要混。

3．按违规类型准备材料，材料要与申诉理由一一对应，不要堆无关文件。

4．申诉理由按“事实加证据加请求”三段写，每段不超过三句话。

5．提交后截图留存提交记录与受理编号。

6．申诉成功的，把证据包归档到店铺的合规案例库；申诉失败的，看驳回原因，能补料的补料，补不了的就执行整改。

7．无论申诉成败，都把这条违规对应的操作流程改掉，避免同类问题第二次出现。

**申诉五步的时效节奏**

| 时间 | 动作 |
| --- | --- |
| 第1天 | 定位违规条目，判断误判还是确需整改 |
| 第1到2天 | 备齐证据材料并按类型归类 |
| 第2到3天 | 提交申诉并留存提交记录 |
| 第3到7天 | 每天查看申诉状态，及时补料 |
| 第7天起 | 申诉结束，失败则立即整改并修订流程 |

**正确做法**

- 收到通知当天就动。申诉是抢时间的活，材料可以在提交后补，窗口不能补。

- 申诉理由写事实和证据，不写情绪。所有涉及指责对方的表述都删掉。

- 一次申诉只针对一条违规。多条违规合并申诉会降低处理效率。

- 申诉失败不等于没救，很多场景可以补料后再提。但要看清驳回原因，不要重复提交同一份材料。

- 把每一次申诉都当成积累。成功的证据包存下来，下次同类违规直接复用。

**常见错误**

错误示范：想着“等有空再申诉”，拖到窗口关闭。

错在哪：申诉入口关闭后处罚不可逆，而且会占用申诉机会。严重违规的申诉期更短。

错误示范：申诉理由写“你们判错了”“我做了这么多年从来没被罚过”。

错在哪：申诉是证据审核，不是辩论。没有证据的情绪化表述对结果没有任何帮助。

错误示范：同一条违规反复提交同一份材料。

错在哪：重复提交会被判定为无效申诉，消耗申诉次数，被驳回的间隔时间还会被拉长。

> **【规则提示·2026规则修正】** 售假、导流、虚假交易这类严重违规的申诉要求更严，光提交资质不够，必须拿出完整的行为证据链。具体时效与入口以后台实时提示为准。

**实操检查清单**

- [ ] 建立违规申诉台账（违规编号、类型、通知时间、申诉截止时间、处理结果）

- [ ] 收到违规通知当天完成定位与判断

- [ ] 按类型准备证据清单，一一对应申诉理由

- [ ] 申诉提交后截图留存提交记录与受理编号

- [ ] 每天查看一次申诉状态

- [ ] 申诉成功后把证据包归档到案例库

- [ ] 申诉失败后48小时内启动整改

## 14 申诉证据怎么准备：照片、视频、聊天记录、物流凭证、进货凭证

典型状态：你知道自己是被误判的，但打开申诉页的时候发现手上什么都拿不出来。发货没拍视频、聊天记录没存、进货凭证找不到了。

> **问**：五类证据分别要准备什么

| 证据类型 | 具体内容 | 注意点 |
| --- | --- | --- |
| 照片 | 商品实拍、包装实拍、发货现场、开箱过程 | 要能看清商品本体、标签、批次号，带时间信息 |
| 视频 | 打包过程、封箱过程、拆包验货、商品功能演示 | 一镜到底，中途不剪辑，能看出包裹与订单的对应关系 |
| 聊天记录 | 与买家的完整对话、协商过程、买家提供的问题照片 | 从会话开始到结束完整截图，不能只截有利部分 |
| 物流凭证 | 电子面单、揽收记录、中转记录、签收记录、退货单号 | 必须使用平台电子面单，中转轨迹要连续 |
| 进货凭证 | 发票、进货单加公章、付款流水、授权书、供货方营业执照 | 品名规格数量日期四处要一致，日期早于销售 |

> **问**：证据怎么和申诉理由对应

一条申诉理由对应一组证据。写“商品为正品”，对应授权链加进货凭证；写“已真实发货”，对应电子面单加揽收记录加打包视频；写“买家未提供质量凭证”，对应完整聊天记录加买家上传的图片。理由和证据不对应的部分，审核不会采信。

**分步实操**

1．建一个本地的证据文件夹，按违规类型分子文件夹：售假、盗图、虚假发货、虚假交易、售后争议。

2．每个子文件夹里放一份清单文件，写明这类申诉需要哪几件材料。

3．发货环节固定动作：打包前拍商品外观，打包中拍装箱过程，封箱后拍面单与包裹同框。全程一镜到底。

4．聊天记录按订单号归档，与买家的每一次争议对话都完整截图存到订单文件夹。

5．进货凭证按批次归档，扫描件命名写清品牌加批次加日期。

6．收到申诉通知后，从对应子文件夹里直接取料，按清单核对一遍再提交。

7．提交完成后把本次材料另存一份到“已用证据”目录，作为下次同类申诉的模板。

**正确做法**

- 证据要在日常积累，不是出事以后补。补出来的证据有时间断点，一看就假。

- 拍视频一镜到底，不剪辑、不加字幕。剪辑过的视频在申诉里可信度低。

- 聊天记录要完整。只截对自己有利的片段，审核一旦看到上下文就认定你在筛选证据，整份材料的可信度归零。

- 物流凭证必须走平台电子面单。跨平台单号直填、手动填无轨迹单号，都会被判虚假发货。

- 进货凭证的四处一致性要反复核对：品名、规格、数量、日期。这四处任意一处不一致，整份凭证就废了。

- 证据留存期限至少三年。很多争议在半年后才升级处理。

**常见错误**

错误示范：申诉时上传十几张截图，但没写清哪张对应哪条理由。

错在哪：审核需要按理由找证据。材料堆在一起没对应关系，等于没提交。

错误示范：发货时顺手拍一张包裹照片，但看不出面单信息，也看不出包裹里装的是什么。

错在哪：证据要能建立“这个订单的包裹里装的是这个商品”的对应关系。拍不出对应关系的照片，帮不上忙。

错误示范：把进货发票的关键信息用马赛克遮掉，理由是“怕泄露客户信息”。

错在哪：品名、规格、数量、日期、开票方正是审核要看的，遮掉就等于没有这张凭证。可以遮价格，不要遮身份信息与商品信息。

> **【规则提示·2026规则修正】** 涉及行为轨迹的申诉，平台要求的是完整的证据链，单份材料不足。发货打包视频、电子面单轨迹、聊天记录三条证据同时具备，才是完整的一条链。

**实操检查清单**

- [ ] 建立本地证据文件夹，按违规类型分子文件夹

- [ ] 每个子文件夹放一份材料清单文件

- [ ] 发货打包全程录制一镜到底视频并留存90天

- [ ] 用平台电子面单，保证中转轨迹连续

- [ ] 争议聊天记录按订单号完整截图归档

- [ ] 进货凭证扫描件按品牌加批次加日期命名

- [ ] 所有证据留存三年以上

## 15 各类常见违规的申诉理由与话术模板

典型状态：材料你都准备好了，但打开申诉输入框不知道怎么写。写了三行发现全是情绪，删掉重写又不知道从哪句开始。

> **问**：申诉话术有没有通用结构

有，固定三段：先说事实，再说证据，最后说请求。每段控制在三句话以内，全文不超过200字。审核看的是事实与证据的对应关系，不是文采。

> **问**：申诉里什么话绝对不能写

四类：指责对方的表述、情绪化表述、“我从来没被罚过”这类资历说明、没有证据支撑的结论。

**逐类申诉话术模板**

**售假类申诉：**

本店该商品货源来自某某商贸有限公司，已提交完整的品牌授权链（品牌方至一级授权至本店）与该次进货对应的增值税发票。发票载明商品名称、规格、数量，与我方在售商品一致，进货日期早于销售日期。本店不存在售假行为，请求平台重新核实，恢复商品正常展示。

**盗图类申诉：**

该主图为本店原创拍摄，已提交同一批次的拍摄原片（含拍摄时间信息）与设计源文件。原片拍摄日期早于侵权投诉方商品的上架日期，可对比构图、道具、布光角度三处细节。请求平台核实素材权属，恢复商品正常状态。

**虚假发货类申诉：**

该订单使用拼多多电子面单发货，面单号可查询到完整的揽收记录、中转记录与签收记录，轨迹连续。同时提交打包过程的完整视频，可对应订单商品与包裹。请求平台核实物流轨迹，撤销本次处罚。

**虚假交易类申诉：**

该批次订单为真实企业采购，买家为某某公司，已提交采购合同、该公司订单聊天记录与全部物流签收记录，签收地址为该企业注册地址。订单时间跨度在正常工作时段内，非集中下单。请求平台核实后撤销本次判定。

**仅退款争议申诉：**

我方已多次向买家明确表示支持退货退款、退货运费由我方承担，并已留存聊天截图。买家拒绝提供质量问题凭证，也拒绝退货。我方拒绝不退货仅退款。请求平台维护公平交易秩序，驳回该笔仅退款申请。

**知识产权投诉被驳回后的补料申诉：**

上一轮提交的权属材料缺少创作时间证明，本轮补交该素材的拍摄原片与云端首次上传时间记录，两者时间一致且早于被投诉商品上架时间。请求平台重新审核素材权属。

**分步实操**

1．复制对应模板，把方括号位置换成你自己的信息，包括公司名称、日期、单号。

2．通读一遍，删掉所有形容词与情绪词，只留事实。

3．核对每一句都能对应到一份上传的材料，对不上的句子删掉或补材料。

4．全文控制在200字以内，超过就说明有冗余。

5．提交后记录提交时间与受理编号。

6．被驳回的，看驳回原因是“证据不足”还是“判定维持”，前者补料再提，后者改走整改路线。

**正确做法**

- 模板只解决结构，不解决证据。证据不足时用再漂亮的模板也没用。

- 一句话只讲一件事，让审核能逐句核对。

- 把所有单号、日期、公司名称写准确。写错一个数字，整份材料会被退。

- 申诉话术里不要出现情绪化用词，也不要出现新的夸大表述，否则可能触发新的违规。

- 保留每次申诉的话术，成功的版本存档复用。

**常见错误**

错误示范：申诉写“这个客户明显是恶意白嫖，我们已经忍他很久了”。

错在哪：申诉是给审核看的，不是给买家看的。情绪化表述不影响判定，但会削弱整份材料的专业度。

错误示范：把四五条违规的申诉写成一份长文一次提交。

错在哪：每条违规独立审核，合并提交会导致材料无法对应到具体条目，反而全部被驳回。

错误示范：申诉里承诺“以后一定不再犯”但一句证据都没有。

错在哪：承诺不是证据。没有证据支撑的申诉，处理结果是维持原判。

**实操检查清单**

- [ ] 为六类高频违规各准备一份申诉模板

- [ ] 模板里的方括号位置全部替换为真实信息

- [ ] 每条申诉理由都能对应到一份已上传材料

- [ ] 申诉全文控制在200字以内

- [ ] 提交后留存提交记录与受理编号

- [ ] 申诉成功的版本归档到案例库并复用

- [ ] 申诉失败的按驳回原因决定补料还是整改

## 16 违规对店铺的实际影响与恢复节奏

典型状态：处罚下来之后流量断了一截，你急着加大推广投放，想把流量买回来。结果钱花得更快，流量没回来，评分还往下掉。

> **问**：违规会造成哪些实际影响

1．搜索降权：自然流量下滑，关键词排名下移。

2．活动资格：有违规记录会被活动驳回，大促通常要求近90天无严重违规。

3．推广受限：违规期间部分推广功能被限制或计划被下线。

4．体验分下滑：违规扣分会直接影响综合体验星级，进而影响搜索加权与活动资格。

5．资金影响：扣保证金、限制提现、货款冻结。

6．评分与评价：虚假评价被清理后，销量与评价数会下降，链接的转化基础被削弱。

> **问**：多久能恢复

**按违规轻重分三档：**

| 违规程度 | 典型违规 | 恢复周期参考 |
| --- | --- | --- |
| 轻度 | 极限词、类目错放、描述不符 | 整改到位后3到7天，限流逐步解除 |
| 中度 | 虚假发货、知识产权侵权、低价引流 | 7到30天，需配合扣分周期滚动 |
| 严重 | 售假、虚假交易、导流 | 清退或资金冻结，属于不可逆 |

> **问**：恢复的核心是什么

三件事同时做：整改到位、时间过去、数据变好。缺任何一件都恢复不了。只整改不改善数据，平台没有理由把流量还给你；只等时间不做整改，违规记录会一直挂着。

**分步实操**

1．第1天：确认违规类型与整改要求，把违规商品下架，停止继续产生违规数据。

2．第1天：关闭自动化推广，只保留小额测试。违规期间大额投放会被判定为异常。

3．第2到3天：修数据。把48小时揽收率提到98%以上，把仅退款占比压下来，把3分钟人工回复率稳定在98%以上。

4．第4到7天：整改后的商品逐步上架，主图、详情、标题全部过一遍违禁词，客服话术同步更新。

5．第8到14天：看数据曲线。在“流量数据、搜索流量”里看蓝线与黄线的关系，蓝线高于黄线说明权重在回来。

6．第15到30天：确认限流解除后再逐步恢复推广预算，每次调整幅度不超过原来的20%。

7．全程记录，形成一份违规修复记录，写清违规原因、整改动作、恢复日期。

**恢复期核心指标**

| 指标 | 目标 |
| --- | --- |
| 48小时揽收率 | 稳定在98%以上 |
| 仅退款占比 | 环比下降30%以上 |
| 3分钟人工回复率 | 稳定在98%以上 |
| 商品体检 | 保持绿色 |
| 纠纷率 | 压到1.5%以内 |
| 描述不符占比 | 压到3%以下 |

**正确做法**

- 先修数据，再谈推广。违规后加投推广是最常见的错误，等于给平台的负向判断加杠杆。

- 把恢复期当成一次全面体检。趁这段时间把主图、详情、标题、SKU、资质全部过一遍。

- 每天看一次后台数据，只看六个指标，不要一天换一个指标。

- 恢复到什么程度由数据决定，不是由日历决定。连续7天指标稳定再恢复投放。

- 建立违规修复记录表。每一条违规都写清原因、动作、恢复日期，这就是你店铺自己的经验库。

**常见错误**

错误示范：收到降权通知当天就把推广预算翻倍，想用钱把流量买回来。

错在哪：降权期间系统对异常的付费流量更敏感。加大投放不仅买不回自然流量，还可能触发新的风控判断。

错误示范：只改主图，其他一切照旧。

错在哪：违规判定看的是行为，不是某个素材。同一类行为还会再犯，第二次的处罚档位更高。

错误示范：想用换新链接的方式把旧记录甩掉。

错在哪：违规记在店铺主体上，不在单条链接上。换链接不能清零，只是重新从零开始积累权重。

错误示范：整改完了但不去复核，不知道限流有没有解除就恢复投放。

错在哪：没确认解除就加大投放，钱花了还会被发现违规行为仍在，损失翻倍。

**实操检查清单**

- [ ] 违规商品先下架整改，停止产生新的违规数据

- [ ] 关闭自动化推广，只保留小额测试

- [ ] 每天盯六个核心指标，做趋势记录

- [ ] 全网商品主图、详情、标题过一遍违禁词

- [ ] 确认48小时揽收率稳定在98%以上

- [ ] 建立违规修复记录表（原因、动作、恢复日期）

- [ ] 连续7天指标稳定后再逐步恢复推广预算

## 17 上架前合规体检：六项自查不过不上架

典型状态：你上架了一个商品，第二天就收到违规通知。回头看，问题出在类目放错、标题带极限词、SKU价格真实但类目不对——三个问题其实在上架前就能查出来。

> **问**：上架前要查哪六项

按顺序查这六项，任何一项不过就不上架：

1．类目对：三级类目与实际商品一致，属性填写完整。

2．标题合规：商品预审工具跑出0违规词，标题30字以内、核心词前置。

3．图片合规：主图白底无牛皮癣、无其他平台水印、无极限词、无虚假促销、无诱导性文字。

4．SKU真实：每个SKU都能独立成交发货，价格差异来自真实规格差异。

5．资质齐：类目所需证照齐全且在有效期内，品牌有授权链。

6．不导流：主图、详情、SKU图、客服话术中无站外联系方式。

> **问**：除了自己查，还有什么工具

后台有三个：商品预审工具查标题与详情违规词，商品体检工具查商品健康度，违规记录查历史与累积。另外可以用第三方图文检测工具做二次校验。

**分步实操**

1．进入商品编辑页，先核对三级类目与属性，类目选错的直接返回重选。

2．标题写好后用商品预审工具跑一次，有命中就改，直到0违规词。

3．主图逐张检查：白底或浅色背景，主体占比不小于70%，第一张不含极限词与虚假促销文字，主图文字不超过10字且不遮挡主体。

4．SKU逐个检查可成交性，删除不可发货的规格。

5．打开资质台账，核对类目所需证照的有效期。

6．检查详情与客服快捷语，删掉所有站外联系方式。

7．六项全部通过后再点“提交”。提交后当天再看一次商品体检结果。

**上架前六项自查表**

| 项目 | 通过标准 | 常用工具 |
| --- | --- | --- |
| 类目 | 三级类目与商品一致，属性填全 | 商品编辑页 |
| 标题 | 预审0违规词，30字以内 | 商品预审工具 |
| 图片 | 白底、无牛皮癣、无极限词 | 商品体检加图文检测 |
| SKU | 全部可成交，价差来自真实规格 | 商品编辑页 |
| 资质 | 证照齐全有效，授权链完整 | 资质台账 |
| 导流 | 无站外联系方式与二维码 | 人工逐条检查 |

**正确做法**

- 把六项做成一张表，每次上新填一次，运营签字后再提交。

- 类目放错是最隐蔽的“零流量”原因，也是最容易被忽略的一项。选类目时按商品属性走，不要按保证金高低走。

- 预审工具的结果可以是0，你的自查标准就应该是0，不是“少一点”。

- 属性要填全。属性不全会导致商品无法进入某些流量池，也会影响比价系统的类目归属。

- 上新当天再看一次体检结果。有些问题在提交后才会被系统扫描出来。

**常见错误**

错误示范：为了少交保证金，把商品放到保证金低的类目。

错在哪：类目错放会导致搜索流量错配，同时可能被判定为违规。省下的保证金远不够补流量的损失。

错误示范：标题里带一个自己觉得“通用”的品牌词，想着反正没人投诉。

错在哪：未经授权使用品牌词属于知产侵权，投诉是别人发起，不是你能控制的。别人什么时候投诉你，你说了不算。

错误示范：SKU设一个0.01元的规格用来吸引点击。

错在哪：这是低价引流，商品会下架并扣分。

**实操检查清单**

- [ ] 建立上新前六项自查表并每次填写签字

- [ ] 商品预审跑出0违规词再提交

- [ ] 主图逐张检查白底、主体占比、无牛皮癣

- [ ] SKU逐个确认可成交可发货

- [ ] 类目与属性逐项核对

- [ ] 资质台账核对一次有效期

- [ ] 详情与客服话术检查无站外联系方式

## 18 商家合规自查清单：日、周、月、季四档节奏

典型状态：上面十几条你都知道，但落到日常就忘了。一周忙下来，什么都没查过，直到违规通知再来一次。

> **问**：自查清单为什么必须分频次

因为不同风险的暴露速度不一样。违规记录和商品体检是每天变的，素材授权是每周积累的，资质有效期是按月跑的，规则更新是按季度来的。用同一个频率查所有项目，要么漏，要么累到自己放弃。

> **问**：检查结果要留痕吗

要。留痕有三个作用：出问题时能证明你查过，团队交接时有依据，平台要求提供整改记录时能直接拿出来。

**每日自查**

- 检查“违规记录”，当天清零待处理条目。

- 检查商品体检，颜色为绿色。

- 检查48小时发货时效，看有无逼近时限的订单。

- 检查客服3分钟人工回复率，目标不低于98%。

- 检查售后待处理队列，当天清空。

- 检查在售商品有无异常低价或价格跳变。

**每周自查**

- 检查全店商品标题与详情有无新增违规词。

- 检查在售商品的类目、属性、主图、SKU是否完整合规。

- 抽查10条客服聊天记录，看有无导流与情绪化表述。

- 检查包裹卡文案与库存，确认无站外引导内容。

- 抽查一段发货打包视频，确认录制规范。

- 复查一次素材库的授权状态。

**每月自查**

- 核对资质证照有效期，即将到期的列入续期计划。

- 核对授权链完整性，检查授权书是否临近到期。

- 检查平台规则更新公告与后台通知。

- 复盘本月的违规记录与申诉结果。

- 核对一次平台结算金额与开票情况。

- 检查自建违禁词库，按最新规则补充。

- 梳理一次在售商品清单，无凭证的货源清出。

**每季度自查**

- 组织全员合规培训，用本店与行业的真实违规案例做教材。

- 更新违禁词库与合规话术库。

- 全店素材按原创、已授权、待替换三类重新标注。

- 复查一次供应商资质与样品抽检记录。

- 更新合规检查表版本，把新踩过的坑加进去。

- 做一次全店合规复核，由负责人带队并留档。

**分步实操**

1．打开后台“违规记录”，确认没有待处理条目。

2．打开“商品体检”，确认所有在售商品为绿色。

3．导出一份近30天成交明细，看有没有异常价格与异常集中订单。

4．打开客服后台，抽查聊天记录与回复率数据。

5．打开资质台账，核对证照与授权书的有效期。

6．按上面四档清单逐条打勾，把不合格项写成整改任务。

7．把本次自查表归档，注明日期与执行人。

**正确做法**

- 把自查表挂在工位上，用纸质版打勾，不要只存在电脑里。手写打勾比点开文件更容易坚持。

- 给每个检查项指定责任岗位。运营管类目、标题、素材、违禁词；客服管回复率、售后、聊天记录；美工管素材来源与授权；老板管资质、税务、申诉。

- 每档自查都要有固定的时间点。每日自查在开店后一小时内完成，每周自查固定在周五下班前，每月自查固定在1号，每季度自查固定在季末最后一周。

- 不符合项当天就转成整改任务，写清责任人与截止时间。

- 记录本身要能被出示。整改记录、自查记录、凭证归档，都是申诉和资质审核时的材料。

**常见错误**

错误示范：清单打出来贴在墙上，从来没人翻。

错在哪：清单如果没绑到具体岗位和时间点，就只是一张纸。要绑定到晨会流程里，每天过一遍。

错误示范：自查发现不合格，先上架再说，等卖掉一批再改。

错在哪：带病上架产生的每一笔销售都会进入处罚计算基数，尤其是涉及售假和知产侵权时，销售额就是罚款基数。

错误示范：自查表全部打勾，但实际一项没查。

错在哪：自查的价值在于发现问题并改掉。全部打勾等于把这张表变成自我安慰，下一次踩坑时你连数据都没有。

> **【规则提示·2026规则修正】** 平台词库、活动门槛、处罚力度每年都在调整，凭记忆做合规必然漏项。把规则核对做成固定动作，比记住具体条款更可靠，具体门槛与罚则以商家后台实时提示为准。

**实操检查清单**

- [ ] 每个检查项指定责任岗位与固定执行时间

- [ ] 每日自查在开店后1小时内完成

- [ ] 每周自查固定在周五下班前完成

- [ ] 每月自查固定在1号，核对资质与规则更新

- [ ] 每季度做一次全员合规培训与全店复核

- [ ] 不合格项当天转为整改任务并写明截止时间

- [ ] 全部自查表归档留痕并注明执行人
