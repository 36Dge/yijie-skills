# 拼多多业务工作流

先确认店铺、类目、商品与经营阶段。比价、活动和冷启动建议先核实际规格、到手价、成本与当前后台准入条件；不把低价或平台补贴当成商家净收入。多多进宝等内容推广需明确结算与佣金，当前不自动调用服务。

投放先确认成交出价/投产比/净成交等实际后台模式与计费定义，原资料描述不证明当前规则；归因成交额、退款/未发货处理及消耗必须相同口径。不要把设定ROI当作实际ROI。

店铺领航员、消费者服务体验分、店铺综合体验星级三体系分别记录：体系名、量表范围、单位、观测日期、原始值、来源。百分位不是分数/星级，三者不合成健康分或默认权重。用户只说“体验分”必须先明确体系。物流先核承诺发货/揽收/实际轨迹，客服先核咨询与回复口径；不采用旧资料金额/时限作未经核实的当前处罚。
