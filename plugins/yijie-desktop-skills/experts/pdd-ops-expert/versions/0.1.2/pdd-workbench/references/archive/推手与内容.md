# 推手与内容　多多进宝CPS、直播、短视频怎么落地

**本模块导语**：多多进宝、直播、短视频是三条增量通道，共同的底线只有一条：成交必须留在平台内，销量必须来自真实订单。本模块把多多进宝的佣金结构与推手筛选、直播的分时段脚本、短视频的脚本结构与投流配合、达人合作的结算规则一件件拆开，并给每一步配上算账方式，让你在投之前就知道划不划算。

本模块讲三件事：用多多进宝让推手帮你卖货，按成交付佣金；用直播把流量变成当场成交；用短视频把人从内容场带进店铺。这三件事不做，你的店只能靠付费推广和自然流量两条腿走路，起量慢、成本高。看完你能自己设佣金、自己搭直播货盘、自己写视频脚本、自己看数据判断该续还是该停。

## 01 多多进宝是什么：推手帮你卖货，卖出去了才付钱

典型状态：你听同行说多多进宝能破零、能冲量，但打开后台看到要设佣金、要配优惠券，不知道这一步该不该走。

> **问**：多多进宝和全站推广、全店托管到底差在哪？

第一，付费方式不同。全站推广、全店托管是先花钱买曝光，点一次扣一次，成交不成交都扣。多多进宝是按成交付佣金的CPS模式，没有成交就不产生佣金。

第二，流量来源不同。付费推广买的是站内流量，多多进宝带来的是站外和私域流量，这些人你在站内抢不到。

第三，适用阶段不同。付费推广适合链接已经入池、有效率数据以后放大。多多进宝适合新品破零、清库存、冲销量基础、大促前攒人气。

> **问**：什么品适合做多多进宝？

三个条件满足两个就能做：单品毛利能覆盖两成左右的佣金；商品一看就懂，推手不用讲三分钟；有复购或者组合装空间，推手愿意反复带。

反过来，毛利不足三成的极致低价品、要强讲解的高客单品、售后极重的品，做多多进宝就是白付佣金。

**分步实操**

1．打开商家后台，进入“营销”菜单，找到“多多进宝”。

2．进“推手广场”，按自己类目翻同类商品，记下同行公用佣金的比例区间。

3．挑1—3条主推链接做CPS，不要全店一起开。

4．先按通用佣金挂出去，跑7天看有没有推手接单。

5．7天零单，再考虑加券或者提佣金，一次只动一个变量。

**正确做法**

- 把多多进宝当增量渠道，不当救命渠道。它承接的是你站内拿不到的站外流量。

- 优先给利润高、卖点简单、主图和视频已经做齐的链接开佣金。

- 佣金算进成本账，不要到月底看账单才发现吃掉利润。

**常见错误**

错误示范：全店几十条链接一股脑设两成佣金，等着推手自己挑。

错在哪：推手只挑好卖的挑，剩下链接佣金白挂，还容易被低价冲乱整店价格体系。

错误示范：找熟人下单再私下返钱，当成破零手段。

错在哪：这是虚假交易，系统按同设备、同地址、异常轨迹识别，查到清销量、扣分限流，严重时封店。

> **【规则提示·2026规则修正】** 原找熟人下单再返钱的破零做法已属虚假交易违规。依据：平台对虚假交易实行系统识别与关联店连坐。合规替代：在多多进宝设真实佣金10%—20%，让真实推手带真实订单，3天出10—20单真实订单就够完成破零。

**实操检查清单**

- [ ] 确认店铺保证金与类目资质齐全

- [ ] 只选1—3条主推链接开佣金，不做全店

- [ ] 算清单品毛利能否覆盖预期佣金比例

- [ ] 记录同类目佣金区间作为定价参照

- [ ] 在后台找到多多进宝入口并收藏

- [ ] 设定7天观察期，期间不反复改佣金

- [ ] 把正常推手单与异常单分开登记

## 02 开通与搭建：把第一个多多进宝推广计划跑起来

典型状态：后台进了多多进宝，看到“推广计划”“商品佣金”“推手广场”几个入口，不知道先点哪个，也不知道券该发多大。

> **问**：开通多多进宝要额外花钱吗？

不需要开通费。店铺正常经营、没有严重违规、保证金已缴就能用，具体门槛以后台实时提示为准。你付出的只有成交后的佣金和优惠券让利。

> **问**：一个推广计划要填哪几项？

商品、佣金比例、优惠券、推广时间、每日库存上限，五样齐了计划才算完整。想让某个推手专门帮你带，再加一项专属佣金。

**分步实操**

1．走“商家后台→营销→多多进宝→推广计划→新建计划”。

2．选商品：从可推广商品里勾选，第一轮不超过5条。

3．填佣金比例：先按类目通用值填，多数类目从10%—20%起步，以后台实时提示为准。

4．配券：新建“进宝专享券”，面额3—10元，门槛设在券后价之上，有效期7—15天。

5．算发行量：按日均推手单量乘以15天，宁少勿多，领完再补。

6．设推广时间与每日库存上限，防止一夜爆单发不出货。

7．提交后回“推手广场”搜自己商品，确认已经能搜到。

**正确做法**

- 券和佣金一起设计。先定券后到手价，再倒推佣金比例，顺序反了必亏。

- 新链接用小额券加中等佣金；有销量基础的链接逐步降佣金。

- 每天固定时间看一次进宝订单，陌生地址的批量单先核实再发货。

**常见错误**

错误示范：设满59元减5元的券，可商品到手价只有39.9元。

错在哪：券根本领不了也用不上，等于没配券，推手拿着链接也推不动。

错误示范：为了快点起量，第一次就把佣金提到三成。

错在哪：高佣金换来的量在降佣当天就断，链接白冲一波，还带进来一批只等低价的人。

> **【规则提示·2026规则修正】** 原把标价虚高到99元再发60元大额券的做法，属虚构原价、虚假优惠折扣。依据：平台按真实成交价与历史价核查。合规替代：用真实吊牌价配真实券，券后价就是你想卖的目标价。

**实操检查清单**

- [ ] 新建计划时五要素填齐不空缺

- [ ] 券门槛设在实际到手价之上

- [ ] 券有效期控制在7—15天

- [ ] 每日库存上限按实际备货填

- [ ] 计划里的商品有主图和主图视频

- [ ] 提交后到推手广场搜一次确认可见

- [ ] 建立进宝订单每日核对记录

## 03 佣金怎么定：通用佣金、专属佣金、团长服务费

典型状态：你知道要设佣金，但设低了没推手接，设高了又怕亏，全靠感觉拍。

> **问**：通用佣金和专属佣金有什么区别？

通用佣金对所有推手生效，作用是铺量。专属佣金只对指定推手生效，作用是拉头部，可以比通用佣金高2—5个百分点。先用通用佣金铺开，看到有人稳定出单，再单独谈专属。

> **问**：招商团长的服务费怎么算？

团长手里有一批推手，能在短时间内把量拉起来。他在佣金之外还要收服务费，常见按成交额5%—10%，也有按单收固定金额的。谈的时候必须问清一句：服务费是含在佣金里，还是另加。

**分步实操**

1．先算保本佣金率：保本佣金率等于（到手价减货品成本减运费减包装人工减平台技术服务费）除以到手价。

2．通用佣金取保本佣金率的六成到七成。

3．专属佣金取保本佣金率的八成五到九成，并约定独家期限，比如15天。

4．团长合作先看对方历史数据，再谈服务费，服务费与佣金合并算总成本。

5．合作首月按周结算观察，数据达标再转月结。

**算例**

到手价39.9元，货品成本16元，快递加快递袋4.5元，人工1.5元，平台技术服务费按0.6%算0.24元。

可分配空间＝39.9－16－4.5－1.5－0.24＝17.66元。

保本佣金率＝17.66÷39.9＝44.3%。也就是说佣金提到44.3%才不赚钱。

若要求单件净利不低于4元，佣金上限＝（17.66－4）÷39.9＝34.2%。

结论：通用佣金设20%，支出7.98元，单件剩9.68元；专属佣金设28%，支出11.17元，单件剩6.49元；设到35%就只剩3.44元，再叠加退货必亏。

**正确做法**

- 佣金比例跟着毛利走，不跟着同行走。同行敢设三成是因为他成本低。

- 专属佣金写清期限与量级要求，比如“15天内不少于50单”。

- 团长服务费单独立账，算进总成本再决定接不接。

**常见错误**

错误示范：看同行挂25%就跟着挂25%，没算自己成本。

错在哪：同行成本可能是你的六成，同样的佣金他只是少赚，你是亏。

错误示范：口头答应团长“佣金两成再加一成服务费”，没写清服务费基数是佣金还是成交额。

错在哪：两个算法差出一倍的钱，做一千单就是几千元的差距。

**实操检查清单**

- [ ] 算清本品的保本佣金率

- [ ] 通用佣金取保本线的六到七成

- [ ] 专属佣金取保本线的八五到九成并写期限

- [ ] 团长服务费写明计算基数

- [ ] 佣金加服务费合计不超过保本线

- [ ] 每周核对一次佣金支出与单量

- [ ] 高佣链接设置每日库存上限

## 04 佣金加优惠券叠加，真实到手利润到底剩多少

典型状态：佣金设了，券也发了一款链接跑起来，订单不少，月底一算账没赚钱，不知道钱漏在哪。

> **问**：为什么券和佣金一起上就容易亏？

因为券先砍基数，佣金再按砍完的基数砍一刀，两刀都砍在同一个价格上。你感觉只让了6元券，实际让掉的是6元券加上按券后价计算的佣金。

> **问**：怎么算才准？

分三层算：先算券后到手价，再扣佣金、平台技术服务费、货品成本、运费、人工得到单件利润，最后扣退货分摊得到真实净利。

**分步实操**

1．打开商品成本表，把货品成本、快递加包材、打包人工三项填准，不要凭印象估。

2．算出券后到手价：标价减券额，再减可能叠加的平台优惠。

3．按佣金比例算佣金支出：券后到手价乘以佣金比例。

4．逐项相减：券后到手价减佣金减平台技术服务费减货品成本减运费包材减人工。

5．结果再减退货分摊：退货率乘以每单退货净损失。

6．真实净利率低于15%的，先提价或者缩券，再决定要不要继续投佣金。

**算例一（安全线内的链接）**

标价45.9元，进宝专享券6元，买家实付39.9元。

佣金按20%算：39.9×20%＝7.98元。

平台技术服务费按0.6%算：39.9×0.6%＝0.24元。

货品成本16元，快递加包材4.5元，打包人工1.5元。

单件利润＝39.9－7.98－0.24－16－4.5－1.5＝9.68元。

再扣退货：退货率12%，每单退货净损失按4元算（逆向运费3元加包材损耗1元），分摊到每单成交＝4×12%＝0.48元。

真实净利＝9.68－0.48＝9.2元，净利率＝9.2÷39.9＝23.1%。

这个链接可以继续加推手预算。

**算例二（亏本的链接）**

标价35.9元，券8元，买家实付27.9元。

佣金按25%算：27.9×25%＝6.98元。

平台技术服务费0.6%：27.9×0.6%＝0.17元。

货品成本16元，快递加包材4.5元，人工1.5元。

单件利润＝27.9－6.98－0.17－16－4.5－1.5＝－1.25元。

每单亏1.25元，做1000单亏1250元。

问题不在佣金高，在于券后价被压到成本线附近，佣金基数小了但成本一分没少。

**算例三（叠加平台券后的击穿）**

买家手里还有一张平台新人券5元，最终实付22.9元。

佣金25%＝5.73元，平台费0.14元，成本16元，运费包材4.5元，人工1.5元。

单件＝22.9－5.73－0.14－16－4.5－1.5＝－4.97元。

每单亏近5元，全靠你贴。

所以设券时必须检查两件事：券能不能与平台券叠加，每人限领几张。

**正确做法**

- 先定目标净利率（建议不低于15%），再反推券额与佣金上限。

- 券的面额按“到手价减成本减运费减人工再乘30%”这个量级控制，不要超过。

- 新客单、叠加单每天抽查几单，看真实到手价有没有击穿成本。

**常见错误**

错误示范：券发10元、佣金挂25%，两样一起上，想着“量大就赚”。

错在哪：这不是薄利，是负利，单量越大亏得越多，还拉低了链接的成交价基准。

错误示范：券不设领取上限，也不看是否与其他优惠叠加。

错在哪：职业薅券的人一天领几百张，到手价击穿成本，你还要照常发货。

**实操检查清单**

- [ ] 每个进宝链接都做一遍三层算账

- [ ] 目标净利率写死，低于就不开佣金

- [ ] 券面额不超过到手价的三成

- [ ] 券设置每人限领1张

- [ ] 检查券是否与其他优惠叠加

- [ ] 每天抽查3单看真实到手价

- [ ] 退货率超过15%的链接先修品质再谈推广

## 05 怎么找推手、团长、社群：三个入口和四条筛选线

典型状态：佣金挂上去，等了半个月一个推手都没来，你怀疑是不是自己没找到“渠道”。

> **问**：推手从哪里来？

三个入口。第一个是多多进宝的推手广场，发布招募信息，按类目、粉丝量、带货数据筛。第二个是招商团长，团长手里握着一批推手，能一次对接多个人。第三个是社群和站外内容主，比如宝妈群群主、社区团购团长、短视频和图文内容主。

> **问**：怎么判断一个推手能不能合作？

四条线，缺一条就要慎重。第一看类目匹配，他最近带过同品类的货。第二看真实成交数据，不要截图，要能对上你后台的订单。第三看粉丝价格带，粉丝习惯买9.9元的人群带不动你39.9元的品。第四看退款率，退款率高的推手粉丝冲动下单多，最后麻烦全是你的。

**分步实操**

1．后台“多多进宝→推手广场→发布招募”，写清类目、佣金、券、卖点、可带的库存。

2．按类目筛推手，把近30天有成交的挑出来，列成一张表。

3．给每个推手发招募消息，模板：“本品类目××，到手价××元，通用佣金××%，专属可谈××%，样品可寄，主图和视频素材已备齐，7天内可配合出内容。”

4．按体量分三级：头部冲量、腰部稳种草、尾部铺量，预算按5:3:2分。

5．先给腰部试单，数据达标再往上加。

6．达成合作的统一在平台内走佣金，不做任何私下结算。

**正确做法**

- 招募消息必须写清佣金和到手价。推手第一眼看的就是这两个数。

- 优先挑腰部推手。头部要价高、档期难排；尾部单量小但配合度好、成本低。

- 同一个推手先给一条链接试，不一次给全店。

**常见错误**

错误示范：招募消息只写“高佣金招募，详情私聊”。

错在哪：推手看不到到手价和佣金，直接划过去，一天也招不到人。

错误示范：把全部预算压在粉丝量最大的推手上。

错在哪：粉丝量不等于匹配度，一百万泛粉可能不如五万精准粉出单多。

> **【规则提示·2026规则修正】** 原通过私聊达成“包销多少单、不够我补”的做法，本质是虚假交易约定。依据：平台对虚假交易连带处罚商家。合规替代：所有合作按真实成交计佣，量级目标写“不少于”而不是“包到”，不承诺保底销量。

**实操检查清单**

- [ ] 发布一条写清佣金与到手价的招募信息

- [ ] 建推手登记表，记录类目与近期成交

- [ ] 按头部、腰部、尾部分三级并分配预算

- [ ] 先给腰部推手一条链接试单

- [ ] 所有结算只走平台内佣金

- [ ] 拒绝任何包销与返现约定

- [ ] 每周更新一次推手表

## 06 结算、寄样与数据复盘：把推手当渠道管，不当人情处

典型状态：推手催佣金，你不知道钱什么时候扣；样品寄出去十几份，一半没动静。

> **问**：佣金什么时候结、怎么对账？

佣金按成交产生，订单确认收货后进入结算流程，发生退款的订单佣金不结或者追回，具体口径以后台实时提示为准。对账走“多多进宝→推广数据→佣金明细”，每周固定一天拉一次，与财务台账对齐。

> **问**：样品要不要寄、怎么寄才不被白嫖？

要寄，但要有条件。寄样是合作的前置动作，不寄样推手不敢推。控制三点：寄样前先要脚本或拍摄思路；同一推手第一次只寄1份；约定7天内出内容，两周无产出不再寄第二批。

**分步实操**

1．建寄样登记表，字段固定：推手名、粉丝量、寄样日期、快递单号、约定出内容日期、实际单量、退款单量。

2．寄样前收对方的拍摄思路或选品理由，一句话也行。

3．寄出后第3天回访一次，第7天看内容是否发布。

4．佣金对账按周做，把单量、佣金支出、退款单列在一张表里。

5．每两周评一次：优质推手签专属佣金续约，不出单的停寄样。

6．把优质推手沉淀进推手库，下次新品优先找他。

**算例（一批寄样的真实账）**

寄样5份，每份货品成本12元，合计60元。

30天内产出30单，单笔到手价39.9元，成交额30×39.9＝1197元。

佣金20%：1197×20%＝239.4元。

货品成本：30×16＝480元。

快递与包材：30×4.5＝135元。

这批推手带来的毛利＝1197－239.4－480－135－60＝282.6元。

投产比＝282.6÷60＝4.7。这批值得加预算再寄10份。

如果同样寄5份只出6单：成交额239.4元，佣金47.9元，货品96元，运费27元，毛利＝239.4－47.9－96－27－60＝8.5元，基本白干，这批推手要换。

**正确做法**

- 佣金对账先看退款单，再看成交单，别只看成交额。

- 寄样对象分两档：能出内容的和只会转发的，后一档少寄。

- 推手库记录ROI，按ROI排序，下次优先合作。

**常见错误**

错误示范：谁要样品都寄，一个月寄出去几十份。

错在哪：样品成本按每份12元算，30份就是360元，等于白送，还没换来一条内容。

错误示范：只对成交额，不看退款。

错在哪：退款的订单佣金要追回，货还要退回来，一来一回你亏两次运费，账却记成赚钱。

**实操检查清单**

- [ ] 建立含8个字段的寄样登记表

- [ ] 寄样前先收拍摄思路

- [ ] 同一推手首次只寄1份

- [ ] 约定7天内出内容并回访

- [ ] 每周拉一次佣金明细对账

- [ ] 退款单单独统计

- [ ] 按投产比给推手排序并沉淀推手库

## 07 用CPS做合规破零：正确用法和风险控制

典型状态：新品上架三天没一单，你心里着急，想动点“办法”又怕出事。

> **问**：新品破零为什么不能用刷单？

刷单在拼多多属于虚假交易，系统按同设备、同地址、异常轨迹识别，查到清销量、扣分限流，严重时封店，还会连坐关联店铺。你为了十几个基础销量押上整店，不值。

> **问**：用CPS破零该做到什么程度？

目标不是销量数字，是让系统判定这条链接有人买、有转化。上架3天内出10—20单真实订单就够，超过这个量说明你在花钱买数字，不是买权重。

**分步实操**

1．上架当天在多多进宝建计划，设佣金10%—20%，配一张3—5元券。

2．备齐主图、主图视频、详情页和3条短视频素材，一起给推手。

3．主动@推手广场里匹配的推手，一人一条链接。

4．第2—3天看订单，重点看收货地址是否分散、下单时间是否自然。

5．第4天看评价和退款，出现集中退款立刻停计划并留证。

6．第7天把佣金降到常规值，转由自然流量和付费推广接力。

**时间节奏**

第1天：建计划、配券、发招募。

第2—3天：出10—20单，只看真实度，不看数量。

第4天：查退款率与评价内容，异常单报平台。

第7天：佣金降温，链接转常态运营。

第14天：复盘这批订单带来的自然访客有没有起来。

**正确做法**

- 破零期间佣金可以给高一点，但券要小额，避免拉低价格基准。

- 破零目标是“有效订单”，不是“销量榜”。

- 破零完成后立刻降佣金，避免长期高佣依赖。

**常见错误**

错误示范：一次性把破零单量做到200单，冲个销量好看。

错在哪：花的是真金白银，订单里只要有一批同一地址的，整批被判定异常，白花钱还惹处罚。

错误示范：破零单的收货地址全是你认识的几个地方。

错在哪：系统直接识别为异常轨迹，判定虚假交易，前功尽弃。

> **【规则提示·2026规则修正】** 原委托第三方代写评价、同步同行评价来补基础评价的做法，属虚假评价治理范围。依据：平台对虚假评价清理并扣分。合规替代：用包裹卡引导真实晒图，话术写“晒图领券”“晒图参与抽奖”，不写“好评返现”。

**实操检查清单**

- [ ] 上架当天就建好多多进宝计划

- [ ] 佣金设10%—20%，券不超过5元

- [ ] 素材备齐再触达推手

- [ ] 破零目标定在10—20单

- [ ] 每天检查订单地址集中度

- [ ] 出现集中退款立刻停计划并留证

- [ ] 第7天把佣金降到常规值

## 08 推手渠道的四个坑：刷单型、假流量、薅券党、亏本叠加

典型状态：有推手主动找上门，说能帮你“一场带几百单”，条件是先给返点、先私下打款。

> **问**：怎么一眼认出刷单型推手？

三个特征同时出现就要停。一是承诺包量，比如“保证200单，不够我补”。二是结算要私下，要求你先返现、先打款。三是数据形态怪，订单集中在半小时内、地址集中、客单价整齐。这种人图的不是佣金，是返点。

> **问**：假流量、薅券党怎么防？

假流量只给播放量截图、不给成交。防法是只认后台真实订单，不认任何截图。

薅券党专挑券后最低价下单，或者买完就退。防法是券设每人限领1张、SKU价格真实一致、短周期内同地址多次下单直接标记异常。

**分步实操**

1．合作前要求对方提供近期同类目真实成交数据，能与后台订单对得上的才算。

2．拒绝一切私下转账，所有佣金走平台结算。

3．单量出现异常时，导出订单明细，按收货地址前三位、下单时段、客单价三项查。

4．发现同一地址或同一收货人反复下单，停止发货并留证申诉。

5．券统一设每人限领1张，不与其他优惠叠加的选项一并勾选。

6．把所有异常推手拉入黑名单，记录原因。

**佣金与券叠加亏本的自查公式**

佣金上限＝（券后到手价－货品成本－运费包材－人工－平台技术服务费－目标净利）÷券后到手价。

代入：券后到手价39.9元，货品成本16元，运费包材4.5元，人工1.5元，平台技术服务费0.24元，目标净利4元。

佣金上限＝（39.9－16－4.5－1.5－0.24－4）÷39.9＝13.66÷39.9＝34.2%。

算出来低于当前佣金比例，就必须先提价、扩毛利，或者降佣金，没有第三条路。

**正确做法**

- 只跟愿意在平台内结算的推手合作。

- 异常单一律先核实后发货，宁可少发一单，不要赔一店权重。

- 每批合作都算出真实净利，不赚钱的渠道直接砍。

**常见错误**

错误示范：被“包销200单”打动，先打了3000元返点。

错在哪：这3000元买的是虚假交易，订单会被清，钱要不回来，店铺还要被罚。

错误示范：券叠加平台优惠后到手价击穿成本，还按原计划发货。

错在哪：每单亏钱，单量越大亏越多，等于替平台和买家买单。

> **【规则提示·2026规则修正】** 原靠返现、私下返点买销量的做法已属虚假交易与佣金欺诈。依据：平台对虚假交易与异常结算链条双向核查。合规替代：用真实佣金加真实券做CPS，异常订单主动举证上报，把渠道健康度当成经营指标每周看。

**实操检查清单**

- [ ] 合作前核验推手真实成交数据

- [ ] 全部佣金走平台结算

- [ ] 每单用佣金上限公式自查

- [ ] 券设每人限领1张

- [ ] 异常地址与异常时段订单单独排查

- [ ] 建立异常推手黑名单

- [ ] 每周看一次渠道真实净利

## 09 直播开通、直播间权重与流量来源

典型状态：你开了两场直播，一场进来十几个人，说三句话就没人，怀疑直播不适合自己。

> **问**：开通直播要什么条件？

店铺完成实名认证、资质齐全、保证金已缴、没有严重违规，就能在后台申请开播权限，部分类目（食品、化妆品、3C等）要补类目资质，具体门槛以后台实时提示为准。路径走“商家后台→多多直播”，也可以用多多直播APP开播。

> **问**：直播间为什么没人？权重是怎么算的？

系统看六个信号：平均停留时长、互动率、商品点击率、成交转化率、成交额、退款率，再叠加违规记录和开播稳定性。停留短、互动零、点击低，系统就判定你的直播间留不住人，下一场给的人更少，形成负循环。

**分步实操**

1．申请开播权限，补齐类目资质，绑定主播实名。

2．把开播时间固定下来，比如每晚19:30—22:30，连续播14天不间断。

3．开播前2小时发一条短视频预热，视频中讲清今晚有什么福利。

4．开播后每10分钟报一次“在线人数加福利”，用抽奖和福袋拉停留。

5．每个品讲解控制在5—8分钟，讲完立刻切下一个，别停在一个品上。

6．下播后看停留时长与商品点击率，第二天调整开场话术。

**流量来源五路**

一路是直播广场与推荐位，靠停留与转化换。

二路是关注粉丝的召回，开播通知会推给粉丝。

三路是短视频引流，开播前发的视频带来的人最精准。

四路是店铺页、商品详情页的直播入口。

五路是付费投流，用来在人多的时候把精准人群放大。

**判断标准**

第一场不要看成交额，看三个数：平均在线人数能不能稳住20人以上，平均停留能不能到60秒以上，商品点击率能不能到10%以上。三个都不到，先改话术和场景，别急着加投流。

**正确做法**

- 用固定时段养粉丝习惯，比随机开播强得多。

- 开场5分钟只做一件事：让进来的人留下来。

- 直播间画面要亮、要稳、要能看清产品，画质和服务感直接影响停留。

**常见错误**

错误示范：想起来就播，一周播一次，一次两小时。

错在哪：权重需要连续开播累积，断播一次等于重新开始，永远在冷启动。

错误示范：开播三分钟就开始催单，人还没留下来。

错在哪：观众停留不到30秒就划走，系统判定内容差，后续不给流量。

**实操检查清单**

- [ ] 完成开播权限申请与资质补齐

- [ ] 固定开播时段并连播14天

- [ ] 开播前2小时发预热短视频

- [ ] 每10分钟做一次互动动作

- [ ] 单品讲解控制在5—8分钟

- [ ] 下播即看停留与点击率

- [ ] 首场不投流，先把内容跑顺

## 10 直播货盘怎么搭：引流款、主推款、利润款的比例

典型状态：你把全店商品都搬到直播间，一件一件讲，讲了三小时没成交几单。

> **问**：一场直播要上几个品、怎么分角色？

一场3小时的直播，上4—5个品就够，按角色分三类。

引流款1个，占货盘两成，作用是拉停留和拉点击，价格要低到让人愿意停下。

主推款2个，占货盘一半以上，是成交额主力，毛利控制在25%—35%。

利润款1—2个，占货盘三成，毛利要在40%以上，用来承接被主推款打动的高意向人群。

> **问**：库存要怎么备？

引流款备到目标单量的1.5倍，主推款备到预估单量的2倍。备货不足导致中途断货，直播间直接冷场，比少准备几个品损失大得多。

**分步实操**

1．开播前一天列货盘表：品名、角色、直播价、成本、毛利、库存、讲解顺序。

2．按“引流款→主推款1→主推款2→利润款→返场主推款”排顺序。

3．每个品设一个专属福利，只在直播时段生效，福利真实可兑。

4．主推款安排两轮循环，第一轮讲清卖点，第二轮直接逼单。

5．直播中每30分钟核对一次库存，接近安全线立刻换下一个品。

6．下播后统计每个品的转化率，转化高的下场上到前半场。

**算例（一场3小时带货的当日账）**

引流款：直播价9.9元，成本7元，快递4.5元，每单亏1.6元。发100单，亏160元。这160元当买停留的推广费。

主推款：直播价39.9元，成本16元，快递加包材4.5元，人工1.5元，平台技术服务费0.24元。单件净利＝39.9－16－4.5－1.5－0.24＝17.66元。出150单，净利2649元。

利润款：直播价69.9元，成本28元，快递5元，人工1.5元，平台技术服务费0.42元。单件净利＝69.9－28－5－1.5－0.42＝34.98元。出50单，净利1749元。

当日成交额＝990＋5985＋3495＝10470元。

当日净利＝2649＋1749－160＝4238元，净利率约40%。

如果这场投流花了900元，净利变成3338元，仍然赚钱。

如果主推款只出40单、利润款只出8单：净利＝40×17.66＋8×34.98－160＝706.4＋279.8－160＝826.2元，再扣900元投流就是亏损。这是货盘配比失衡的典型信号。

**正确做法**

- 引流款是门票，别指望它赚钱；利润款是收钱的，讲解时间要留够。

- 主推款只放两个，多了讲不透，观众记不住。

- 全场只有一个价格逻辑，直播价与店铺活动价保持一致。

**常见错误**

错误示范：整场只推最贵的利润款，指望一单顶十单。

错在哪：观众停下来看到价格就走了，停留时长崩掉，后面系统不再给流量。

错误示范：引流款备货不足，讲完刚上链接就卖空。

错在哪：评论区全是“没抢到”，情绪直接转负，主推款也没人看。

> **【规则提示·2026规则修正】** 原用9.9元超低价SKU挂在链接里充当诱饵、实际主推高价款的做法，属低价引流与价格陷阱治理范围。依据：平台按SKU真实价格与到手价核查一致性。合规替代：引流款单独建真实链接，真实库存、真实可发货，直播价与商品页价一致。

**实操检查清单**

- [ ] 开播前列出含角色与毛利的货盘表

- [ ] 引流款库存备到目标单量1.5倍

- [ ] 主推款固定两个并安排两轮讲解

- [ ] 利润款毛利不低于40%

- [ ] 每30分钟核对一次库存

- [ ] 直播价与店铺活动价保持一致

- [ ] 下播统计单品转化率并按结果调整顺序

## 11 直播间憋单、话术与节奏的基础框架

典型状态：你在直播间反复说“马上上链接”，人还是留不住，一上链接就掉人。

> **问**：憋单到底是什么，怎么才算合规？

憋单的本质是用真实的稀缺换停留时间：限量、限时、限人。合规的底线有两条——库存和倒计时必须是真的，价格必须是真的。虚构“只剩3件”实际有1000件，或者编一个“原价199今天39”，都属于虚假宣传和虚构原价。

> **问**：一场直播的话术按什么顺序走？

五段循环：留人、提问、讲卖点、做演示、给福利逼单。一个品讲完，换个品再走一遍，全场合计循环三到四次。

**分步实操**

1．开场0—5分钟只做留人：报今天有几个福利品、说清几点上、让新进来的人先点关注。

2．5—15分钟上引流款，用最低价把人留住，同时拉商品点击。

3．15—45分钟进主推款第一轮：先提问戳痛点，再讲三点卖点，然后当场演示。

4．45—60分钟上利润款，只讲两类人：有升级需求的、买过主推款的。

5．60分钟以后返场主推款，报库存、报倒计时、报上车人数，限量50单，卖完切品。

6．每一轮结尾用同一句逼单话术，反复三遍，不换词。

**话术模板**

留人：“刚进来的朋友先点个关注，今天第一个福利品五分钟后就上，价格是全天最低。”

提问：“你是不是也遇到过买回去用两天就坏、退货还嫌麻烦？”

演示：“我现在当着镜头做一遍，大家看清楚，正常使用就是这个效果。”

逼单：“这批只有50单，卖完就恢复原价，需要的现在点下面的商品卡。”

**时间节奏**

0—5分钟：留人，不卖货。

5—15分钟：引流款上场，拉停留与点击。

15—45分钟：主推款两轮循环。

45—60分钟：利润款承接。

60分钟以后：返场逼单，收尾预告下一场。

**正确做法**

- 一个品只讲三个卖点，讲多了观众记不住。

- 演示动作要占讲解时间的三分之一，看得见才信。

- 话术写下来贴在镜头旁边，不要靠临场发挥。

**常见错误**

错误示范：全程“最后三分钟”“马上涨价”，说了两小时。

错在哪：观众发现时间一直在延后，信任清零，后面说什么都不信。

错误示范：讲品时只念参数，不演示、不回答评论。

错在哪：互动率接近零，系统判定直播间质量差，下一场流量会明显缩水。

> **【规则提示·2026规则修正】** 原直播口播“原价199元，今天只要39元”的对比话术，若199元不是真实吊牌价或历史成交价，属虚构原价、虚假优惠折扣。依据：平台按真实价格与历史价核查。合规替代：口播改为“日常到手价45.9元，今天直播间到手价39.9元”，两个价格都可查。

**实操检查清单**

- [ ] 话术五段写成文字稿贴在镜头旁

- [ ] 开场5分钟只留人不卖货

- [ ] 每个品只讲三个卖点

- [ ] 每个品预留演示环节

- [ ] 限量与倒计时全部真实

- [ ] 逼单话术全场统一不换词

- [ ] 下播后回看一段录像找话术漏洞

## 12 直播数据复盘：下播后先看这六个数

典型状态：播了半个月，每场都累，但说不清到底哪场好、好在哪。

> **问**：直播复盘到底看哪几个数？

六个：平均在线人数、平均停留时长、互动率、商品点击率、支付转化率、UV价值。UV价值等于成交额除以观看人数，这个数决定这场直播赚不赚钱。

> **问**：数据不好该从哪里下手改？

按顺序排查：停留低于60秒是话术和场景问题；商品点击率低于10%是货盘或者讲解问题；支付转化率低于1.5%是价格力或者信任问题；UV价值低于1元，这场基本不赚钱，先别加投流。

**分步实操**

1．下播30分钟内打开直播数据后台，把六个数字抄进当天的复盘表。

2．和上一场比，不要和同行比，只和自己比。

3．找出掉得最多的那个数，从它对应的环节找原因。

4．第二天只改一个变量，比如只换开场话术，不要同时改三处。

5．连续三场数据一致向好，再考虑加投流放大。

6．把场均数据按周汇总，看趋势不看单场。

**算例（一场直播的盈亏判断）**

观看人数5000人，成交额7500元，UV价值＝7500÷5000＝1.5元。

客单价39.9元，成交188单。

货品成本188×16＝3008元。

快递与包材188×4.5＝846元。

打包人工188×1.5＝282元。

投流花费900元，场地与设备折旧300元。

净利润＝7500－3008－846－282－900－300＝2164元，净利率约28.9%。

这场值得加投流。

如果同一场只成交60单：成交额2394元，UV价值0.48元。货品成本960元，快递270元，人工90元。

净利润＝2394－960－270－90－900－300＝－126元，亏损。这时候加投流就是烧钱，要先改货盘和话术。

**正确做法**

- UV价值低于1元不加投流，先把转化修好。

- 复盘表固定字段，每场都填，不要凭印象。

- 一个变量一个变量改，改了三处就不知道是哪处起了作用。

**常见错误**

错误示范：只看成交额，不看停留和UV价值。

错在哪：成交额高可能是投流砸出来的，算完账才发现是亏的。

错误示范：数据不好就马上加大投流。

错在哪：转化没修好，投流只是把更贵的人带进来，亏损放大。

**实操检查清单**

- [ ] 下播30分钟内填完六项数据

- [ ] 只与上一场对比

- [ ] 定位掉得最多的那个指标

- [ ] 第二天只改一个变量

- [ ] UV价值低于1元时不加投流

- [ ] 连续三场向好才放大投入

- [ ] 每周汇总一次场均趋势

## 13 短视频：入口、内容形式和挂车逻辑

典型状态：你拍了几条视频发出去，播放量几百，没有一个人进店，很快就放弃了。

> **问**：拼多多的短视频有哪些入口？

四个：多多视频的内容场推荐位、店铺页的短视频模块、商品详情与主图位的商品短视频、直播切片。前两个带来的是站内内容流量，第三个直接服务转化，第四个是给直播引流的。

> **问**：视频怎么挂车才有人点？

三层一起做。第一层是视频挂商品卡，观众看完直接点。

第二层是评论区置顶引导，写清商品名和到手价。

第三层是口播埋搜索词，比如“搜××品牌××型号”，让人去搜索进店。

**内容形式四类**

痛点解决型：先说一个具体麻烦，再给解法，出单最稳。

场景演示型：把产品放进真实使用场景，适合非标品。

对比测评型：同价位两个选择摆在一起看差距，适合性价比商品。

幕后实拍型：拍工厂、拍仓库、拍打包，解决信任问题，适合客单价偏高的品。

**分步实操**

1．从四类形式里选两类先做，不贪多。

2．一次拍够5—8条素材，分两周发，保持节奏。

3．每条视频结尾统一挂商品卡，评论区置顶一句引导。

4．发布后48小时看三个数：播放量、完播率、商品点击率。

5．完播率到30%、点击率到5%的，加投流放大。

6．数据最差的方向直接停掉，把精力压在出数据的方向上。

**判断标准**

完播率低于20%是内容问题，先改前3秒。

完播率达标但点击率低于3%，是利益点没说清，改口播和字幕。

点击率达标但转化低，是落地页问题，回去改主图、价格和评价。

**正确做法**

- 视频中出镜的人、场景、产品必须真实，摆拍过度会被判描述不符。

- 视频中标注的价格与商品页到手价一致，不能视频一个价、进店另一个价。

- 一个账号只做一个方向，别今天卖锅明天卖袜子。

**常见错误**

错误示范：视频只拍产品转圈，没有任何人物和场景。

错在哪：观众没有理由看完，完播率上不去，系统不给二次推荐。

错误示范：视频中口播“加我微信发货更快”。

错在哪：属站外导流，视频会下架，账号还会被处置。

> **【规则提示·2026规则修正】** 原在视频描述或评论区留联系方式、二维码、引导去其他平台下单的做法，属站外导流。依据：平台对导流行为实行素材与账号双向稽查。合规替代：只在视频内挂商品卡，引导语写“点下方商品卡”或“搜店铺名进店”，复购引导用平台内的关注店铺与店铺会员。

**实操检查清单**

- [ ] 选定两个内容形式并坚持两周

- [ ] 一次拍够5—8条素材

- [ ] 每条视频都挂商品卡

- [ ] 评论区置顶一句引导

- [ ] 口播埋一个搜索词

- [ ] 48小时内看完播率与点击率

- [ ] 达标视频再加投流

## 14 主图视频和内容短视频：一个管转化，一个管进人

典型状态：你觉得视频做一条就够了，结果这条视频放在详情页没点击，发到内容场又没人看。

> **问**：主图视频和内容短视频到底差在哪？

主图视频是商品资产，它待在首图轮播第一位，任务是把点进来的人转化成下单的人。内容短视频是流量资产，它待在内容场，任务是把刷视频的人带进你的店铺。同一个镜头语言，两个完全不同的目标。

> **问**：主图视频的硬要求有哪些？

比例用1:1或者3:4，时长5—60秒（严口径按30秒以内做更稳），格式MP4或MOV，单文件不超过100MB，画质不低于720P。内容必须与商品一致，前3秒抓眼球，口播每句不超过15个字，结尾引导点击。不能出现联系方式、二维码、外链。

**分步实操**

1．先做主图视频。用1:1比例，拍产品核心卖点和真实使用效果，控制在30秒内。

2．上传到首图轮播第一位，因为第一位自动播放，权重最高。

3．同一批素材再剪三条内容短视频：一条讲痛点、一条讲对比、一条讲使用场景。

4．内容短视频用3:4或9:16，时长15—45秒，结尾挂商品卡。

5．主图视频看点击率和停留，内容短视频看完播率和进店人数，两套数据分开看。

6．每两周换一次主图视频，用数据决定留哪条。

**正确做法**

- 主图视频讲“这东西好在哪”，内容短视频讲“什么场景下你需要它”。

- 主图视频不能有花哨转场，前3秒必须出现产品。

- 内容短视频可以软一点、有情节一点，但价格必须与商品页一致。

**常见错误**

错误示范：把一条45秒的内容短视频直接当主图视频上传。

错在哪：内容视频前3秒往往在做铺垫，没有产品，主图位的停留直接掉，点击率反而比没有视频更低。

错误示范：主图视频中出现其他平台的水印或者店铺联系方式。

错在哪：素材会被驳回，链接曝光归零，不只是不展示那么简单。

**实操检查清单**

- [ ] 主图视频按1:1或3:4制作

- [ ] 主图视频时长控制在30秒内

- [ ] 主图视频放在轮播第一位

- [ ] 一条素材剪出三条内容短视频

- [ ] 内容短视频结尾都挂商品卡

- [ ] 两套数据分开统计

- [ ] 每两周依据数据更换一次主图视频

## 15 短视频脚本结构：前3秒、痛点、卖点、促单

典型状态：你写的脚本自己读着挺顺，发出去三秒就被人划走，播放量一直卡在几百。

> **问**：前3秒到底要放什么？

三种钩子任选一种，不要放片头和logo。

痛点式：直接拍出用户的麻烦，比如“洗碗布用三天就臭，你是不是也扔过一堆”。

反常识式：给一个和常识相反的结论，比如“这个锅千万别用大火，会让涂层提前报废”。

结果前置式：先把最终效果拍出来，比如“倒进去三秒，油污自己滑下来了”。

> **问**：一条30秒的脚本怎么排？

按五段排：0—3秒钩子，3—8秒放大痛点，8—20秒讲三个卖点，20—26秒做证明，26—30秒促单。

**分步实操**

1．先写30秒的口播稿，每句不超过15个字。

2．把最狠的一句话挪到第一句，哪怕逻辑上不顺。

3．每讲一个卖点配一个画面，画面里必须出现产品。

4．证明段用真实对比或者真实使用过程，不用特效。

5．促单段只报两件事：到手价和动作指令。

6．成片后自己看一遍，把音量关掉，只看画面能不能看懂在卖什么。

脚本示例一（厨房清洁品，28秒）

0—3秒：镜头怼近脏灶台，字幕“这层油，抹布擦不掉”。

3—8秒：手拿抹布反复擦，字幕“越擦越花，还伤手”。

8—20秒：喷上清洁剂，油污流下来，字幕“喷上停30秒”“一擦见底”“不伤釉面”。

20—26秒：同一块灶台左右对比，字幕“左边没用，右边用了”。

26—28秒：手举产品，字幕“今天到手价19.9元，点下方商品卡”。

脚本示例二（家居收纳品，30秒）

0—3秒：打开乱成一团的抽屉，字幕“你家抽屉是不是也这样”。

3—8秒：翻找东西找不到，字幕“每次找东西都要翻半天”。

8—20秒：放上分隔收纳盒，字幕“隔层可拆”“尺寸可调”“一盒分四格”。

20—26秒：合上抽屉再打开，一秒拿到目标物，字幕“拿取不用翻”。

26—30秒：字幕“到手价12.9元两个，评论区置顶有链接”。

脚本示例三（服饰类，26秒）

0—3秒：直接穿上身转身，字幕“158cm穿出165cm的效果”。

3—8秒：镜头切到普通版型的臃肿效果，字幕“普通版显胯宽”。

8—20秒：拉近拍面料和版型，字幕“垂感面料”“高腰线”“显腿长”。

20—26秒：字幕“直播间同款到手价49.9元，点下方商品卡”。

**正确做法**

- 每条视频只讲一个卖点，讲透比讲全重要。

- 关键句上字幕，且字幕只保留最短的词。

- 结尾一定有动作指令，不给指令就没人点。

**常见错误**

错误示范：前3秒放品牌logo加一段音乐。

错在哪：观众不知道你要讲什么，直接划走，完播率连20%都到不了。

错误示范：一条30秒视频塞八个卖点。

错在哪：观众一个都记不住，等于什么都没讲，转化自然是零。

> **【规则提示·2026规则修正】** 原用“醉佳”“鼒好”等谐音字规避极限词的做法已被识别。依据：平台新增谐音违规词识别能力。合规替代：脚本统一用“呵护”“舒适”“好用”这类可举证描述，上架前用后台词库工具过一遍。

**实操检查清单**

- [ ] 每条脚本前3秒写三种钩子选一种

- [ ] 口播每句不超过15字

- [ ] 只讲一个核心卖点

- [ ] 每个卖点配一个画面

- [ ] 证明段用真实画面

- [ ] 结尾有价格与动作指令

- [ ] 成片静音看一遍能否看懂

## 16 达人合作：佣金、服务费与坑位费的风险账

典型状态：一个达人报价，坑位费3000元加两成佣金，你算不清这场到底能不能做。

> **问**：达人合作有哪几种付钱方式？

三种。纯佣是只付佣金，一般20%—30%，没有前置费用，适合新店试水。

佣加服务费是佣金15%—20%再加服务费5%左右，适合已经跑出数据的店。

坑位费加佣金是先付一笔固定费用，再按成交付佣金，风险最高。

> **问**：坑位费什么情况下才能付？

先算出保本单量再决定。公式：保本单量＝坑位费÷（单件净利－单件佣金）。

**算例（两种合作方式对比）**

商品到手价39.9元，单件净利（不含佣金）17.66元。

方式一，纯佣25%：单件佣金＝39.9×25%＝9.98元，单件净利＝17.66－9.98＝7.68元。出100单，净利768元。零前置风险，适合首月合作。

方式二，坑位费2000元加佣金10%：单件佣金＝3.99元，单件净利＝17.66－3.99＝13.67元。

保本单量＝2000÷13.67＝146.3单，也就是说至少要出147单才回本。

如果这场只出40单：13.67×40＝546.8元，减掉2000元坑位费，净亏1453.2元。

如果这场出200单：13.67×200＝2734元，减掉2000元，净赚734元。

结论：坑位费只有在你有把握卖到保本单量1.5倍以上时才付，也就是这场必须预期220单以上才值得签。

**分步实操**

1．拿到达人报价，先问三件事：粉丝画像、近30天同类目真实成交数据、有没有刷量记录。

2．用保本单量公式算一遍，不满1.5倍就不付坑位费。

3．合同写清四件事：内容形式与发布时间、保底单量、未达标的处理方式、付款分两期（30%定金、70%验收后付）。

4．直播场次要求看实时后台，不看对方提供的截图。

5．合作当天自己派人在直播间截图和录屏留证。

6．结算时把佣金、服务费、样品成本、坑位费一起算进这场账。

**正确做法**

- 新店首月只做纯佣，跑出数据再谈前置费用。

- 达人合作的价格必须与店铺到手价一致，不能直播价低于店铺价还挂店铺链接。

- 每场合作单独记账，按投产比决定续不续。

**常见错误**

错误示范：看达人粉丝量五十万就签了坑位费合同。

错在哪：粉丝量不等于匹配度，粉丝买的是九块九的人群带不动你四十元的品，2000元打水漂。

错误示范：一次性付清坑位费，没有保底条款。

错在哪：卖多少全看对方心情，卖不动钱也退不回来，这是最贵的一课。

> **【规则提示·2026规则修正】** 原与达人约定“刷够单量走个流程，事后返现”的做法属虚假交易。依据：平台对虚假交易与佣金链条双向核查，商家连带受罚。合规替代：只签真实成交计佣的合作，把保底写成“不少于”的目标并约定未能达成时按比例退费。

**实操检查清单**

- [ ] 合作前核验达人真实成交数据

- [ ] 每场都算保本单量

- [ ] 预期单量不到保本1.5倍不付坑位费

- [ ] 合同写明内容形式与发布时间

- [ ] 付款分两期，尾款验收后付

- [ ] 合作当场截图录屏留证

- [ ] 把坑位费与样品成本计入单场账

## 17 内容流量与货架流量：一个是增量，一个是基本盘

典型状态：你做了直播、发了视频、开了推手，订单是多了，但停了内容单量就归零，心里没底。

> **问**：内容流量和货架流量是什么关系？

货架流量来自搜索、推荐、活动、店铺页，由价格力和转化效率决定，这是你的基本盘，它稳，店就稳。

内容流量来自视频、直播、推手，平台有扶持，但它是增量，你不做就没有，做了也不一定明天还有。

两者的关系是：内容负责拉新，货架负责承接和复购。

> **问**：怎么判断内容做得值不值？

看两个比例。内容带来的订单占全店低于10%，说明内容没跑起来。

超过40%要警惕，说明你的基本盘太弱，一旦内容停掉店铺就断流。

健康区间是15%—30%，同时搜索订单还在增长。

**分步实操**

1．每天记录三组订单来源：搜索、推荐、内容（含视频、直播、推手）。

2．算出内容订单占比，落在15%—30%区间算健康。

3．看搜索订单有没有随内容增长而增长，涨了说明内容在反哺货架。

4．内容里提到的关键词与商品标题、详情页保持一致。

5．内容带来的新客，用平台内关注店铺和复购券承接。

6．每月做一次全店复盘，内容订单涨了但总利润没涨，就要查内容渠道的真实净利。

**算例（内容对货架的带动）**

第1个月：全店日销300单，搜索180单、推荐80单、内容40单。内容占比＝40÷300＝13.3%，偏低。

第2个月：加了短视频和直播后，内容订单涨到120单，同时搜索涨到200单、推荐涨到90单，全店日销410单。

内容占比＝120÷410＝29.3%，落在健康区间。

说明内容做起来的这一个月，货架流量也同步涨了。

如果第2个月内容订单涨到120单，但搜索掉到110单、全店日销只有280单，那就是内容在抢自己的货架流量，要检查是不是内容价与店铺价不一致。

**正确做法**

- 内容的到手价与货架价保持一致，价差是流量互相打劫的根源。

- 内容拉来的新客要沉淀，用关注店铺和会员券把人留下来。

- 把内容当增量渠道考核，不给它背全店增长指标。

**常见错误**

错误示范：直播间价格比店铺低，还挂店铺链接。

错在哪：买家看完直播回店铺发现价格不一样，直接投诉或者退款，两头都受损。

错误示范：内容做起来就停掉付费推广和搜索优化。

错在哪：内容流量波动大，基本盘一停，单量断崖，恢复要重走一遍冷启动。

**实操检查清单**

- [ ] 每天记录三组订单来源

- [ ] 每周算一次内容订单占比

- [ ] 内容占比低于10%就加内容排期

- [ ] 内容占比高于40%就补基本盘

- [ ] 内容价与店铺价保持一致

- [ ] 内容关键词与标题详情对齐

- [ ] 每月查一次内容渠道真实净利

## 18 社交裂变与内容渠道的合规红线

典型状态：想用拼团、助力拉一波人，又怕碰线；推手和达人在外面怎么说，你也管不住。

> **问**：拼团、助力、分享有礼的边界在哪？

能做，但有五条线不能过。

第一，不能强制分享才能享受已经付款的商品，分享必须是自愿的加分项。

第二，不能诱导分享到站外，比如让买家把链接发到微信群再截图给你。

第三，奖励必须真实兑现，不能写“邀请3人必得”实际永远差一人。

第四，不能做多层级拉人头返现，那是传销式结构。

第五，助力人数和进度必须真实，不能后台改数字。

> **问**：内容渠道最容易踩的三类红线是什么？

站外导流、虚假宣传、佣金欺诈。推手和达人说的话，出了事商家一起担责，所以脚本必须审。

**算例（裂变这笔账怎么算）**

玩法：邀请3人助力免单。每单成本按8—12元算（货品成本加运费加让利），取中位数10元。

投入5000元，可支撑约500单参与，沉淀私域用户5000人。

后续复购率按35%算，复购人数＝5000×35%＝1750人。

复购客单价39.9元，单件净利7.68元。

复购带来的净利＝1750×7.68＝13440元。

对比投入的5000元，这笔账是划算的。

但如果复购率只有5%：1750变成250人，净利＝250×7.68＝1920元，低于投入的5000元，这场裂变就是纯亏。

所以裂变能不能做，取决于你的品有没有复购，没有复购的品不要做裂变。

**分步实操**

1．做裂变前先看品类复购周期，复购周期超过6个月的不做。

2．奖励设计成“分享得券”而不是“分享得现金”。

3．活动规则里写明奖励数量与兑现时间，不写“必得”。

4．所有推手、达人的脚本先收上来审一遍，去掉极限词和导流话术。

5．直播全程录屏，短视频成片后自己再看一遍再发。

6．每个月做一次素材合规自查，用后台词库工具过一遍文案。

**三类红线的具体表现**

站外导流：客服引导加微信、包裹卡印二维码、视频描述留联系方式、直播口播“加我发优惠”。

虚假宣传：写“最”字头、“第一”“唯一”“国家级”；功效类写“七天美白”“减肥”；谐音规避如“醉佳”；虚构原价如“原价199今天39”。

佣金欺诈：要求返现刷单、要求私下转账、承诺包销多少单、提供假的推广数据。

> **【规则提示·2026规则修正】** 原包裹卡写“加微信领红包”、客服引导站外成交的做法属站外导流。依据：平台对导流行为与包裹卡内容双向稽查，违规扣分限流。合规替代：包裹卡改成“晒图参与抽奖”，复购引导只用平台内的关注店铺、店铺会员与复购券。

> **【规则提示·2026规则修正】** 原通过推手返现做基础销量、用第三方代写评价的做法属虚假交易与虚假评价。依据：平台实施同设备、同地址、异常轨迹识别与关联店连坐。合规替代：多多进宝真实佣金破零加包裹卡引导真实晒图，全部动作留在平台真实成交链路里。

**正确做法**

- 推手和达人的话术由你提供，不要让对方自由发挥。

- 每一次内容发布前走一遍自查，宁可晚发一天。

- 所有合规素材、录屏、聊天记录留存至少半年。

**常见错误**

错误示范：推手在群里说“全网最低价、效果立竿见影”，你当作没看见。

错在哪：极限词和功效承诺的处罚算在商品和店铺头上，推手走了你还在。

错误示范：为了裂变效果，把助力进度后台改成“还差1人”永远不变。

错在哪：属虚假宣传与欺诈，买家投诉后活动会被取消，店铺扣分。

**实操检查清单**

- [ ] 裂变活动只做自愿分享

- [ ] 奖励写成得券不写必得

- [ ] 不做多层级拉人头返现

- [ ] 推手与达人脚本发布前逐一审核

- [ ] 直播全场录屏留存

- [ ] 包裹卡不出现微信与二维码

- [ ] 每月用词库工具做一次全店文案自查

- [ ] 合规素材与记录留存不少于半年
