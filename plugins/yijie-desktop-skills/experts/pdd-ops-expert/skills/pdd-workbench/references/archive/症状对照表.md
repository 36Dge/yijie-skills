# 拼多多运营 · 症状 → 根因诊断脑（2026 合规实战版）

> **用法三句话**
> 1. 商家报问题时，先在本表定位「症状簇」→ 拿到候选根因与该读的模块场景。
> 2. 用场景标题或关键词在对应板块文件里搜索定位，再 Read 原文取证（取它的分步实操与算例）。
> 3. 按 `SKILL.md` 的诊断六步输出「根因排序（带证据等级）+ 合规校验 + 分步动作 + 检查清单 + 复核指标」。
>
> **两条纪律**：① 所有阈值/费率/时效一律标注「以后台实时提示为准」，不冒充平台确定结论；② 命中 规则修正对照表 或 `合规与申诉` 红线的意图，先拦截再给合规替代。
> 每簇末尾的「需索取」= 没有这些数据就只能给方向，不能给结论。

---

## 1. 新店 / 新品没流量、不出单

- **根因A 类目或品选错**：类目错了流量从第一天就歪，后面怎么推都补不回来 → `核心认知·09 类目能不能做`、`开店入驻·10 类目怎么选`、`复盘诊断·16 选品数据`
- **根因B 上架有硬伤**：类目放错 / 属性填不全 / 标题违禁词 / 主图不达标，链接上线即被限流或搜不到 → `上架发布·01 类目选错`、`上架发布·02 属性填不全`、`上架发布·04 违禁词自查`、`素材规范·01 主图规格`
- **根因C 价格力不足**：比价机制直接压流量 → `核心认知·05 比价机制`、`定价算账·13 价格力考核`、`定价算账·09 价格带卡位`
- **根因D 新品初始权重≈0 就开车**：白烧钱 → `核心认知·15 初始权重`、`冷启动·02 一上来就开车`、`付费推广·01 推广底层`
- **根因E 没破零 / 没入池**：头 3 天到 14 天的黄金窗口没抓住 → `冷启动·01 破零抢头3天`、`冷启动·06 合规冷启动五步法`、`冷启动·10 入池没入池`
- **需索取**：上架天数、近 7 天访客与成交、主图点击率、同款同行最低到手价、是否开过车、类目与价格带

## 2. 有访客没转化 / 加购不下单

- **根因A 承接问题不是流量问题**：点击率解决「进不进来」，转化率解决「买不买」，加流量只会放大亏损 → `复盘诊断·02 核心数与假指标`、`复盘诊断·11 有加购不下单`
- **根因B 主图与详情没承接住**：卖点顺序、场景图、详情模块顺序 → `素材规范·03 五张主图怎么排`、`素材规范·13 详情页结构`
- **根因C 价格与权益没打透**：券后价/到手价没竞争力 → `定价算账·06 券后价与到手价`、`定价算账·07 营销工具合规降价`
- **根因D 评价与信任不足**：基础评价条数不够 → `冷启动·04 基础评价条数`
- **根因E 人群推错**：访客人群与支付人群错位 → `复盘诊断·13 人群标签跑偏`
- **需索取**：点击率、支付转化率、加购数、停留、访客人群画像、评价条数、同款到手价

## 3. 付费推广烧钱没转化 / 投产比低

- **根因A 没算保本投产就上车**（最常见的翻车点）：投产比 2.8 看着赚，保本要 3.125 就是亏 → `付费推广·01 保本投产`、`定价算账·04 保本投产比`
- **根因B 毛利不够却做付费**：自然流 <10%、微付费 <20–30%、强付费 <50% → `定价算账·05 毛利红线`、`付费推广·08 强付费`
- **根因C 出价模式选错**：新链接用成交出价养权重，老链接退货率稳定后才换净成交出价 → `付费推广·03 出价模式`、`复盘诊断·02`
- **根因D 只看整体投产比**：盈利计划被亏损计划吃掉 → `复盘诊断·02 逐计划看`、`复盘诊断·14 假指标`
- **根因E 没做拖价 / 托管设置错**： → `付费推广·05 拖价`、`付费推广·06 全店托管`
- **需索取**：出价模式、日限额、目标投产设置值、客单价、单件利润、退货率、逐计划投产比

## 4. 定价算不清 / 算完发现亏了

- **根因A 成本项漏算**：只算货品成本，漏运费、包材、人工、费率、推广、退货逆向运费与货损 → `定价算账·01 九项成本表`
- **根因B 套错费率**：误用 7.6%，实际类目 0.6%–5% → `定价算账·02 技术服务费`
- **根因C 没算退货损耗**：退货率按 0% 算出来的保本价会低两成 → `定价算账·01`、`定价算账·04`
- **根因D 用标价而不是到手价算利润**：券后价才是买家眼里的真实价 → `定价算账·03 保本售价公式`、`定价算账·06`
- **根因E 一件代发加价越红线** → `定价算账·15 一件代发保本`
- **需索取**：货品成本、快递费、包材、人工、类目费率、退货率、目标净利率、玩法（自然流/微付费/强付费）

## 5. 报不上活动 / 报名被驳回

- **根因A 历史最低价卡住**：活动价需 ≤ 近 30 天最低真实成交价（秒杀价、店铺关注券不计入） → `活动提报 报名三本账`、`定价算账·06 历史最低价`
- **根因B 评分/领航员不达标**：综合排名 >30% 是及格线（不是进前 30%） → `店铺评分 领航员读法`、`活动提报`
- **根因C 库存/货盘不够**：报活动前先算货够不够 → `活动提报 报名前算三本账`
- **根因D 资质不齐 / 虚高标价**：虚构原价触发违规且报不上 → `合规与申诉`、`附录B·1 虚构原价`
- **根因E 价格守不住**：报上去就砸穿价格体系 → `定价算账·11 大促价格体系`、`活动提报 避坑`
- **需索取**：想报的活动名、近 30 天真实成交最低价、领航员综合排名、库存深度、资质清单

## 6. 活动报上了却赔钱 / 被活动反噬

- **根因A 没有留降价空间**：平时价 = 活动到手价，一报名就利润倒挂 → `定价算账·11`
- **根因B 没算活动让利的完整成本**：券、满减、平台补贴、退货率叠加 → `定价算账·07`、`定价算账·01`
- **根因C 频道报错**：不同频道对价格力、库存、评分的要求不同 → `活动提报`
- **需索取**：报的活动与活动价、平时到手价、单位净利、活动期预估单量与退货率

## 7. 流量突然下滑 / 断流

- **根因A 先分清是掉了还是被限了**：三项同跌且全天均匀 → 指向权重或处罚；单块掉 → 指向那块规则 → `复盘诊断·07 三板斧定位`、`复盘诊断·04 六层拆解`、`复盘诊断·09 降权表现`
- **根因B 权重/处罚类**：查商品体检、违规记录、体验分排名、价格力诊断四个页面 → `复盘诊断·04`、`合规与申诉`
- **根因C 人群标签跑偏**：标签乱了推荐越推越不准 → `复盘诊断·13`、`核心认知·03 价格就是流量`
- **根因D 时间/竞品因素**：只在某时段掉，可能是竞品直播或秒杀 → `复盘诊断·04 分时间`
- **急救顺序**：断流急救动作有先后，顺序错了越救越死 → `复盘诊断·08 断流急救`
- **需索取**：掉的起止时间、流量结构（推荐/搜索/活动/付费）占比变化、违规记录截图、是否改过主图或价格

## 8. 主图点击率低 / 素材不过审

- **根因A 尺寸比例格式不达标**：反复驳回 → `素材规范·01`、`素材规范·02 1:1还是3:4`
- **根因B 首图没在 0.1 秒内说清卖点**： → `素材规范·03 五张主图排序`、`素材规范·06 场景细节图`
- **根因C 牛皮癣/边框/水印/拼接图**：违规且降权 → `素材规范·04`
- **根因D 极限词与功效宣称**：绝对化用语、功效夸大、虚假承诺 → `素材规范·11 标题极限词`、`素材规范·12 素材合规红线`
- **根因E 硬换首图导致断流**：改主图有正确方式 → `素材规范·14 改主图的正确方式`
- **需索取**：被驳回的具体提示、当前首图、点击率与同行均值、是否近期换过图

## 9. 店铺评分 / 领航员低（报名被拒、流量变少）

- **根因A 分不清是哪套分**：领航员（百分位排名）、消费者服务体验分（0–5 分）、综合体验星级（3–5 星）用途不同 → `店铺评分·01`
- **根因B 商品体验掉**：品退、差评、描述不符 → `店铺评分·02 分维度提升`、`客服售后`
- **根因C 物流体验掉**：揽收及时率不足 → `店铺评分·02`、`发货履约`
- **根因D 服务体验掉**：3 分钟人工回复率不足、纠纷率高 → `客服售后`、`店铺评分·02`
- **必读提醒**：官方从未公开任何体系的维度权重，网传「商品品质占 30%」类内容无出处，直接跳过；只比排名不猜权重 → `店铺评分`、核心指标与名词速查
- **需索取**：各项百分位排名、48h 揽收率、3 分钟回复率、近 30 天品退率与纠纷率

## 10. 客服回复率不达标 / 售后处理慢

- **根因A 机器人回复不计入人工回复**：口径没吃透 → `客服售后·01 客服接待`
- **根因B 考核时段覆盖不足**：考核时段（一般 08:00–23:00）内的在线状态、快捷短语、离线公告没配齐 → `客服售后·01`、`客服售后·03 客服工具`
- **根因C 高频问题没做话术库**：每次重新打字，响应必慢 → `客服售后·01`
- **需索取**：当前 3 分钟人工回复率、时段分布、客服人数与排班

## 11. 仅退款 / 极速退款 / 恶意售后 / 差评

- **根因A 没按场景分档处理**：八类售后场景各有 SOP，一刀切必吃亏 → `客服售后·02 售后处理流程`
- **根因B 举证不足就认赔**：金额大、明显异常的应该走恶意售后申诉 → `客服售后`、`合规与申诉 申诉举证`
- **根因C 差评根因在上游**：主图详情与实物不符、尺码不准 → `客服售后`、`素材规范·15 SKU 图与名称`
- **需索取**：纠纷类型、订单金额、举证材料（聊天记录/物流/开箱视频）、响应时效、是否已申诉

## 12. 发货超时 / 虚假发货 / 物流异常

- **根因A 判定看揽收不看你点发货**：48 小时内必须有物流首条揽收记录 → `发货履约·01 发货时效规则`
- **根因B 电子面单认知错**：它是开通制但有协议约束，不开的真实风险是轨迹回传延迟导致被误判 → `发货履约`、`合规与申诉`
- **根因C 二次单号填不进**：代发链路不对 → `发货履约·03 履约优化`
- **根因D 虚假发货/虚假轨迹赔付**：5%（下限 5 元、上限 100 元/单），欺诈发货 30% → `发货履约·02 虚假发货`
- **需索取**：待发货量、单日超时单量、面单类型、是否代发、近 30 天揽收表现、快递揽收稳定性

## 13. 被比价 / 价格力不足

- **根因A 躲比价的老办法已失效**：换文字换图、炮灰 SKU、隐藏活动 ID 都属规避比价 → `定价算账·13`、`上架发布·08 阴阳/炮灰 SKU`、`附录B·6/7/8`
- **根因B 缺真实差异化**：同质化只能打价格 → `定价算账·16 真实差异提价`
- **根因C 成本没有优势**：供应链成本决定价格力下限 → `核心认知·10 成本优势验证`、`定价算账·01`
- **需索取**：同款竞品到手价、规格差、自有成本结构、是否被系统提示价格力不足

## 14. 冷启动破零失败 / 破零就被清洗

- **根因A 用了刷单/代写评价类老打法**：清销量、删评价、扣分、限制流量 → `冷启动·05 包裹卡合规`、`冷启动·06 五步法`、`附录B·3/4`
- **根因B 破零节奏错**：头 3 天窗口、不能一上来猛冲 → `冷启动·01`、`冷启动·03 破零量窗口`
- **根因C 没用合规增量通道**：多多进宝 CPS 真实破零没做 → `冷启动·07 CPS 破零`、`推手与内容·01`
- **需索取**：上架天数、当前销量与评价、做过的破零动作、是否找过第三方

## 15. 合规被罚 / 收到违规通知

- **根因A 命中红线打法**：虚构原价、刷单、阴阳 SKU、站外导流、好评返现等 → `合规与申诉 违规分级`、规则修正对照表
- **根因B 不知怎么申诉/举证**：证据准备与申诉路径 → `合规与申诉 申诉举证`
- **根因C 亮照与税务**：收到亮照通知后未办理 → `合规与申诉`、`附录B·16`
- **需索取**：违规类型与通知原文、处罚形式（扣分/扣保证金/限流/清退）、可举证的原始材料

## 16. 上架被驳回 / 审核不过

- **根因A 类目与属性**：类目放错、属性填不全 → `上架发布·01`、`上架发布·02`、`上架发布·15 审核与驳回`
- **根因B 资质与品牌**：缺授权、资质到期 → `开店入驻·06 资质怎么备`
- **根因C 图片与文案不合规**：盗图、违禁词、极限词 → `素材规范·16 盗图处罚`、`素材规范·11`
- **需索取**：驳回提示原文、商品类目、资质有效期、图片与文案来源

## 17. 利润越做越薄 / 卖得多赚得少

- **根因A 客单价下跌伴随低毛利 SKU 占比上升**：退货率与运费占比同步上升 → `复盘诊断·03 核心等式`、`定价算账·10 SKU 锚点与阶梯价`
- **根因B 推广费按固定金额记而不是按营收占比记**： → `定价算账·01`
- **根因C 没有月度盈亏复盘**：哪条链接亏钱不知道 → `定价算账·18 定价复盘与利润预警`
- **需索取**：月度单款盈亏表、客单价走势、SKU 结构占比、推广费占比、退款率

## 18. 店铺成长/分层进度卡住

- **根因A 想靠冲单量堆层级**：考核的是真实经营质量（发货时效、仅退款占比、店铺评分、纠纷） → `核心认知·14 层级`、`开店入驻·15 成长分层`、`附录B·5`
- **根因B 卡在某一项考核项没补**：后台成长与分层入口可看进度 → `开店入驻·15`
- **需索取**：当前等级与升级进度、卡住的具体考核项

## 19. 广告/内容（多多进宝·直播·短视频·达人）没效果

- **根因A 佣金与推手筛选没做对**：CPS 结构与筛选标准 → `推手与内容·01 多多进宝`、`冷启动·07`
- **根因B 直播分时段与选品没配合**： → `推手与内容·02 直播`
- **根因C 短视频挂车与内容结构问题**： → `推手与内容·03 短视频`
- **根因D 成交没留在平台内**：站外成交必被处理 → `推手与内容`、`合规与申诉`
- **需索取**：佣金设置、推手数量与动销、直播时长与时段、视频播放与转化数据

## 20. 不知道数据看哪里 / 复盘无从下手

- **根因A 八个看板没分工**：一个看板对应一个判断 → `复盘诊断·01 看板分工`
- **根因B 被假指标带偏**：只看成交额、只看整体投产比、把系统推荐出价当目标 → `复盘诊断·02`、`复盘诊断·14`
- **根因C 没有日盯表与周报月报机制**： → `复盘诊断·15 周报月报`
- **需索取**：当前盯的数、复盘频率、是否有固定字段的日盯表

## 21. 联合营销开通 / 开票 / 货款冻结

- **根因A 依赖活动流量却关不掉**： → `活动提报 联合营销`、`推手与内容`
- **根因B 开票能力没准备好**：税率与冻结比例以后台实时提示为准 → `活动提报`、`附录B·10`
- **需索取**：流量结构（活动占比）、纳税身份、开票流程是否走通、是否已收到冻结提示

## 22. 竞品截单 / 被同行抢流量

- **根因A 没有竞品监控机制**： → `复盘诊断·12 竞品监控`
- **根因B 被针对性降价**：跟不跟降价的判断框架 → `定价算账·12 对手降价跟不跟`
- **需索取**：竞品清单、竞品价格与活动节奏、自家份额与转化变化

## 23. 新品/新款选择与找款

- **根因A 凭感觉选品**： → `核心认知·12 找款两种精确方法`、`复盘诊断·16 选品数据`
- **根因B 没有测款机制**：AB 测试没对照 → `复盘诊断·17 AB 测试`
- **根因C 市场大盘在退**：行业在跌时你不是唯一掉的人 → `复盘诊断·04 外因`、`复盘诊断·01 行业大盘`
- **需索取**：候选款清单、成本与目标价、行业大盘走势、测款预算

## 24. 一件代发 / 供应链问题

- **根因A 代发铺货没权重**： → `上架发布·16 代发铺货没权重`、`定价算账·15`
- **根因B 上家单号填不进后台（二次单号）**： → `发货履约·03`、`附录B·13`
- **根因C 代发加价越红线导致亏**： → `定价算账·15`
- **需索取**：上家发货时效、面单类型、加价空间、退货由谁承担

## 附：三条最常被忽略的口径

1. **领航员/体验分的百分位是「超过多少比例的同行」**，数字越大越好；「> 30%」是及格线不是排前 30%（`店铺评分`）。
2. **发货时效看揽收，不看后台点发货的动作**；48 小时内无首条揽收记录即判延迟（`发货履约`）。
3. **保本投产比必须用退货率修正**，否则会把亏损当盈利（`定价算账·04`、`付费推广`）。
