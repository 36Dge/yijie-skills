# 实操检查清单合集

本附录把全书各模块的检查清单按经营阶段重新编排，方便你按当下所处阶段逐条勾选。

用法：找到你现在的阶段，把清单打印出来，完成一条勾一条。勾不上的条目，就是你现在最该补的动作，翻到对应模块去查怎么做。

建议节奏：起步阶段每周完整过一遍，稳定期每两周过一遍。每次大促前必须完整过一遍。

## 阶段一：开店与准备期

### 1.1 开店前想清楚的事

- [ ] 确认要做的类目，并用行业大盘数据验证过需求体量

- [ ] 确认自己在这个类目有成本优势，货架价不高于同行极致价的1.2倍

- [ ] 算清单件货品成本、运费、人工、平台技术服务费

- [ ] 算出保本售价与保本投产比

- [ ] 判断自己做的是自然流量玩法、微付费还是强付费，并确认毛利是否达标

- [ ] 确认所选类目的资质要求自己能不能满足

- [ ] 想清楚发货方式：自有仓、代发、还是混合

### 1.2 开店与资质

- [ ] 确定店铺类型：个人店还是企业店

- [ ] 准备营业执照与经营范围，确保覆盖所卖商品

- [ ] 准备类目资质与品牌授权（如需）

- [ ] 完成入驻提交，跟进审核进度

- [ ] 处理审核驳回意见，补齐材料

- [ ] 确认保证金金额与缴纳方式

- [ ] 完成店铺命名，避免违规词

### 1.3 下店后的首周基建

- [ ] 完善店铺简介、头像、联系方式

- [ ] 配置客服账号与分流规则

- [ ] 设置快捷短语与自动回复

- [ ] 配置离线公告与离线消息

- [ ] 设置运费模板，含偏远地区策略

- [ ] 设置发货地址与退货地址

- [ ] 开通拼多多电子面单

- [ ] 配置售后规则与自动退款相关设置，逐项确认是否该开

- [ ] 打印附录A本阶段清单并建立每周自查习惯

## 阶段二：上架与素材期

### 2.1 商品发布

- [ ] 用行业数据验证类目选得对

- [ ] 确认有无以图搜货的同款可发布

- [ ] 类目属性填写完整，品牌与材质准确

- [ ] 标题字数用满，关键词布局合理，无违禁词

- [ ] 标题与属性、主图内容一致，不出现描述不符

- [ ] SKU设置完整：引流规格、主推规格、利润规格

- [ ] SKU名称清晰，无歧义，不让买家选错

- [ ] 库存设置合理，不漏设，不设虚假库存

- [ ] 尺码关联按要求设置（适用类目）

- [ ] 商品关联推荐与商品系列配置

- [ ] 检索商品搜索结果，确认已上架成功

### 2.2 素材规范

- [ ] 主图尺寸符合平台要求

- [ ] 主图共5张以上，分工明确：点击图、同风格图、细节图、场景图、白底图

- [ ] 最后一张为白底图

- [ ] 主图无牛皮癣、无水印、无拼接、无边框

- [ ] 主图无绝对化用语与虚假宣传

- [ ] 主图全部为自制或已授权素材，无盗图

- [ ] SKU图与商品一致，不货不对板

- [ ] 主图视频已关联，若有素材

- [ ] 详情页尺寸正确，模块顺序合理，卖点放在前几屏

- [ ] 详情页尺码表准确，含实测数据

### 2.3 定价与券

- [ ] 标价为真实吊牌价，非虚高价格

- [ ] 券后价在同价格带中有竞争力

- [ ] 券后价算得过利润，不是亏本冲量

- [ ] 优惠券设置完成，明确发放门槛与有效期

- [ ] 大促降价空间已预留，不会打乱日常价格体系

- [ ] 已确认哪些价格会进入历史最低价考核

## 阶段三：冷启动期（上架后0—14天）

### 3.1 破零动作

- [ ] 上架当天完成全部零成本设置

- [ ] 通过多多进宝设置佣金并发起真实破零

- [ ] 佣金比例算过利润，叠加优惠券后不亏本

- [ ] 包裹内放置合规的晒图有礼卡

- [ ] 话术合规：引导晒图，不承诺好评返现

- [ ] 已积累基础真实评价，达到可支撑转化的数量

### 3.2 入池与测款

- [ ] 确认链接是否已入池，查入池硬指标

- [ ] 若未入池，逐项排查：主图、价格、类目属性、库存

- [ ] 用小额付费测点击率与转化率

- [ ] 测出点击率明显高于同类的主图，作为第1张

- [ ] 通过测款判断该款值不值得继续投入

### 3.3 冷启动期的红线自查

- [ ] 全程没有刷单、没有代写评价

- [ ] 没有使用任何“同步竞品数据”的服务

- [ ] 没有拍大单冲层级

- [ ] 没有设置不发货的炮灰SKU

## 阶段四：起量与放大期

### 4.1 付费推广

- [ ] 保本投产比与修正后的保本投产比均已算出

- [ ] 根据自身玩法确定投产目标：微付费约保本×1.4

- [ ] 新链接使用成交出价或投产比出价养权重

- [ ] 老链接跑满7天、退货率稳定后再评估切换到净成交出价

- [ ] 全店托管的投产目标、日限额、探索比例设置合理

- [ ] 每日查看推广消耗与产出，及时止损

- [ ] 拖价时单次调幅小，调后观察再调下一次

- [ ] 定时检查自然流量占比，确认付费没有挤压免费

### 4.2 活动提报

- [ ] 报名前核对库存是否充足

- [ ] 报名前核对价格能否守住，算过活动价利润

- [ ] 报名前核对体验分是否达标

- [ ] 自查全网价格，确认不触及补贴比价红线

- [ ] 确认活动期间的客服与发货人力能承接

- [ ] 活动结束后复盘数据，沉淀为下次报名的依据

### 4.3 体验分与售后

- [ ] 体验分与领航员分定期查看，明确自己在行业中的位置

- [ ] 3分钟人工回复率保持在不低于90%

- [ ] 品质退款率与退款率分开跟踪

- [ ] 客诉高发问题已从上游（主图、详情、尺码、包装）整改

- [ ] 售后处理流程与话术模板已形成团队标准

## 阶段五：稳定期与增长期

### 5.1 数据复盘

- [ ] 建立每日必看数据清单，固定时间查看

- [ ] 每周做一次两周期对比，找出退步项

- [ ] 核心等式拆解：流量×转化率×客单价，定位下滑环节

- [ ] 竞品价格与活动定期监控

- [ ] 人群标签精准度定期核查

- [ ] 有加购不下单的商品，检查是否有截单风险

### 5.2 货品结构

- [ ] 全店商品按引流款、主推款、利润款分工

- [ ] 动销率保持在合理水平，滞销品及时处理

- [ ] 持续上新，保持店铺活跃度

- [ ] 潜力款通过数据筛选出来，投入资源

### 5.3 履约与供应链

- [ ] 48小时揽收率定期检查

- [ ] 快递揽收稳定性定期评估，不只看价格

- [ ] 物流异常订单有主动处理机制

- [ ] 打包规范已形成标准，破损率可控

- [ ] 大促前确认备货与发货人力

### 5.4 客服与复购

- [ ] 客服考核指标与奖惩机制已落地

- [ ] 客服话术库持续更新，沉淀高频问题

- [ ] 复购引导路径清晰，不触碰站外导流红线

- [ ] 老客维护动作常态化

### 5.5 渠道拓展

- [ ] 多多进宝佣金结构与推手质量定期评估

- [ ] 直播或短视频如有开展，有固定复盘节奏

- [ ] 达人合作有筛选标准与结算规则

- [ ] 所有外部合作渠道均无站外导流与虚假宣传

## 日常运营自查清单（每天过一遍）

- [ ] 查看当日访客数、支付转化率、成交量

- [ ] 查看有无待处理的售后与投诉

- [ ] 查看客服3分钟回复率是否达标

- [ ] 查看是否有超时未发货订单

- [ ] 查看推广消耗与投产比是否在目标区间

- [ ] 查看店铺体验分与领航员分的变动

- [ ] 查看有无平台通知、违规提醒

- [ ] 查看库存，避免热销款断货

## 每周自查清单（每周过一遍）

- [ ] 两周期数据对比，找出退步项

- [ ] 动销率与滞销商品盘点

- [ ] 主图点击率数据复核，评估是否换图

- [ ] 竞品价格与活动监控

- [ ] 退款原因归集，找出高频问题

- [ ] 客服高频问题归集，补充话术库

- [ ] 推广计划结构复盘，砍掉亏损计划

- [ ] 发货时效与物流异常统计

## 大促前自查清单

- [ ] 主推款库存确认充足，备用货源已落实

- [ ] 大促价提前算过利润，不会亏本冲量

- [ ] 价格未触及历史最低价红线问题

- [ ] 客服人力排班已加配，排班表已确认

- [ ] 打包与发货人力已加配，面单纸与包装耗材备足

- [ ] 推广预算已调整，投产目标明确

- [ ] 主图与详情已更新大促氛围，但无虚假宣传

- [ ] 体验分在达标区间，不影响报名

- [ ] 售后预案已准备，高发问题处理口径统一

## 大促后复盘清单

- [ ] 核对实际成交、实际让利、实际利润

- [ ] 核对发货是否全部按时揽收

- [ ] 核对退款率与品质退款率是否异常上升

- [ ] 核对客服响应与满意度数据

- [ ] 汇总大促期间暴露的问题，形成整改清单

- [ ] 评估大促带来的新客是否形成复购

- [ ] 更新下一场大促的价格与库存预案
