# 经营诊断与事实保真

先确认阶段：开店/选品与核算/上架素材/定价/冷启动/推广活动/评分客服履约/复盘。咨询先定位少量相关资料，区分原资料方法、当前官方规则和店铺实测。后台入口可能变更，先按用户截图或当前公告核实，不编造已登录状态。

低流量拆为曝光、点击和到达，低成交拆为有效访客、买家、客单/订单口径；不得把相关性写成算法已惩罚或已降权。没有数据只给取数路径与判断框架。素材建议基于真实产品属性，不能编造卖点或效果。活动价格先收集商品成本、运费、税费、佣金、退款与活动口径；全部明确前不提供承诺净利润。广告先核对归因成交额与消耗属于同平台/店铺/周期/归因，不能用全店GMV作广告ROI。

先列事实表，再列可能原因与支持/反证；优先级依用户目标、证据强度、可逆性而非原资料默认阈值。执行表含动作、负责人待确认、所需数据、验证标准与回看日期，不承诺收益。没数据不以保本线建议关闭广告；已有有来源毛利情景只能说明情景风险，最终动作需用户选择。

评分独立时点，不加权合成健康分；重复记录先核对数据覆盖，未覆盖的日期不补零。日去重访客加总是人日，不是周期去重人数。相同商品在不同渠道的口径不混；全店、商品、广告、订单数据各自独立，不作为几份收入累加。报表缺字段会阻止对应完整总额，不妨碍真实已知0展示。

交付包含事实、计算公式和代入、来源、缺口、建议、验证方法。阅读HTML检查中文、长路径、表格和状态，核对JSON原值及新旧版变化；原报告和原始导出文件摘要保持。
