# 上架发布　从类目、标题到SKU，把商品正确地发上去

**本模块导语**：上架是整个店铺唯一一次可以零成本改命的机会，类目、属性、标题、SKU、详情、主图顺序，任何一项填错，后面花多少钱推广都补不回来。本模块不讲选品、不讲投放，只讲从打开“发布新商品”到点击“提交”这一条链路上的每一个按钮怎么点、每一个数怎么填、每一处坑怎么绕。照着做完，你的链接上架即合规、上架即入池、上架即能被搜到。

## 01 类目选错：发出去就搜不到，权重全部白做

典型状态：商品提交成功，后台显示“在售”，可是搜自己的核心词翻十页也找不到；你以为是降权，查了违规、查了体检，什么都没查出来。

> **问**：类目选错到底会带来什么后果？

类目是平台给商品发的“身份证”，它一次性决定三件事：第一，商品进哪个搜索池，池子不对，你的标题再精准也进不了对应筛选；第二，被哪套比价系统抓取，类目错位后同款聚合比价抓的是另一批商品，你的价格力评分失准；第三，能报哪些活动，很多资源位只对特定类目开放，类目错了连报名入口都看不到。这三件事同时出错，结果就是零精准搜索流量，权重记在错误的池子里。

> **问**：怎么确认自己的类目放对了？

最简单的方法是用拼多多App搜核心词，看搜索结果前排的商品挂在哪。或者在后台发布页输入商品名称，看系统推荐的类目是哪一个，再点进去比对同类目下在售商品的主图风格、价格带、销量水平。风格、价格带、销量都对得上，类目基本就是对的。

> **问**：链接已经出单了，还能换类目吗？

未出单的链接可以下架后按正确类目重发。已出单的链接不要动类目，一旦变更，历史销量、评价、人群标签不再跟随，等同于权重清零。

**分步实操**

1．进商家后台，点“商品管理”，再点“发布新商品”，在名称框输入你的商品核心词。

2．看系统弹出的类目推荐，把前3个候选类目分别点开。

3．在每个候选类目下浏览在售商品，记录排前20名的主图风格、主流成交价、单链接销量。

4．打开拼多多App，搜你的核心词，看搜索结果排前20的商品类目路径。

5．把后台推荐类目与App搜索结果交叉比对，重合度最高的那个就是你的类目。

6．确认类目后，再进入“商品管理”→“商品列表”，点开自己的商品，核对“类目”字段。

7．发现错了，未出单的立即下架，按正确类目重新发布；已出单的保留原链接，另建新链接覆盖新方向。

**正确做法**

- 先定类目，再填属性、标题、SKU，顺序不能反，反了就是整页重填。

- 一个商品只挂一个类目，不要为了多拿流量跨类目重复发布。

- 后台类目推荐是免费的官方答案，发布页永远先看它一眼。

- 类目判断用“三对”：对风格、对价格带、对销量水平。

- 拿不准的时候，看头部竞品挂在哪，跟着挂，别自己发明。

- 类目错了不是优化问题，是方向问题，越早改损失越小。

**常见错误**

错误示范：类目随便挑一个相近的，先把商品发出去再说。

错在哪：类目错位后商品进不了正确的搜索筛选池，主图和标题都发挥不出作用，系统把这条链接的权重记在错误的池子里，越推越偏。

错误示范：同一个款挂两个类目发两条链接，想两头吃流量。

错在哪：属于重复铺货，平台会判定同款多链接并降权，两条链接互相分散数据，最后都起不来。

错误示范：链接已经卖了几百单，觉得类目不对就直接编辑改类目。

错在哪：已出单链接变更类目，历史权重不继承，等于把前期的销量、评价、人群标签全部清零重做。

> **【规则提示·2026规则修正】** 原做法“流量不行就用换类目的方式救链接”已不成立。依据：类目是商品识别的基础字段，变更后系统按新类目重新冷启动该商品，历史销量与评价不再直接折算权重。合规替代：未出单链接下架后按正确类目重发，已出单链接不动类目，另开新链接测试新方向，用真实差异化做区隔。

**实操检查清单**

- [ ] 发布前用后台类目推荐确认过类目

- [ ] 用App搜核心词比对过前20名商品的类目

- [ ] 确认该类目下有稳定在售的同款与足够销量水平

- [ ] 在“商品列表”核对过自家商品的类目字段

- [ ] 没有为多拿流量跨类目重复发布同一款

- [ ] 已出单链接没有变更类目

## 02 属性填不全：搜索筛选进不去，等于少了半个流量入口

典型状态：标题写得很用心，主图也合规，可是商品的曝光起不来。查了半天，最后发现属性栏空了七八个，品牌和材质两项还是随手乱勾的。

> **问**：属性到底影响什么？

属性是商品的“隐形搜索词”。买家在搜索结果页勾选“材质：纯棉”“适用人群：男士”这类筛选项时，系统是按属性字段匹配的。属性没填，商品就不会出现在这些筛选结果里，等于主动放弃了筛选流量。属性填错更严重，比如把涤纶填成纯棉，属于商品描述不符，会被判定虚假信息。

> **问**：这么多属性，哪些必须填？

必填项一个都不能空。非必填项里，品牌、材质、规格、适用人群、风格这几项优先级最高，因为它们既是搜索筛选条件，也是比价系统判断“是不是同款”的依据。剩下那些无关痛痒的，能填就填。

> **问**：我没有品牌，品牌栏怎么填？

有自有商标或授权的，如实选对应品牌。没有品牌的，选平台允许的“其他”或“无品牌”选项。绝对不能冒用他人品牌，那是售假风险，不是填错的问题。

**分步实操**

1．在发布页填完类目后，先滚动到“商品属性”区域，把所有带红色星号的必填项一次性填完。

2．打开拼多多App，搜你的核心词，看搜索结果页左侧的筛选项有哪几个维度。

3．把筛选项里的维度逐个对照到自己的属性栏，能做筛选项的属性优先填全。

4．品牌栏按实际选择：有商标选商标，无商标选“其他”或“无品牌”。

5．材质栏按实物成分填写，与吊牌、水洗标一致，不要凭感觉选。

6．规格栏填真实尺寸或容量，与SKU名称保持一致。

7．全部填完后，回到商品列表点开商品，逐项核对一遍再提交。

**正确做法**

- 属性当标题用：能填的关键词都填上，且必须真实。

- 品牌和材质两项优先级最高，这两项填对，同款识别的准确度直接影响比价结果。

- 属性与标题、主图、详情里的描述必须互相一致，三处对不上就是虚假描述。

- 服饰、家纺、食品这类有强筛选需求的类目，属性填全等于多开好几个流量入口。

- 拿不准的属性值，看同款头部商品怎么填，跟着填。

- 每次上新都按同一张属性清单走，别每次凭记忆填。

**常见错误**

错误示范：只填必填项，非必填的全部跳过。

错在哪：非必填项里藏着最关键的筛选维度，比如适用人群、风格、功能，跳过就等于放弃了这一整层筛选流量。

错误示范：材质栏随手选一个看起来高档的，比如把混纺选成纯棉。

错在哪：买家收到货一对水洗标就发现不符，轻则差评退款，重则被判商品描述不符、虚假宣传。

错误示范：没商标却在品牌栏随便挑一个大牌。

错在哪：直接构成冒用品牌、售假风险，处罚等级远高于普通违规。

**实操检查清单**

- [ ] 所有必填属性已填写完整

- [ ] 品牌、材质两项已按实际情况填写

- [ ] 属性与标题、主图、详情的描述互相一致

- [ ] 已对照搜索页筛选项补齐可用属性

- [ ] 无品牌商品选择的是“其他”或“无品牌”

- [ ] 提交前在商品列表复查过属性字段

## 03 标题怎么写才搜得到：30字用满，核心词放前面

典型状态：标题随手堆了一堆热词，看起来很热闹，“夏季新款爆款女装潮流时尚百搭”这种，结果一个月下来搜索访客只有个位数。

> **问**：拼多多标题有字数上限吗？

标题上限30个汉字，前12到15个字最关键。移动端搜索结果页只展示标题的前半段，核心词放在末尾等于没写。所以标题的第一原则是：核心品类词必须在前10个字以内出现。

> **问**：标题的结构公式是什么？

核心品类词 + 高搜索属性词 + 场景词 + 长尾词。可以先用方括号强调一个卖点，比如“[纯棉]短袖T恤男夏季宽松透气百搭”。系统按词根切分标题，重复的词根不会带来第二次曝光，只会浪费字数。

> **问**：词从哪里来？

四个来源：搜索框下拉联想词、商品推广搜索词报表里的高转化词、行业热搜词、竞品标题拆词。筛选标准只有一条：有人搜，且竞争小。新店优先吃精准长尾词，比如“冰丝防晒衫女薄款透气”，别一上来就抢“防晒衫”这种大词。

**分步实操**

1．打开拼多多App，在搜索框输入你的核心词，把下拉框弹出的联想词全部截图记录。

2．进商家后台，打开“商品推广”的搜索词报表，导出近30天有成交的词，单独列一张表。

3．用行业热搜词工具或类目罗盘，补齐你这个类目的趋势词。

4．打开5个头部竞品，把它们的标题复制到记事本，人工拆成词根。

5．把四路词源汇总，去掉重复词根，按“搜索热度高、竞争商品数少”排序。

6．按“核心词 + 属性词 + 场景词 + 长尾词”的顺序组装，控制在30字内，核心词前置。

7．用后台“商品预审工具”过一遍违规词，确认零命中再提交。

**正确做法**

- 30个字用满，一个都不浪费，字数就是免费曝光位。

- 核心词前置，前10字定生死。

- 不重复词根，“女装女款女士”这种写法只占字数不加权重。

- 新店先吃长尾，链接跑起来有真实数据了再去碰大词。

- 标题里的每个词都要能在商品上找到对应，写“加绒”就必须真的是加绒。

- 上架前几天可以小调，链接满7天有真实数据后再精修，改动别太频繁，频繁改会扰乱人群标签。

**常见错误**

错误示范：标题塞满行业大词，比如“女装T恤夏季新款”。

错在哪：大词竞争商品数量极大，新链接没有销量和评分支撑，排名根本挤不进去，钱花了也没有曝光。

错误示范：核心词放在标题最后几个字。

错在哪：移动端搜索结果页标题被截断，买家根本看不到你的核心词，点击率直接腰斩。

错误示范：为了凑字数把同一个词换着写法重复三遍。

错在哪：系统按词根切分，重复词根不产生二次权重，反而挤占了本可以放长尾词的字数。

**实操检查清单**

- [ ] 标题字数用满30字

- [ ] 核心品类词出现在前10个字内

- [ ] 标题内没有重复词根

- [ ] 关键词来自下拉联想词、推广报表、行业热搜、竞品拆词四路汇总

- [ ] 词与商品实物完全对得上

- [ ] 已用“商品预审工具”排查违规词

- [ ] 标题定稿后没有频繁修改

## 04 违禁词自查：一个词就能让链接上线即限流

典型状态：商品刚提交就被驳回，或者勉强过审上线，第二天发现曝光几乎为零。翻来覆去查不出问题，最后发现是标题里带了“全网第一”。

> **问**：哪些词是绝对不能写的？

四类。第一类是价格敏感词，比如跳楼价、亏本甩卖、底价。第二类是营销敏感词，比如秒杀、全网第一、网络爆款、同款、清仓。第三类是绝对化用语，比如国家级、最高级、顶级、唯一、最佳、第一。第四类是功效敏感词，比如防癌、抗癌、抗衰。

> **问**：标题、主图、详情、SKU名称都要查吗？

全都要查。标题只是最容易被查的一处，主图上的文字、详情页文案、SKU名称里出现违禁词，处罚是一样的。2026年平台已经能识别谐音违规词，比如用“醉佳”代“最佳”、用“第①”代“第一”，这类写法一律按违规处理。

> **问**：用什么工具查最快？

商家后台的“商品预审工具”是免费的，可以自动识别违规词。上架前100%排查，大促前把全店商品批量排查一遍。类目词库要自己建一份，把本类目的禁用词整理成清单，存在团队共享的在线表格里，每次上新照单排查。

**分步实操**

1．进商家后台，在搜索框里搜“商品预审工具”，打开后把标题粘贴进去检测。

2．把标题里命中的词逐个替换成合规表述，“全网最低价”改成“到手价29.9元”这种直白说法。

3．打开主图源文件，逐个检查图上的文字，重点看极限词和促销诱导词。

4．打开详情页，从头到尾读一遍文案，重点查功效描述。

5．打开SKU列表，逐个检查SKU名称。

6．在商品管理里找到本类目的规则说明，把禁用词整理成一份类目词库。

7．把类目词库存到团队共享位置，每次上新前照单排查一次。

**正确做法**

- 上架前100%过一遍预审工具，一次都别省。

- 主图、详情、SKU名称与标题同样标准，一处都不能带违禁词。

- 谐音字、符号替代、拼音替代都不行，平台能识别。

- 建立并维护本类目词库，把查词变成流程而不是灵感。

- 大促前做全店排查，别只查新上的那几条链接。

- 写“最”字开头的文案，先自己怀疑一遍，再删掉重写。

**常见错误**

错误示范：标题写“全网最低价，秒杀清仓”。

错在哪：一句话里踩了价格敏感词和营销敏感词两类，链接提交即驳回；强上之后也会被限流，曝光基本归零。

错误示范：把“最佳”写成“醉佳”绕过检测。

错在哪：平台已具备谐音违规词识别能力，判定结果与直接写违规词一致，且主观规避意图明显，处罚更重。

错误示范：只在标题里排查，主图上的促销文字不管。

错在哪：主图是搜索和推荐结果的展示位，带违禁词的主图会直接导致整条链接被限制曝光。

**实操检查清单**

- [ ] 标题已用“商品预审工具”检测并零命中

- [ ] 主图文字逐张检查过，无极限词、无诱导词

- [ ] 详情页文案检查过，无功效宣传

- [ ] SKU名称检查过，无违禁词

- [ ] 已建立本类目禁用词词库并共享给团队

- [ ] 大促前做完全店批量排查

## 05 上架后能不能改标题、能不能换主图

典型状态：链接挂着没起色，你想改标题试试，又怕改了权重掉光。想换主图测试点击率，又怕换完系统重新评估。

> **问**：标题到底能不能改？

能改，但要讲节奏。标题确定后频繁大改会触发系统重新评估商品，人群标签跟着抖动。正确做法是：链接满7天有真实数据后再精修，每次只调1到2个词，改动幅度控制在三分之一以内。大促前把标题定稿，促销期不要再动。

> **问**：主图能不能换？

能换，但换首图等于重新测一次点击率。稳妥的方式是先把想试的图放到第2到第4张，用推广的创意测一轮，跑出点击率数据后再决定要不要换到首图。绝对不要频繁换首图，点击率数据不稳，系统没法给你稳定的曝光。

> **问**：换图的正确频次是多少？

一条链接一个月换首图不超过1次，换之前必须有数据支撑。判断依据是推广创意测出的点击率，不是自己的审美。

**分步实操**

1．打开“商品管理”→“商品列表”，找到目标链接，点“编辑”。

2．修改标题时，只替换表现差的1到2个词，保留核心词和已跑出数据的词。

3．保存后连续观察3天，看搜索访客和转化有没有下滑。

4．换主图时，先进入推广后台，点“添加创意”，把候选图放进创意库测试。

5．跑满3到5天，看哪张图的点击率最高，胜出的图才具备换首图的资格。

6．换图时在“编辑”页直接替换首图，其余图顺序不变，减少变量。

7．换完记录日期，连续观察7天点击率与转化数据。

**正确做法**

- 标题是小步优化，不是推倒重来，一次只动一两个词。

- 换首图必须先有数据，用推广创意测出来的点击率说话。

- 一次只改一个变量：改标题就不换图，换图就不改标题。

- 大促前后各留一周静默期，不动作何修改。

- 每次修改都记进操作日志，写清日期、改了什么、改后3天的数据变化。

- 数据没下滑就保持不动，稳定本身就是权重。

**常见错误**

错误示范：链接没起色就天天改标题，一天一个版本。

错在哪：频繁修改触发系统反复重新评估，人群标签持续抖动，最终表现是流量忽高忽低，永远跑不稳定。

错误示范：凭自己的审美直接把首图换成新做的图。

错在哪：换首图后系统要重新测试点击率，效果不好的话链接会经历一段曝光下滑期，白白损失已有的流量基础。

错误示范：大促当天改标题、换主图。

错在哪：大促期间系统正在给链接集中分配流量，此时改动会打断流量节奏，严重的直接失去活动资源位。

**实操检查清单**

- [ ] 标题修改前确认链接已有7天以上真实数据

- [ ] 每次只调1到2个词，核心词未动

- [ ] 换首图前用推广创意测过点击率

- [ ] 单次只改动一个变量

- [ ] 大促前后留出静默期

- [ ] 每次改动已记录日期与后续3天数据

## 06 三规格SKU布局：一条链接同时扛住比价和转化

典型状态：链接里的SKU随便分了几个规格，价格一模一样，买家进来点哪个都行，结果客单价上不去，比价系统一抓一个准。

> **问**：一条链接应该布几个规格？

三个规格是最低配置，分别承担不同任务。第一个是引流规格，用真实的小规格或体验装做低价门面，卡住搜索价格排序的位置，把人拉进来；它必须真实可发货，不是假货位。第二个是主推规格，也就是利润款，量大、性价比高，买家对比之后自然选它，这是真正赚钱的那一个。第三个是利润规格，用高配或套装做锚点，反衬主推规格的性价比。

> **问**：三个规格的价格怎么定梯度？

大规格的单价要略低于小规格，引导买家买大；主推规格的价格放在中间位置；引流规格微利甚至打平。核心原则是价格差距不能太离谱，差距过大系统会判定价格异常并屏蔽相关规格。

> **问**：规格之间的图文要不要做出区别？

必须做出明显差异。不同规格的图片和文字如果长得一样，会出现两个问题：一是买家分不清，买了贵规格以为会收到主推规格的货；二是系统抓不到规格之间的真实差异，防比价的效果就没了。

**分步实操**

1．进“商品管理”→“发布新商品”，在规格区域点“添加规格”，按颜色或容量或数量维度建三个规格。

2．第一个规格设成引流规格：真实存在的最小规格，价格最低，库存控制在合理范围。

3．第二个规格设成主推规格：真正的核心盈利款，价格居中，库存给足。

4．第三个规格设成利润规格：高配、组合或套装，价格最高，用来做锚定。

5．给三个规格分别上传对应的实物图，三个规格的图必须能一眼看出区别。

6．给三个规格分别写名称，用买家看得懂的话描述差异，不要用内部代号。

7．填完后用另一台手机看一遍前台，模拟买家视角确认三个规格的差异是否清晰。

**正确做法**

- 三个规格各司其职：引流拉人、主推赚钱、高价锚定。

- 引流规格必须真实可发货，这是底线不是技巧。

- 价格梯度做成平滑曲线，不要出现断层。

- 规格图片用真实实拍，三个规格三个样。

- 规格名称用买家语言，比如“藏青色”而不是“C01”。

- 定期看各规格的销量占比，主推规格卖不动就调整图文和价格梯度。

**常见错误**

错误示范：三个规格价格一样，只是名字不同。

错在哪：没有价格引导，买家随机选，客单价上不去，比价系统抓到的也是同一条链接里最便宜的那个价，价格力评分被拉低。

错误示范：引流规格设一个极低价，但不发货或者以次充好。

错在哪：属于低价引流违规，会被平台稽查，处罚包括下架、扣分、限制活动报名。

错误示范：三个规格用同一张图，只改名字。

错在哪：买家无法分辨规格差异，容易买错导致退款和差评，同时系统也识别不出规格差异，防比价失效。

**实操检查清单**

- [ ] 链接内至少布局三个规格：引流、主推、利润

- [ ] 引流规格真实可发货

- [ ] 价格梯度平滑，无异常价差

- [ ] 三个规格各有独立实拍图

- [ ] 规格名称使用买家看得懂的语言

- [ ] 已用手机端复核前台展示效果

- [ ] 主推规格销量占比已纳入每周复盘

## 07 SKU名称与SKU图规范：让买家一眼选对，让仓库一眼发对

典型状态：SKU名称写的是“C01”“A款蓝色L”，买家看不懂要来问客服，客服一天回几十条同样的咨询；仓库发货时看错规格，发错货引起退款和差评。

> **问**：SKU名称应该怎么写？

用买家的语言写，格式建议为“属性 + 规格”。比如“藏青色均码”“深灰XL码”“500毫升单瓶装”。不要用内部编号，不要把颜色代码、工厂货号直接当名称。如果商品有对应的尺码表，SKU名称里的尺码要和尺码表完全对应。

> **问**：SKU图有什么要求？

每个SKU上传对应的实物图，图片要能看清这个规格与其他规格的差异。颜色规格必须上传该颜色的实拍图，不能所有颜色共用一张主色图。数量规格比如3件装，图上要能看出是三件。SKU图是买家下单前最后一道确认关口，图不对就是退款的源头。

> **问**：SKU名称和SKU图能不能中途改？

可以改，但要和前台的尺码表、详情页同步改。三处不一致是最容易引起纠纷的情况。改完之后要在手机端重新看一遍，确认前台展示正确。

**分步实操**

1．进“商品管理”→“商品列表”，点开目标链接的“编辑”。

2．在规格区域逐个点开每个SKU，修改名称为“属性 + 规格”的买家语言格式。

3．逐个SKU上传对应的实拍图，颜色规格必须一色一图。

4．打开详情页编辑器，把尺码表里的规格名称同步更新成与SKU完全一致。

5．在商品列表的“库存”字段，逐个SKU核对库存数与实际仓库库存。

6．保存后打开手机端前台，逐个点选每个SKU，看名称、图片、价格是否对应正确。

7．把最终的SKU名称清单打印一份给仓库，作为发货核对表。

**正确做法**

- SKU名称用买家语言，第一眼就能看懂是什么规格。

- 一色一图，数量规格要在图上体现数量。

- SKU名称、尺码表、详情页三处必须完全一致。

- SKU编码体系自己定好规则，比如品类 + 年份 + 序号，方便库存管理和订单核对。

- 代发的商品用供应商编码做映射表，避免发货时对不上货。

- SKU清单要同步给客服和仓库，让所有人用同一套说法。

**常见错误**

错误示范：SKU名称全部写内部代号，比如“C01”“A3-2”。

错在哪：买家看不懂只能问客服，咨询量成倍增加，客服人力被无效咨询占满，转化率还下降。

错误示范：所有颜色共用一个SKU图。

错在哪：买家无法确认自己买的颜色长什么样，收货后颜色不符直接退款，退货率居高不下。

错误示范：SKU名称改了，详情页尺码表没改。

错在哪：买家按尺码表下单，收到货发现与SKU描述不符，属于商品描述不一致，纠纷判罚基本都判商家责任。

**实操检查清单**

- [ ] 所有SKU名称已改成“属性 + 规格”的买家语言

- [ ] 每个SKU已上传对应实拍图，颜色一色一图

- [ ] SKU名称、尺码表、详情页三处完全一致

- [ ] 已建立自有SKU编码规则

- [ ] 代发商品已做供应商编码映射

- [ ] SKU清单已同步给客服与仓库

- [ ] 手机端逐SKU点选验证过

## 08 阴阳SKU、炮灰SKU、低价引流SKU：为什么现在碰不得

典型状态：链接里放一个0.01元的SKU能不能把点击率拉起来，用两个看起来一样、实际货不同的SKU能不能躲开比价，这两件事你正在犹豫，也正准备照着试。

> **问**：什么是阴阳SKU？

同一个链接里，两个SKU名称看起来差不多，实际发的货不一样，或者价格与实物严重不符。这种做法过去被用来绕开比价系统的同款聚合，现在平台按规格语义跨店跨平台聚类，名称改了照样能识别。

> **问**：什么是炮灰SKU？

在链接里放一个极低价、低质的规格，专门用来把整条链接的价格力评分拉低，好让其他规格拿到流量。或者反过来，放一个高价规格专门当锚点，衬托主推规格便宜。定价锚定本身不违规，但如果炮灰规格实际不发货、或者以次充好，就构成低价引流违规。

> **问**：那三规格布局还能做吗？

能做。合规的边界只有一条：每个规格都是真实在售、真实可发货、图文一致。在这个前提下，用引流规格做低价门面、用高价规格做锚定，都是正常的商品结构设计。违规的不是规格数量，是规格真实性。

**分步实操**

1．打开“商品管理”→“商品列表”，点开链接的“编辑”，逐个检查每个SKU。

2．逐个核对三件事：这个规格是否有真实库存、是否能真实发货、SKU图是否是该规格实拍。

3．发现有不发货的规格，立即删除该SKU，而不是改名字或者调价掩盖。

4．发现两个SKU名称相近但货物不同，立即合并或删除其中一个，并修正名称。

5．检查价格梯度，把明显异常的极低价规格改成真实小规格的合理价格。

6．保存后用水印截图保存本次编辑记录，作为后续合规自查的凭据。

7．把这三条检查项写进上架检查清单，每次上新都执行一遍。

**正确做法**

- 所有SKU真实在售、真实可发货，这是唯一底线。

- 用真实差异化做防比价：独家规格、赠品组合、定制款、真实场景图。

- 低价规格用真实的小规格或体验装，价格低但不假。

- 高价规格做锚定可以，但必须有真实的货物能发出去。

- 不做换文字、换图躲比价的动作，比价系统按规格语义聚类，改名无效。

- 把合规检查固化成流程，不靠个人自觉。

**常见错误**

错误示范：在链接里放一个0.01元的SKU拉点击。

错在哪：属于不正当低价引流稽查范围，会被平台判定违规，处罚包括商品下架、扣分、限制活动报名。

错误示范：用名称相近的两个SKU装同一款货，想躲开同款比价。

错在哪：比价系统按规格语义跨店跨平台聚类，名称改写无法规避，一旦被判定为规避比价，链接会被降权处理。

错误示范：高价规格只是为了当锚点，实际不备货。

错在哪：买家拍下高价规格后你发不出货，构成虚假发货，处罚比虚假宣传更重。

> **【规则提示·2026规则修正】** 原做法“用阴阳SKU、换文字换图躲比价、放炮灰SKU卡价格排序”已属违规。依据：比价系统已跨店跨平台按规格语义聚类，规避动作可被识别；低价引流另有专项稽查。合规替代：用真实差异化做区隔，包括独家规格、赠品组合、定制款、真实场景图；低价规格必须是真实小规格且可发货。

**实操检查清单**

- [ ] 逐个SKU确认真实库存与真实可发货

- [ ] 无0.01元级别的虚假低价规格

- [ ] 无名称相近但货物不同的SKU

- [ ] 高价规格有真实备货

- [ ] 每个SKU图是该规格实拍

- [ ] 防比价靠真实差异化而非改名换图

- [ ] 合规检查项已写入上架检查清单

## 09 库存设置技巧与多链接策略

典型状态：库存全靠感觉填，卖爆了发现没货，只能延迟发货；另一头又怕超卖，把库存填得极少，链接刚有点起色就显示缺货。

> **问**：库存到底怎么设才不踩坑？

三条原则。第一，每个SKU独立设库存，实时更新，不用一个总数笼统覆盖。第二，代发的商品要与供应商库存同步，建立每日核对机制，供应商断货要在当天把SKU下架或改为预售。第三，缺货及时下架，不要挂着让人拍，拍到发不出就是延迟发货或虚假发货。

> **问**：报名活动时库存留1是什么意思？

这是拿比价锚点和活动流量的技巧：把这个SKU的库存先设成1，让它以最低价出现在活动提报里，报名成功之后再调回正常库存。这个做法本身合规，但要注意不能让它被真实拍光导致缺货，所以要么及时补库存，要么把这个SKU做成真实的小规格。

> **问**：一条链接不够用，要铺多少条？

分阶段。新店起步别一上来铺一堆链接，先集中打爆1条主推链接，等店铺稳定了再慢慢加。测款阶段用3到5条差异化链接，每条的主图、标题、卖点不同，放进推广计划跑5到7天，有访客有成交的留下并集中资源，没数据的下架换新。在售链接别超过3条，7天没访客没转化的直接下架。

**分步实操**

1．进“商品管理”→“商品列表”，点“编辑”，逐个SKU填写真实库存数。

2．代发商品在“代发管理”里与供应商库存建立同步关系，约定每日核对时间。

3．参加活动的SKU，先把库存设为1用于提报，报名成功后立即调回真实库存。

4．建立缺货台账，每天上午核对一次供应商发货能力和在途库存。

5．库存低于安全线的SKU，提前改为预售或下架，不要让链接挂在那里被拍。

6．测款阶段按“一图一标题一卖点”建3到5条差异化链接，全部加入同一推广计划。

7．第7天看数据，留下有成交的链接，其余下架，避免无效链接拖累店铺动销率。

**正确做法**

- 每个SKU独立库存，实时更新，不用人工估算。

- 代发商品必须做库存同步，每日核对，断货当天处理。

- 活动款库存留1是可用的技巧，但要防止被真拍光。

- 新店先集中打一条主推链接，别一上来铺一堆。

- 测款链接跑满7天就必须做取舍，不拖。

- 在售链接控制在3条以内，清掉没有访客没有转化的僵尸链接。

**常见错误**

错误示范：所有SKU共用一个库存数，随手填个999。

错在哪：超卖是必然结果，一旦发不出货就是延迟发货，缺货率上去之后链接和店铺都会被限流。

错误示范：代发商品不跟踪供应商库存，卖出去再问供应商有没有货。

错在哪：供应商断货时你已经在卖，只能延迟发货或虚假发货，罚款和扣分同时来。

错误示范：新店一次上20条链接，想碰运气。

错在哪：链接互相分散权重和推广预算，店铺动销率被拉低，最后哪条都起不来。

**实操检查清单**

- [ ] 每个SKU库存独立填写且为真实数值

- [ ] 代发商品已建立供应商库存同步与每日核对

- [ ] 活动款库存留1的SKU有补库存预案

- [ ] 已建立缺货台账与安全库存线

- [ ] 测款链接跑满7天后做过取舍

- [ ] 在售链接数量控制在3条以内

- [ ] 无访客无转化的僵尸链接已清理

## 10 以图搜货与发布同款：从找款到改写到避判重

典型状态：你想上一个和市场上热销款同类的商品，自己从零写标题、找图、填属性，一条链接做半天，效率极低，还容易漏项。

> **问**：发布同款在哪里点？

先进商家后台或用拼多多App的搜索页，用“以图搜货”上传一张你的商品图，系统会匹配出同款商品库。在结果里找到匹配度最高的那条，最好选100%匹配的，点“发布同款”。这样进来的商品，很多字段已经预填好了，而且自带一部分商品识别信息。

> **问**：发布同款之后要做哪些改写？

进到编辑页，第一件事是把原商品图片全部删掉，只留1张，换成你自己产品关联的图，然后把你自己这张图拖到图片列表最后面。标题要复制原商品标题做差异化改写，不能完全照抄，否则容易被判重复。属性基本不动，但品牌和材质这两项必须按自己的实际情况重新勾选。详情图同样处理，删掉原图只留1张，换成自己的图再拖到最后。

> **问**：怎么避免被判重复铺货？

关键在差异化。主图、标题、视频这三样是系统区分商品的主要依据，其中主图决定系统把你的商品推给谁，所以主图必须是你自己的。标题用大模型做改写也要保证语义有差异，不能只是换几个同义词。属性、规格、组合、赠品任何一项做出真实差异，都能降低被判重的概率。

**分步实操**

1．打开商家后台或App搜索页，点搜索框旁边的相机图标，上传你的商品图，执行“以图搜货”。

2．在匹配结果里按匹配度排序，找到100%匹配的那条同款，点“发布同款”。

3．进入编辑页，把商品图片全部删除，只保留1张，上传你自己的主图。

4．把自己的主图拖到图片列表最后一位，前面的位置留作对照。

5．复制原商品标题，改写核心词以外的表述，至少替换三分之一的关键词且语义有真实差异。

6．属性栏不动结构，但把品牌、材质两项按自己实际情况重新选择。

7．打开详情图，删除原图只留1张，换成自己的详情图，同样拖到最后。

8．逐项检查类目、运费模板、售后承诺，确认无误后提交。

**正确做法**

- 以图搜货选匹配度最高的同款，100%匹配的优先。

- 原图全部删掉只留1张，用你自己的图作为主展示图。

- 标题必须改写，不能照搬，改写要改到语义层面。

- 品牌和材质两项按真实情况重填，这是属性里最重要的两项。

- 详情图同样换成自己的，不要留任何原图。

- 发布同款带来的效率优势要用在“省时间”上，不要用在“省思考”上，每一项都要复核。

**常见错误**

错误示范：发布同款之后，标题一字不改直接提交。

错在哪：与原商品标题完全一致，容易被判定为重复铺货或抄袭，链接被降权处理。

错误示范：原图留着不动，只把自己的图加在最后。

错在哪：主图是系统判断商品归属和推荐人群的核心依据，原图在前等于把流量导向别人的商品识别；同时使用他人商品图有侵权风险。

错误示范：为了省事把品牌和材质按原商品照抄。

错在哪：品牌冒用是售假风险，材质不符属于商品描述不符，两项都是高等级违规。

> **【规则提示·2026规则修正】** 原做法“发布同款后直接同步竞品数据、靠报名某个活动把竞品销量和买家秀搬过来”不成立。依据：平台不会把竞品的销量与评价同步到你的链接，报名活动拿到的是活动标签和对应流量。合规替代：用多多进宝以真实佣金做破零，用包裹卡引导真实带图评价，前20条评价重点维护。具体活动名称与门槛以后台当前活动名称为准。

**实操检查清单**

- [ ] 以图搜货选取的是匹配度最高的同款

- [ ] 原商品图已全部删除，仅保留1张作为对照

- [ ] 自己的主图已上传并置于图片列表末位

- [ ] 标题已做语义层面的差异化改写

- [ ] 品牌与材质属性按自身实际情况重填

- [ ] 详情图已全部换成自有图片

- [ ] 类目、运费模板、售后承诺逐项复核过

- [ ] 使用的所有图片素材均为自有或已授权

## 11 尺码关联：同款只差规格就该关一个链接

典型状态：同一款衣服的S、M、L、XL你分了四个链接发，每个链接都从零开始积累销量，四个链接加起来还不如别人一个链接卖得多。

> **问**：什么情况该做尺码关联？

同款只差规格的，全部挂在同一个商品下，不要拆开。包括同款不同尺码、同款不同颜色、同款不同容量、单品与组合装。这样做有三个好处：权重共享，一个码卖爆，其他码跟着吃同一份销量、评价和人群标签；低价引流规格能拉动整条链接的点击率，系统给整条链接加权；真实尺码差异属于合理SKU，不会被判定重复铺货。

> **问**：什么情况反而要拆成独立链接？

不同产品、不同功能的必须拆，比如T恤和裤子本来就该是两个链接。测款找方向的时候也要拆，同一个产品想做三到五条差异化链接，一个主图打“补水”、一个打“敏感肌”，分头跑数据，筛出能跑的再集中资源。差异大到算两个品的款，比如不同风格、不同人群，也拆。

> **问**：关联尺码之后，对转化和退款有什么影响？

影响很直接。买家在一个链接里能选到全部尺码，选择成本低，转化率会明显好于分散链接。同时因为链接里有完整的尺码表，买错尺码的概率下降，退换货率跟着降。反过来，如果尺码表含糊，只写S、M、L不给厘米数据，退货率一定高。

**分步实操**

1．判断这个款属于“同款只差规格”还是“不同产品”，前者做关联，后者拆链接。

2．做关联时，在发布页把所有尺码、颜色、容量全部添加在同一个商品ID下，不要拆开。

3．按三层结构设SKU：真实引流小规格做门面、利润主款做主推、组合装拉客单价。

4．打开详情页编辑器，插入真实厘米尺码表，肩宽、胸围、衣长、袖长逐项标注。

5．在尺码表下方加一句“手工测量，误差1到3厘米”，并给出选码建议，比如身高170厘米建议选L码。

6．保存后在手机端逐项点选每个尺码，确认名称、图片、价格对应正确。

7．上架后第7天看尺码相关的退货原因占比，占比高就回去改尺码表。

**正确做法**

- 同款只差尺寸就关一个链接，共享权重、省钱起量。

- 不同产品、测新方向就拆独立链接，覆盖更多词、赛马选款。

- 引流规格用真实的小规格，不做虚假低价引流款。

- 尺码表给厘米数据，不给含糊的S、M、L。

- 注明手工测量误差，给出选码建议，把退换挡在售前。

- 新店起步别铺一堆链接，先集中打爆1条主推链接，站稳了再加独立链接测款。

**常见错误**

错误示范：同款的四个尺码拆成四个链接，每个链接单独养。

错在哪：销量、评价、人群标签被拆成四份，每个链接都从零开始，没有一个能积累到起量所需的权重。

错误示范：为了拉点击，放一个超低价的虚假引流规格，标低价但点进去买不到，或者同品不同名实际发一样的货。

错在哪：属低价引流违规，会被平台稽查处罚；引流规格必须真实可发货。

错误示范：尺码表只写S、M、L，不给厘米数。

错在哪：买家全凭猜，买错尺码的比例大幅上升，退货率和差评率同步走高，还要额外承担逆向运费。

**实操检查清单**

- [ ] 已判断该款属于关联还是拆分

- [ ] 同款所有规格挂在同一个商品ID下

- [ ] SKU结构为引流规格、主推规格、组合装三层

- [ ] 详情页已插入真实厘米尺码表

- [ ] 尺码表已注明手工测量误差与选码建议

- [ ] 引流规格真实可发货

- [ ] 上架7天后复盘过尺码相关退货原因

## 12 商品关联推荐、商品系列与评价共享

典型状态：店铺好不容易把一条链接的流量做起来了，访客进来只看一个商品，看完就走，客单价上不去，流量白白浪费。

> **问**：商品关联推荐怎么设置？

路径是：商家后台 → 商品管理 → 商品工具 → 商品关联推荐。给爆款详情页关联2到3个互补款或相似款，再挂一张凑单券。关联推荐的作用是复用流量，不产生新流量，也就是说它不能帮你拉新，只能把已经进来的访客用到极致。

> **问**：商品系列怎么用？

把同一系列、同一风格的商品归到一组系列里，买家在详情页可以看到同系列的其他款，便于连带购买。系列划分要按买家的理解来，比如按风格分、按场景分，不要按你的仓库货架分。

> **问**：评价共享是怎么回事？

同款不同规格挂在一个链接下时，评价是共享的。所以把同款规格关在一个链接里，新规格一上线就能吃到已有评价，转化起点比独立链接高得多。这也是为什么同款不该拆链接。

**分步实操**

1．进商家后台，点“商品管理”，再点“商品工具”，打开“商品关联推荐”。

2．选择流量最好的那条主推链接，在关联位添加2到3个互补款或相似款。

3．关联商品的价格要比主推款略低或持平，作为凑单引导，不要把高价款放在关联位。

4．在关联区域同时配置一张凑单券，让买家加购后能直接享受优惠。

5．打开“商品分组”或“店铺分类”，按风格或场景建立商品系列，把同系列商品归组。

6．在店铺首页配置对应的导航入口，让买家能顺着分类找到系列商品。

7．上架后每周看一次关联位的点击数据，转化差的关联商品换掉。

**正确做法**

- 关联推荐只做流量复用，别指望它拉新。

- 关联2到3个就够，太多反而分散注意力。

- 关联商品选互补款或相似款，价格与主推款匹配。

- 商品系列按买家理解划分，不按仓库货架分。

- 同款规格关在一个链接里，让新规格直接吃已有评价。

- 关联效果按周复盘，把不转化的换掉。

**常见错误**

错误示范：关联位挂10个商品，什么都想推。

错在哪：买家注意力被分散，关联点击率被拉低，等于没做。

错误示范：把同款不同尺码拆成多条链接，指望各条独立积累评价。

错在哪：评价被拆散，新链接从0条评价起步，转化率长期起不来。

错误示范：店铺不做任何分类，所有商品混在一起。

错在哪：买家进来找不到想要的款，跳失率上升，连带购买的路径根本不存在。

**实操检查清单**

- [ ] 主推链接已配置2到3个关联商品

- [ ] 关联商品价格与主推款匹配

- [ ] 关联区域已配置凑单券

- [ ] 已按风格或场景建立商品系列

- [ ] 店铺首页已配置对应导航入口

- [ ] 每周复盘关联位点击数据并汰换

## 13 详情页结构：模块顺序决定买家留不留

典型状态：详情页整页照抄同行，图片模糊、顺序混乱，买家划两下就退出。上架一周，停留时长不到15秒。

> **问**：详情页应该放几张图？

建议5到8张，最多不超过10张。图片太多加载慢，反而拉高跳失率。移动端首屏决定了买家留不留，第一张图必须把核心卖点说清楚。

> **问**：模块顺序怎么排？

按AIDA结构排：首屏直击痛点并给出解决方案 → 中部放卖点图、材质说明、对比图、使用场景图 → 尾部放信任背书，包括质检报告、资质、销量、好评截图、售后承诺。拼多多用户决策快、耐心低，所以文案要短，多用大字利益点和实拍对比，少用长段描述。

> **问**：尺寸和体积有什么要求？

图片宽度建议750像素，高度控制在1000到1500像素之间，单张压到200到500KB。格式优先用WebP或JPG，不要放超长拼接大图。图太大加载慢，移动端用户等两秒就退出去了。

**分步实操**

1．进“商品管理”→“商品列表”，点开链接的“编辑”，进入详情页编辑器。

2．先做首屏：一张实拍主视觉图加一句痛点文案，比如“夏天穿衬衫最怕闷汗”。

3．第二屏放解决方案：产品整体图加卖点文字，卖点不超过5个字一条。

4．第三到第五屏放细节图：材质特写、做工细节、使用场景，每张图配一句短文案。

5．加入一组真实对比图：使用前与使用后的对比，或者与普通款的对比，注意不涉及功效夸大。

6．尾部放信任背书：质检报告、品牌授权、售后承诺，比如“48小时发货”“坏了包赔”。

7．全部图片用工具压缩到200到500KB，宽度统一750像素。

8．保存后用手机端从头划到尾，记录完整浏览需要几秒，超过20秒就删图。

**正确做法**

- 首屏给结论，痛点加方案，不要卖关子。

- 卖点前置，多数买家懒得翻到最后几屏。

- 图多不如图准，5到8张够用。

- 排版用大字利益点加实拍对比，少用长文案。

- 售后承诺标签要写上，“48小时发货”“极速退款”“坏了包赔”能明显降低决策门槛。

- 图片全部压缩，加载快等于转化高。

- 详情页必须原创，整页照抄同行既是同质化，也可能构成侵权。

**常见错误**

错误示范：详情页整页照抄同行，连水印都没去掉。

错在哪：同质化严重导致系统无法区分商品，侵权投诉一旦成立会被下架，多次违规会影响店铺权重。

错误示范：详情页放十几张超长拼接大图，单张好几兆。

错在哪：移动端加载缓慢，买家等不到图出来就退出，跳失率飙升，转化率直接崩塌。

错误示范：把最有吸引力的卖点放在详情页最后一屏。

错在哪：绝大多数买家看不到那么后面，等于没写。

**实操检查清单**

- [ ] 详情图数量在5到8张之间

- [ ] 首屏为痛点加方案的组合

- [ ] 卖点排布在前三屏内

- [ ] 图片宽度750像素、单张200到500KB

- [ ] 尾部有质检或售后承诺背书

- [ ] 详情内容为原创，未整页照搬

- [ ] 手机端完整浏览时长控制在20秒内

## 14 主图上传顺序与白底图位置：上架时的设置动作

典型状态：主图随手传了五六张，顺序乱的，白底图干脆没传。后来想报活动，系统提示缺乏白底图，报不上。

> **问**：主图上传顺序怎么排？

第一张放点击率最高的图，这张图的点击率要到推广后台“添加创意”里跑一轮测试才能确定，不要凭感觉选。第2到第4张做成和第1张同风格的图，平台大概率在前四张里随机展示，如果第2到第4张放的是细节图，买家刷到的时候根本不知道你卖什么。第5张起依次放细节图、使用场景图、产品背书图、买家痛点图。最后一张放白底图。

> **问**：白底图在拼多多有多重要？

白底图是资源位的入场券。未上传白底图，大部分活动资源位报不上。白底图的独立上传入口在“商品素材”里，要求纯白背景、主体居中、无文字无水印无拼接。

> **问**：只传主图够不够？

不够。除了主图，还要在“商品管理”→“商品素材”→“图文素材”里分别上传白底图、长图、场景图三类。这三类图对应首页、搜索页、场景页、店铺页、分类页、频道页与活动页等多个曝光渠道，不传就拿不到对应渠道的曝光。

**分步实操**

1．进“商品管理”→“商品列表”，点开链接的“编辑”，进入图片区域。

2．第1张位置上传经推广创意测出点击率最高的图。

3．第2到第4张上传与第1张同风格的图，不要放细节图。

4．第5张起依次上传细节图、使用场景图、背书图、痛点图。

5．最后一张位置放白底图，白底图要求纯白背景、主体居中、无文字无水印。

6．另外进入“商品管理”→“商品素材”→“图文素材”，分别上传白底图、长图、场景图。

7．保存后打开手机端，从第1张划到最后一张，确认顺序与展示效果。

**正确做法**

- 首图用数据选，不用审美选。

- 第2到第4张保持与首图同风格，保证买家在任何一张被展示时都知道你卖什么。

- 白底图放在图片列表最后一张，同时在“商品素材”里单独上传一份。

- 白底图、长图、场景图三类都要传，漏一类就少一类渠道曝光。

- 主图文字限制在10个字以内，不遮挡主体，不做牛皮癣。

- 主图尺寸不低于750×750像素，推荐1000×1000像素，单张不超过1MB。

- 上传完保存源文件备份，方便后续改图时复用。

**常见错误**

错误示范：第2到第4张放细节图。

错在哪：平台大概率在前四张里随机展示，买家刷到细节图时不知道这是什么商品，点击率大幅下滑。

错误示范：不传白底图，觉得主图够用了。

错在哪：白底图是资源位的入场券，没有它大部分活动资源位报不上，等于丢掉了活动流量入口。

错误示范：主图堆满文字和边框，做成牛皮癣。

错在哪：主图审核会被驳回，即便过审，视觉混乱也会拉低点击率，还会因为文字遮挡主体被判违规。

**实操检查清单**

- [ ] 首图是经过推广创意测出点击率最高的图

- [ ] 第2到第4张与首图同风格

- [ ] 第5张起为细节、场景、背书、痛点图

- [ ] 最后一张为白底图

- [ ] “商品素材”里已单独上传白底图、长图、场景图

- [ ] 主图尺寸不低于750×750像素、单张不超过1MB

- [ ] 所有主图无牛皮癣、无水印、无边框

- [ ] 图片源文件已备份

## 15 提交后的审核与常见驳回：照着提示改，别硬提

典型状态：商品提交后一直不显示，或者收到驳回通知，反复提交反复被驳，一个款卡了三天上不去。

> **问**：审核一般要多久？

一般即时或数小时完成，大促期间审核量大会稍慢。审核不通过时会给出驳回原因，按原因改完重新提交即可。

> **问**：常见的驳回原因有哪几类？

五类：类目不符、资质缺失、标题或详情含违规词、主图不合规、品牌冒用。这五类覆盖了绝大多数驳回情况。逐条对照提示修改，基本一次就能过。

> **问**：被驳回后一直不改，反复提交会怎样？

会触发更高等级的审核，甚至被判定为恶意提交，影响店铺权重。正确做法是每次驳回都认真读原因，改到符合要求再提交。资质缺失这一项要特别处理，需要补资质就先把商品下架，资质补齐再上。

**分步实操**

1．进“商品管理”→“商品列表”，筛选“审核中”或“审核不通过”状态，找到被驳回的商品。

2．点开驳回详情，逐条记录驳回原因，不要只看第一条。

3．把原因归类到类目、资质、违规词、图片、品牌五类中的一类。

4．对应修改：类目错的重新选类目，违规词错的用预审工具重查，图片错的重新做图。

5．资质缺失的，先去补充资质材料，包括营业执照、商标授权、质检报告等。

6．品牌冒用的，改成“其他”或“无品牌”，并核对全部文案无品牌词。

7．修改完成后重新提交，并把本次驳回原因记录到店铺的违规台账里。

**正确做法**

- 驳回原因就是标准答案，照着改，别猜。

- 一次改全，不要只改第一条就提交。

- 资质类问题必须先补材料，不要试图绕过。

- 每条链接的驳回记录都进台账，同类问题不再犯第二次。

- 大促前提前3到5天提交，给审核留出时间。

- 提交前用PC端和移动端各预览一遍。

**常见错误**

错误示范：驳回不改，反复点提交。

错在哪：反复提交会被判定为恶意行为，审核等级提高，还会连带影响店铺权重。

错误示范：驳回原因是资质缺失，却在标题上做修改。

错在哪：没解决根因，白改一轮，下次提交还是被驳。

错误示范：把驳回原因当成系统误判，直接把商品改个名字重新发。

错在哪：改名不改变被驳回的实质，新链接同样会被拦，还多了一条废链接。

**实操检查清单**

- [ ] 每次驳回都完整读取了全部原因

- [ ] 修改覆盖了全部驳回项，不只改第一条

- [ ] 资质类问题已补充材料后再提交

- [ ] 品牌项已改为“其他”或“无品牌”

- [ ] 重新提交前在PC端与移动端各预览一遍

- [ ] 驳回原因已记入违规台账

- [ ] 大促前提前3到5天提交审核

## 16 上架后验证收录、重复铺货与盗图、代发铺货没权重

典型状态：商品提交成功，后台显示在售，可是搜核心词搜不到；或者你直接从供应商那里一键铺货上架，一个月下来零权重零流量。

> **问**：怎么确认上架成功、被收录了？

三步验证。第一，在“商品管理”→“商品列表”确认商品状态是“在售”，不是“审核中”或“已下架”。第二，用拼多多App搜商品全标题，能搜到说明已经被收录。第三，搜核心词并按销量排序，看自己的商品在第几页。全标题搜得到、核心词搜不到，属于新链接权重低，正常现象，需要等数据积累。

> **问**：上架后搜不到怎么办？

先排除四个原因：类目错、标题含违规词被限流、商品还在审核中、价格异常被屏蔽。这四个都排除掉，剩下的就是权重还没起来。新链接上架3天内搜不到核心词很常见，先按CPS破零、报活动拿标签的路径把基础销量做起来，一般3到7天会逐步有搜索曝光。

> **问**：重复铺货和盗图会有什么后果？

重复铺货的判定标准是同款、同图、同标题发多个链接。判定后整店降权，严重的会限制发布。盗图是指使用了他人拍摄的商品图，平台受理原始拍摄图维权，一旦投诉成立，商品会被删除，多次违规会罚款、扣分甚至封店。

> **问**：一件代发直接铺货为什么没权重？

因为铺货过来的商品，主图、标题、属性都是供应商的，和平台上几百个卖同一款的分销商完全一样。系统无法把它和别人的商品区分开，无法判断该推给谁，只能给最低限度的曝光。要改的东西有四样：主图换成自己拍的或自己做的、标题做差异化改写、属性按自己的实际情况重填、详情页重做。这四样改完，商品才具备被识别的独特性。

**分步实操**

1．进“商品管理”→“商品列表”，确认商品状态显示为“在售”。

2．用拼多多App搜商品全标题，记录是否能搜到。

3．搜核心词并按销量排序，记录自己的商品在第几页。

4．如果搜不到，按类目、违规词、审核状态、价格异常四项逐项排查。

5．排查无果的，按CPS真实破零路径把前10到20单做出来，观察3到7天搜索曝光变化。

6．对代发商品，逐条替换主图为自己拍摄或制作的图，标题做差异化改写。

7．属性按自身实际情况重填，详情页重做，不复用供应商全套素材。

8．每周用全标题搜索抽查一次，把未被收录的商品挑出来单独处理。

**正确做法**

- 上架后24小时内完成收录验证，别等着系统自动给流量。

- 全标题能搜到、核心词搜不到，属于权重问题，走破零路径解决。

- 主图、标题、详情、属性四项必须与供应商版本有真实差异。

- 图片只用自有或已授权素材，从源头切断盗图风险。

- 多链接靠真实差异化，不靠复制，复制铺货等于全店降权。

- 建立店铺自己的图片库和文案库，铺货时从库里取素材。

- 每周抽查收录状态，把问题链接挑出来处理。

**常见错误**

错误示范：从供应商处一键铺货，主图标题详情全部照搬。

错在哪：商品与其他分销商完全同质，系统无法识别推送对象，权重几乎为零，推广费花出去也带不动。

错误示范：用浏览器插件下载竞品组图和详情图直接商用。

错在哪：属于盗图侵权，平台受理原始拍摄图维权，投诉成立商品被删，多次违规罚款扣分，严重的封店。

错误示范：同一个款复制出五个链接，只改几个字。

错在哪：属于重复铺货，系统判定后整店降权，五个链接互相分散流量，最后全部趴窝。

**实操检查清单**

- [ ] 上架24小时内确认商品状态为“在售”

- [ ] 用全标题搜索验证过收录

- [ ] 搜核心词记录过排名位置

- [ ] 搜不到时排查过类目、违规词、审核、价格异常四项

- [ ] 代发商品主图已替换为自有素材

- [ ] 标题、属性、详情与供应商版本有真实差异

- [ ] 所有图片素材为自有或已授权

- [ ] 每周抽查一次收录状态

## 17 上架前检查清单：把SOP变成团队动作

典型状态：上架漏项被罚之后才发现，当初漏掉了运费模板、漏掉了白底图、漏掉了违规词体检。每次上架都靠脑子记，每次都会漏一两个。

> **问**：上架前到底要勾哪些项？

标准顺序是：选类目 → 填属性 → 写标题（30字用满、核心词前置）→ 传主图（顺序正确）→ 传白底图 → 设SKU（三规格、真实可发货）→ 做详情（原创）→ 绑运费模板 → 过违规词体检 → 关联主图视频 → 提交审核。逐项勾完再提交。

> **问**：运费模板为什么必须单独提？

上架忘绑运费模板，系统会按全局默认运费计算，偏远地区订单很可能倒贴运费。发布时就要选好已建好的运费模板，包邮区设0元，偏远地区单独设置。

> **问**：这套SOP怎么落地到团队？

把它做成一张可勾选的检查表，每次上新打印或在线填写，谁上架谁勾。档存归档，出现问题时可以回溯当时勾了哪些项。团队新人按这张表上手，比口口相传靠得住。

**分步实操**

1．把检查清单做成一张表，按“类目、属性、标题、主图、白底图、SKU、详情、运费、体检、视频、审核”十一个区块排列。

2．每次上新前打印或在线打开表格，逐项勾选。

3．类目区块：核对类目推荐与App搜索结果。

4．属性区块：必填项填满，品牌与材质按实际情况填写。

5．标题区块：字数用满、核心词前置、预审工具零命中。

6．主图与白底图区块：顺序正确，白底图已传，商品素材里三类图已上传。

7．SKU区块：三规格布局，每个SKU真实可发货，名称用买家语言。

8．详情与运费区块：详情原创、图片压缩、运费模板已绑定。

9．体检与视频区块：违规词体检通过，主图视频已关联。

10．全部勾完后提交，把这张表归档，标注上架日期与商品ID。

**正确做法**

- 检查表是团队资产，不是个人便签，要在线共享。

- 每次上架都完整走一遍，不因为熟练就跳步。

- 每个区块至少要有一个明确可验证的动作，不能写“检查一下”这种模糊项。

- 上架后24小时内回头验证收录，未收录的立即排查。

- 每次被驳回或被处罚的原因，补进检查表，让清单自我进化。

- 新人上手第一周必须按表操作，不带教就上手等于埋雷。

**常见错误**

错误示范：凭记忆上架，熟练了就跳步骤。

错在哪：漏项是必然的，漏掉运费模板会倒贴运费，漏掉白底图报不上活动，漏掉违规词体检上线即限流。

错误示范：检查表做了但只在电脑里躺着，没人用。

错在哪：流程不落地等于没有流程，同一个错误会在不同的人身上重复发生。

错误示范：出了处罚之后只处理当次链接，不回头改检查表。

错在哪：同类问题还会再犯，损失重复支付。

**实操检查清单**

- [ ] 检查表已按十一个区块整理并团队共享

- [ ] 每次上架都逐项勾选，无跳步

- [ ] 类目、属性、标题三项在提交前复核过

- [ ] 主图顺序与白底图、三类渠道图均已上传

- [ ] SKU三规格真实可发货

- [ ] 运费模板已绑定

- [ ] 违规词体检零命中

- [ ] 提交后24小时内验证收录状态

本模块涉及的类目佣金费率区间、活动报名门槛、审核时效等数值会随类目与时期变动，具体以后台实时提示为准。
