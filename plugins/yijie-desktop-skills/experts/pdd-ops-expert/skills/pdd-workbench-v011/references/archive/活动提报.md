# 活动提报　从报名入口到避坑的全流程实操

**本模块导语**：活动是拿量最快的通道，也是赔钱最快的通道。报错一个频道，可能把历史最低价砸穿，后面三个月都缓不过来。本模块按“报名前算清三本账（货够不够、价守不守得住、售后扛不扛得住）→ 选对频道 → 报上以后怎么配合 → 活动结束怎么接住流量”这条链路，把九个活动频道的门槛、价格要求和排期规则一条条拆开，也把报名被驳回的六类原因一次说清。

本模块讲拼多多活动从“看到”到“报上”再到“跑完接住”的整条链路。活动是拿量最快的通道，也是赔钱最快的通道：报错一个频道，可能把历史最低价砸穿，后面三个月缓不过来。看完这一模块，你能自己判断该报哪个活动、价格怎么定、库存怎么锁、被驳回改哪里、活动跑完怎么不让流量掉下去。

## 01 活动全景：九个频道分别在给什么，你的品该报哪个

典型状态：打开商家后台，活动中心里一排入口，名字都认识，就是不知道点哪个。

> **问**：拼多多的活动到底分几类？

按“给什么”分三类，先把这个想清楚，再谈报哪个。

一是给标签的活动：新链接起量类活动（基础秒杀、限量七折、全网低价标等，以后台当前活动名称为准）。它当场卖不了多少，作用是给链接打上“秒杀”“全网低价”标，把点击率和转化率顶起来。

二是给流量的活动：限时秒杀、9.9特卖、领券中心、断码清仓、五折快抢、大促会场。这些是真金白银的坑位流量。

三是给背书的活动：百亿补贴。它同时给流量和信任（官方补贴、假一赔十），是品类头部的入场券。

> **问**：我的品适合报哪个？

判断顺序是固定的：先看价格力，再看销量基础，最后看库存深度。三项都不够，报什么都是白报。

| 活动 | 它给什么 | 适合的品 | 硬门槛（以后台实时提示为准） | 主要风险 |
| --- | --- | --- | --- | --- |
| 限时秒杀 | 短时爆发流量、秒杀标 | 有基础销量、想冲量的款 | 开店满30天，近30天有效评价≥50，秒杀价不高于近30天最低价 | 锁死价格力，排期爽约30天禁报 |
| 百亿补贴 | 官方背书、频道级流量 | 品牌正品、高客单、比价透明的标品 | 体验星级排名达标、覆盖24个省区市、价格不高于全网同款 | 活动期禁调价禁减库存，违规扣保证金并清退 |
| 9.9特卖、领券中心 | 低价捡漏流量、搜索加权 | 低单价走量品、清仓品 | 价格有竞争力，同款赛马 | 报上不等于有流量，赛马不过就没量 |
| 断码清仓、五折快抢 | 低门槛资源位 | 断码、临界期、清库存 | 门槛低于秒杀 | 利润极薄，只适合冲权重与回笼资金 |
| 大促（618、双11、年货节、跨店满返） | 全店流量高峰期 | 全店有货、日销稳定的店 | 所有SKU报全网最低价，且不高于审核时的售价 | 审核前抬价被驳，活动后涨价流量腰斩 |
| 竞价活动 | 单个坑位曝光 | 同款多、愿意为坑位付费的品 | 按坑位出价竞争 | 无脑加价烧钱 |
| 新链接起量活动 | 白送标签、激活权重 | 0销量0评价的新链接 | 低门槛或零门槛 | 不报就一直没权重 |
| 联合营销 | 平台券分担成本 | 靠平台活动吃饭的店 | 平台券自动叠加到你的商品 | 开了必须开票，不开票冻结货款 |
| 直播、短视频话题活动 | 内容场增量流量 | 非标、演示型、性价比对比型 | 内容合规、挂商品卡 | 毫无准备地播就是冷场 |

**分步实操**

1．进“商家后台→店铺营销→营销活动”，先看“可参与商品”里带绿勾的SKU，绿勾代表系统判定这个SKU当前符合基础条件。

2．把上表九个频道的定位抄一张纸贴在电脑边，报活动前先对一眼。

3．给每个主推款标出“当前该报哪个”，依据是价格力和销量基础，不是你想报哪个。

4．每周固定一天刷一遍活动中心，新活动、招商通知、小二邀约都在这里出现。

5．报名前先看活动标题后面的规则说明（活动时长、库存要求、是否计入历史最低价），这一步能省掉后面三次驳回。

**正确做法**

- 新链接先报低门槛标签类活动，把“0销量0评价”变成“有销量有评价”，再去报流量类活动。

- 一个链接同一时间最多报两个活动。多了价格和库存一定打架。

- 分链接提报：不同链接报不同活动，不要把所有活动压在一条链接上。

- 先记清楚哪些入口的成交价不计入历史最低价，这类入口留给最狠的价格。

**常见错误**

错误示范：哪个活动名字听起来大就报哪个。

错在哪：基础权重不够，报上高阶活动也没流量，白占一个坑位还落下一次驳回记录。

错误示范：一条链接同时报秒杀、9.9和大促。

错在哪：三个活动对价格、库存、时长要求都不一样，结果不是被比价踢下线，就是超卖。

**实操检查清单**

- [ ] 抄一份九个频道的定位与门槛对照表贴在工位

- [ ] 给每个主推款标出当前该报的活动名

- [ ] 每周固定一天扫一遍活动中心

- [ ] 确认新链接已排进标签类活动的提报计划

- [ ] 检查每个链接同时报的活动不超过两个

- [ ] 记录哪些入口的成交价不计入历史最低价

- [ ] 报名前截图保存该活动的规则页与报名页

## 02 报名入口在哪：后台从哪进，活动怎么排期不撞车

典型状态：知道要报活动，每次都在后台翻半天找不到入口；活动报多了还老是撞在一起，预算被拆散。

> **问**：报名入口具体在后台哪个位置？

主入口只有一个：商家后台→店铺营销→营销活动。进去以后看四个分区。

一是“可参与活动”，系统按你的类目和店铺层级推荐，这里有绿勾标记能报的款。

二是“活动报名记录”，看审核进度和驳回原因，被驳回的原因就写在这里。

三是“活动日历”，看接下来有哪些活动要开始，排期靠它。

四是“我的活动”，看正在跑的场次、剩余库存、实时数据。

**其他频道的入口记住这几条：**

1．百亿补贴：走“营销中心→百亿补贴报名”，或者直接在活动中心搜“百亿补贴招商”。体验星级排名靠前的店会收到邀约，邀约通道的通过率高于自己硬报。

2．秒杀：在营销活动里搜“秒杀”，再按商品类型选入口，分全类目通用、食品生鲜极速通道、品牌秒杀几类。

3．新链接起量类：在营销活动里筛“新链接”“冷启动”标签，或从商品管理页的推荐位进。

4．大促：大促期间后台首页会有会场入口和横幅；平日走营销活动里的“大促招商”。

5．直播、短视频话题：在活动中心的内容活动分区，或内容后台的话题榜。

> **问**：活动总是撞车怎么排？

先建活动日历，再定资源分配，最后才报名。

**分步实操**

1．在表格里拉出未来60天的日期轴，横轴写日期，纵轴写活动名。

2．把已知的大促日期固定填进去（年货节、618、双11这类时间基本固定）。

3．大促前14天不再排任何秒杀类活动，避免把价格力提前用光。

4．秒杀、9.9这类短周期活动错峰排，一个活动结束后间隔3天再报下一个，让系统重新采集数据。

5．同一个价格带的活动不同时报，避免自己打自己。

6．每次报名后把活动开始时间、结束时间、报名价、库存同步到日历里，每周复盘一次排期表。

**时间节奏参考**

| 时间点 | 该做什么 |
| --- | --- |
| 大促前30天 | 完成选品与资质准备，提交大促报名 |
| 大促前14天 | 锁定产能与备货，确认价格阶梯 |
| 大促前7天 | 设券、设限时限量购、备客服话术 |
| 大促前3天 | 锁活动库存、开库存预警、测试下单链路 |
| 大促当天 | 盯每波动的动销与客服回复率，控推广预算 |
| 大促后7天 | 承接流量、做价格回弹、复盘归档 |

**正确做法**

- 报名记录里的驳回原因要整段复制下来归类，同类原因出现两次就说明是系统性问题，改商品不是改文案。

- 每次报名都把报名页的价格、库存、规则版本和日期截图存到一个文件夹，规则变动时能追溯。

- 排期表要共享给客服和仓库，让发货端提前知道哪几天要爆量。

**常见错误**

错误示范：从商品编辑页随便点一个“报活动”弹窗就报了。

错在哪：那个弹窗报的是系统随机推荐的活动，很可能门槛不符，报了也是驳。

错误示范：同一周报三个不同频道的活动，都想拿流量。

错在哪：资源分散，每个活动都拿不到足够的库存深度和推广预算，三个一起哑火。

**实操检查清单**

- [ ] 收藏“店铺营销→营销活动”这个入口路径

- [ ] 建立未来60天的活动日历并每周更新

- [ ] 大促前14天停止排短周期秒杀

- [ ] 把驳回原因整段复制归类留档

- [ ] 每次报名截图保存规则页与报名页

- [ ] 把排期表同步给客服与仓库

- [ ] 每个链接同时在跑的活动不超过两个

## 03 报名前先算三本账：货够不够、价守不守得住、售后扛不扛得住

典型状态：活动报上了，跑完一算亏钱；或者爆单发不出，被扣虚假发货。

> **问**：报名前到底要想清楚哪三件事？

货、价、售后，三件事缺一件都会翻车。

第一本账是货：活动预计卖多少件，你的库存加产能能不能跟上，补货要几天。

第二本账是价：这个活动价跑完是赚是亏，亏多少，亏的钱换回来什么。

第三本账是售后：活动期退款率通常比日常高2到5个百分点，客服和发货能不能扛住，扛不住就伤体验分，体验分一掉后面所有活动都报不上。

> **问**：活动降价空间怎么预留？

在上架定价那一天就要把活动要打的最深折扣算进去，不能等报了活动再倒推。

**算例（把数字代进去照算）**

某款产品：产品成本12元，快递费4元，包装1元，平台技术服务费按0.6%计，日常退货率10%。

1．算真实保本成本：三项硬成本合计12＋4＋1＝17元。保本成本＝17÷（1－0.1－0.006）＝17÷0.894＝19.02元。也就是说，到手价低于19.02元就是纯亏。

2．算日常价：目标净利15%，日常到手价＝19.02×1.15＝21.87元，取21.9元。

3．反推活动折扣：21.9元的8折是17.52元，比保本成本19.02元还低1.5元，这个折扣碰都不能碰。21.9元的9折是19.71元，每单只赚0.69元，属于微利冲量，可以接受。

4．得结论：这个品只能报“9折以内”的活动。想报更深的折扣，先把成本压下来——要支撑17.52元的活动价，硬成本必须降到17.52×0.894＝15.66元以内，也就是现在17元要砍掉1.34元。

5．反过来验证：如果活动价定在保本线上加5%微利，即19.02×1.05＝19.97元，相当于日常价的9.1折，这是这个品能报活动的最低价。

**分步实操**

1．用上面五步把每个主推款的最深可报折扣算出来，写在商品资料卡上。

2．活动前用历史日销估量：平时日销80单，秒杀场次4小时，按放大6倍估＝480单，再乘1.5安全系数＝720件。

3．备货到位再报名，不要报名通过了才去找工厂。

4．售后侧提前加人：日常3个人工客服，活动期按咨询量1.5倍配人，自动回复提前配好。

5．把退货率、纠纷率计入活动价核算，别只算货品成本。

**正确做法**

- 活动前先写一句“获值/获损”：这次活动我想拿到什么（标签、坑产、评价、老客），最多愿意亏多少钱，写在纸上。

- 亏的钱要有明确用途，比如换标签、换坑产、换评价，没用途的亏就是白亏。

- 价格体系提前分层：引流款让利冲量，利润款守价赚钱，两条链接分开报活动。

- 上架时就把价格阶梯留出来：日常价、券后价、活动价三层，互相之间留2到3元的空间。

**常见错误**

错误示范：日常价已经贴着成本卖，还去报7折活动。

错在哪：活动价直接击穿保本线，卖得越多亏得越多，而且这个价会被记进历史最低价，后面想涨回来流量就断。

错误示范：只算货品成本，不算运费、包装、退款和平台费。

错在哪：账面毛利看着有40%，实际扣完只剩个位数，活动一放大就是几万块的窟窿。

**实操检查清单**

- [ ] 用保本公式算出每个主推款的真实保本成本

- [ ] 把每个款的最深可报折扣写进商品资料卡

- [ ] 按日销×放大倍数×1.5算出活动备货量

- [ ] 报名前完成备货或锁定产能

- [ ] 写下本次活动的获值与获损上限

- [ ] 活动期为客服与仓库配足人手

- [ ] 把退货率与纠纷率计入活动后的结算

## 04 活动库存怎么设：设少了进不去，设乱了会超卖

典型状态：活动库存和日常库存混在一起，活动一爆就超卖；或者库存只填了几十件，报名直接被驳回。

> **问**：活动库存设多少才合适？

一条原则：活动库存单独锁，和日常库存分开算，建议不低于500件。

原因是报名审核时会校验库存深度。库存填10件却去报万人团级别的活动，系统直接判不通过。有些频道还明确要求库存深度达到活动预估销量的2倍，达不到就往后排。

> **问**：活动库存能不能中途改？

分频道看，规律是秒杀类审核通过后只能增加不能减少，百亿补贴类活动期间禁止减库存，违规扣保证金。

**分步实操**

1．先算活动预估销量：平时日销×场次时长对应的放大倍数。日销80单、4小时场次按放大6倍估＝480单。

2．乘安全系数1.2到1.5，得到备货总量。480×1.5＝720件。

3．活动库存按备货总量的七成设：720×0.7≈500件。剩下的200多件留给日常售卖，避免活动期间日常订单无货可发。

4．在营销工具里给这个款单设库存上限，避免活动价被日常订单吃掉库存。

5．开库存预警：剩余库存低于30件时提醒，低于10件时立即决策是补货还是下活动。

6．活动结束当天把剩余锁定库存释放回日常池，别让库存一直挂着。

7．百亿补贴这类频道库存售罄后要在24小时内补齐，不补会影响后续报名资格。

**正确做法**

- 备货量按“预估销量×1.5”准备，供应商侧签一份应急补货协议，写明48小时内可补多少件。

- 代发模式必须备双供应商，一家断货另一家能接。

- 活动库存和日常库存分池管理，用表格记清楚哪个池子扣了多少。

- 参加大促的款提前3天试跑一次下单链路，确认库存扣减正常。

**常见错误**

错误示范：活动库存和日常库存共用一个数，活动价一开就被抢光，日常订单发不出货。

错在哪：日常订单超时发货会被扣虚假发货，罚金按单算，一次大促能把利润罚没。

错误示范：为了报名成功，库存随手填个500件，实际只有80件货。

错在哪：卖出去发不出，超卖订单要么赔付要么被平台判定虚假发货，还会拉低体验分，后面所有活动都报不上。

> **【规则提示·2026规则修正】** 原做法（虚报活动库存、先占坑位再补货、报上以后再把库存调小）已属违规。依据：库存造假、虚假库存占位属于平台重点治理的作弊行为，取消活动资格并扣分。合规替代：按真实可发货库存提报，用“预估销量×1.5”的方式准备货，货不够就先报低门槛小活动。

**实操检查清单**

- [ ] 活动库存与日常库存分池管理

- [ ] 活动库存设置不低于500件并留出余量

- [ ] 备货量按预估销量×1.5准备

- [ ] 供应商应急补货协议已签署

- [ ] 代发款已备好第二供应商

- [ ] 活动前3天完成下单链路测试

- [ ] 活动结束后当天释放锁定库存

- [ ] 售罄后24小时内完成补货

## 05 限时秒杀：报名条件、价格要求、库存要求一次说清

典型状态：想做秒杀，但不知道自己的店和款到底够不够条件，报了几次都被驳。

> **问**：秒杀的报名条件是什么？

分店铺条件和商品条件两块，两块都要过。

店铺这块：企业店和个人店都能报，企业店审核优先级略高；开店满30天；近90天无严重违规（虚假交易、售假、虚假发货都算）；店铺综合体验星级达到该活动的报名要求，部分类目门槛更高。

商品这块：近30天有效评价不少于50条；近30天有效GMV达到该活动的门槛；价格有竞争力。

> **问**：价格和库存有什么硬要求？

价格必须是真低价：秒杀价不能高于近30天最低成交价，平台会对全网同款做比价。

库存报名时填总库存，审核通过后只能增加不能减少，分时段释放，一般每2小时一波。

> **问**：坑产不够怎么办？

秒杀系的进阶活动普遍看坑产（近7天销售额）。有一类进阶秒杀活动明确要求近7天每天销售额达到5000元，达不到就报不上，以后台当前活动名称为准。

补齐坑产的合规路径是把日常销量做起来：靠真实成交、场景券、推广加权，把近7天的日销稳定顶到门槛线以上，再报下一个台阶的活动。

**分步实操**

1．登录商家后台，进“店铺营销→营销活动”。

2．搜“秒杀”，按商品类型选入口，分全类目通用、食品生鲜极速通道、品牌秒杀。

3．在“可参与商品”里勾选带绿勾的SKU。没有绿勾的点“查看原因”，常见原因是SKU缺货、标题有特殊字符、主图有牛皮癣、未上传白底图。

4．填活动库存（不低于500件，按测算留余量）、秒杀价（等于或低于历史最低价）、限购数量。

5．提交后等审核，一般1到3个工作日，人工比价择优。

6．审核通过后只加不减库存，按每2小时一波的节奏盯动销。

7．第一轮尽量在24小时内秒完，系统会据此给出下一轮更好的建议价与坑产要求。

8．平台可要求寄样备查，实际销售的型号、规格、功效、效期必须与提报描述一致，临界保质期的商品不能报正期场次。

**正确做法**

- 秒杀定价定在微利或持平，别定在亏损线上。秒杀的价值是换权重、换标签、换复购，不是单场赚钱。

- 第一轮数据最重要，把最好的主图、最足的库存、最顺的客服都给第一轮。

- 秒杀是百亿补贴的前置跳板：系统会看秒杀前30分钟的库存消化速度判断你的承接能力，消化达标才逐步放开更高阶入口。

- 连续提报时每一轮结束都优化主图和评价，再报下一轮。

- 报名前查近7天有没有虚假发货、延迟发货、滥发信息类违规记录，有就先处理。

**常见错误**

错误示范：为了报上秒杀，把价格一路往下砍，砍到成本线以下。

错在哪：这个价会进入历史最低价体系，后续所有活动的报名价都被它卡住，价格力被自己锁死。

错误示范：审核不通过，改都不改，用同一个款反复硬报。

错在哪：驳回原因通常是图、标题、SKU或价格中的某一项，不改就永远是同一个结果，还浪费排期。

错误示范：主图带文字水印、牛皮癣，标题里材质和规格写不清。

错在哪：这是最高频的驳回原因，材质不清、规格不清、缺卖点三项占了驳回原因的很大比例。

**实操检查清单**

- [ ] 核对开店时长、近90天违规记录、店铺综合体验星级

- [ ] 确认商品近30天有效评价不少于50条

- [ ] 检查主图尺寸750×750以上、无文字水印、已上传白底图

- [ ] 标题写清材质、规格、卖点

- [ ] SKU不缺码、不随机发货、规格文字清晰

- [ ] 活动库存不低于500件且可补货

- [ ] 秒杀价不低于保本成本线

- [ ] 寄样商品与提报描述逐项核对一致

## 06 秒杀排期与坑产：定了上不了，要在开始前72小时取消

典型状态：排期定下来了，货还没到、价还没谈好、客服还没排班，活动眼看要开始，不知道能不能撤。

> **问**：排期定了但上不了，能取消吗？

能，但有硬时限：因自身原因无法进行的，必须在距离活动开始不少于72小时在后台取消。晚于72小时或者直接爽约，30天内禁止参加任何活动，以后台实时提示为准。

取消动作本身也有成本：取消次数多了，后续报名的审核优先级会下降。所以取消是止损手段，不是常规操作。

> **问**：连续提报秒杀怎么把坑产冲上去？

按阶梯往上走，一级一级放大流量池：

1．基础秒杀类活动：门槛低，主要用来打“秒杀标”、拉第一批真实单量。

2．冲量类秒杀（百万爆款、光速秒杀这一类）：要求更高的近30天数据。

3．坑产门槛类秒杀：明确要求近7天每天销售额达到5000元。

4．万人团、千万爆款团：流量池最大，对坑产与承接能力要求最高。

上面这些活动名以后台当前活动名称为准。直接报高阶活动通过率极低，即使侥幸通过，基础权重不够也拿不到流量。

**坑产缺口算例**

门槛是近7天每天销售额5000元，也就是近7天总销售额要达到35000元。你近7天实际做了28000元，缺口7000元。日均缺口1000元。按客单价35元算，每天要多出约29单真实成交。

补齐方式只有两种：一是用场景券把转化率提上来，二是用推广把这29单买进来。假设推广投产比3，多花约340元推广费换来1000元销售额，这340元就是“买坑产”的成本。算出这个数，你才知道为了报下一轮活动花这笔钱值不值。

> **问**：秒杀之后马上能报下一轮吗？

不建议连着报。上一轮结束后，先优化主图和评价，间隔2到3天再报下一轮，让系统重新采集数据。每一轮结束时把主图、SKU、评价都改一遍，第二轮通过率和场次权重会更好。

**分步实操**

1．排期确认后立刻把活动开始时间、库存量、活动价同步到仓库和客服排班表。

2．倒排时间：活动开始前3天完成备货，前1天完成库存锁定与下单链路测试。

3．每2小时看一次场次动销，第一轮争取在24小时内卖完。

4．每轮结束当天做一次小结：卖出多少件、客单价多少、退款多少、加购多少。

5．确实上不了，在开始前72小时以上提交取消，并同步通知仓库停准备。

6．报下一轮之前，先复查近7天销售额是否达到该活动的坑产门槛。

**正确做法**

- 排期拿到后先确认三件事：货到没到、价格批没批、人排没排，三件齐了才敢接。

- 冲坑产只走真实成交路径，用真实买家、真实订单、真实物流。

- 每轮活动之间做一次数据体检，把主图点击率和评价数作为下一轮能否报的依据。

- 秒杀场次和推广节奏对齐：活动前2小时把推广预算加上去，活动结束后收回。

**常见错误**

错误示范：排期定了，货没到，想着先上，卖不出去再取消。

错在哪：进入活动开始72小时内就无法取消，硬上会导致大量超时未发货，罚金按单计，还会留下违规记录。

错误示范：坑产差一截，就找人拍大单把销售额冲上去。

错在哪：虚假交易是治理重点，冲上去的坑产会被清除，还会被判定风险店铺，后续报名连门都过不去。

> **【规则提示·2026规则修正】** 原做法（找买手拍大额订单补坑产、自买自卖、用虚假交易冲近7天销售额）已属虚假交易违规。依据：平台按真实成交口径核算坑产，虚假订单会被识别并清除。合规替代：用场景券提升转化率、用推广真实买量、用真实老客复购把日销稳定顶到门槛线。

**实操检查清单**

- [ ] 排期确认后同步仓库与客服排班

- [ ] 活动前3天完成备货、前1天完成库存锁定

- [ ] 设置每2小时的场次动销检查提醒

- [ ] 无法执行时在开始前72小时以上取消

- [ ] 每轮结束后优化主图与评价

- [ ] 报下一轮前复算近7天销售额是否达门槛

- [ ] 全程使用真实订单，不使用任何刷单方式补坑产

## 07 百亿补贴：门槛最高，比价最狠，补贴成本要算清

典型状态：听说百亿补贴流量最大，但报了几次进不去；也有商家进去了，跑完发现利润比平时还薄。

> **问**：百亿补贴的硬门槛是什么？

店铺侧：综合体验星级排名达到活动报名要求，并且整个活动期间要持续满足。这项是动态的，中途掉下来会被下线。

商品侧：近30天评价高于行业综合值及全站综合值；配送覆盖24个省区市（含京沪粤川等）；品牌具备较强品牌竞争力与价格竞争力。

行业通行的附加条件：开店满90天、近30天订单不少于100单、店铺综合体验星级达标、好评率不低于95%、库存深度达到活动预估销量的2倍或者不少于500件。

价格侧：低于近30天最低价的10%以上，并且不高于全网同款的90%。拿到品牌黑标的商品优先入选。

> **问**：百亿补贴的比价是怎么比的？

这一条在2026年发生了变化，必须用新口径理解。

旧口径：补贴价不得高于全网最低价，这个“全网”包含其他电商平台。

新口径：自2026年3月新版《“百亿补贴”活动规则》生效后，硬性比价要求已调整为“具备较强的价格竞争力”，不再强制全网最低价。

这个变化意味着什么？不是放松了，而是换了一种考法。价格竞争力不足依然进不去，但判定不再只盯一个“全网最低”的绝对值，而是综合看你的价格在同类商品里的位置。

审核阶段仍可能要求你提供其他平台同款售价的截图作为价格凭证。拿不出凭证，会被判“无法证明价格优势”而驳回。所以凭证该备还是要备。

同一版规则还新增了两项管控：临期、过期、超期商品不得参加；商品标题与描述中不得出现“华强北”“莆田”等暗示产地的误导性词汇。这两条踩了会直接被拒。

> **问**：补贴的成本由谁承担？

平台补贴是第二重杠杆：入选商品平台会按客单价实时补贴，常见额度是客单价的10%到20%，综合控制在12%到15%，最高不超过20%。但补贴往往由商家承担或者与平台一比一分担。

费用上要分清两笔：一笔是基础技术服务费，按（消费者实付金额＋平台优惠金额）×0.6%计；另一笔是百亿补贴专项技术服务费，覆盖百亿补贴及其下挂的断码清仓、限时神券、多人团等资源位，实测区间约1.4%到4.4%。两类专项服务费择高计收，不相加。

所以报补贴之前，一定要先在报名页确认这个商品实际适用哪一档专项费率，它直接决定你这单还有没有利润。具体以报名页实时提示为准。

**补贴账算例**

某款客单价100元入百亿补贴。假设平台按12%补12元，买家到手88元。

成本侧：产品成本75元，运费4元，人工分摊1元，按百亿补贴专项服务费2%计2元，合计82元。

若补贴全部由平台承担，单件净利＝88－82＝6元，净利率6.8%，勉强可做。

若补贴由商家承担一半，即商家掏6元，单件净利＝6－6＝0元，等于白干。

这就是为什么没有供应链底气的商家进百补就是亏穿：补贴比例每多承担一点，利润就被吃干。报之前先把两件事问清楚——补贴分摊口径，以及这个类目适用哪一档专项技术服务费。

**分步实操**

1．走“营销中心→百亿补贴报名”，或搜“百亿补贴招商”。头部高分店会收到邀约，走邀约通道。

2．系统自动筛出符合基础条件的商品，从中选品。标品爆款、比价透明、到手价能做到全网最优的款最容易过。

3．填活动价（低于日常售价与近30天最低价）、库存（不少于500件）、活动时长（一般7到14天）。

4．上传品牌授权、质检报告、备案等资质原件扫描件。

5．等审核：系统比价约24小时，人工复审约48小时，期间可能被要求补充其他平台售价截图。

6．通过后按约定锁库存、发货，按规则承担补贴成本。

7．活动期间盯紧三项：价格是否失效、库存是否断、动销是否为零。

**正确做法**

- 价格凭证提前备齐：其他平台同款商品页截图，带上日期，能证明你的价格优势。

- 活动期间绝不调价、绝不减库存，违规会扣保证金并清退。

- 库存售罄必须在24小时内补齐，不补会影响后续报名资格。

- 售后响应时效顶住，投诉率控制在1%以内，超了可能被清退。

- 数字与类目资质（数码、美妆、食品的备案与授权）提前扫描存档。

**常见错误**

错误示范：为了进百补，先把标价从89元改成129元，再用“补贴前129元”衬托低价。

错在哪：这就是先涨后补，属于虚假折扣，2025年之后是重点稽查对象，轻则下线清退，重则扣分罚款。

错误示范：价格凭证不准备，硬报。

错在哪：审核方无法核实你的价格优势，直接以“无法证明价格优势”驳回，白占一次提报机会。

> **【规则提示·2026规则修正】** 原做法（先抬高标价再做“补贴前价”、用虚高划线价制造折扣感）已属虚假折扣违规。依据：平台对先涨后补重点稽查，且新版规则已把硬性比价改成“具备较强的价格竞争力”，同时明确禁止临期超期商品与“华强北”“莆田”类产地暗示词。合规替代：标价用真实吊牌价，让利靠真实券与真实补贴实现，价格凭证用真实成交截图。

**实操检查清单**

- [ ] 核对体验星级排名、店铺评分、好评率是否达标

- [ ] 确认配送覆盖省区市数量符合要求

- [ ] 准备好其他平台同款售价截图凭证

- [ ] 上传品牌授权、质检、备案等资质原件扫描件

- [ ] 问清补贴分摊比例后再核算利润

- [ ] 活动期间不调价、不减库存

- [ ] 设置库存预警并保证24小时内补货

- [ ] 投诉率与售后响应时效每日盯一次

## 08 9.9特卖：走量、打标、清仓，但别指望它赚钱

典型状态：报了9.9特卖，通过是过了，流量少得可怜；也有商家报上以后一算，每单只赚几毛钱。

> **问**：9.9特卖适合什么品、什么价格带？

适合低单价走量品、清仓品、捡漏型流量品，主流价格带集中在9.9元到19.9元，以后台实时提示为准。

它的实际收益有三项：一是打标，拿到低价标签后搜索和推荐会加权；二是破零，新链接靠它拿到第一批真实销量与评价；三是清仓，把滞销库存换成现金。

直接利润通常极薄。把9.9当成赚钱渠道的商家，最后都会失望。

**9.9 包邮的成本账**

某款9.9元包邮。产品成本6元，快递2.8元，包装0.4元，平台技术服务费0.6%即0.06元。

单件毛利＝9.9－6－2.8－0.4－0.06＝0.64元。

再计入退款：退货率按8%估，每单期望净利＝0.64×0.92－2.8×0.08＝0.589－0.224＝0.365元。

一单赚三毛六。这个账说明得很清楚：9.9这条线的价值不在利润，在标签、评价和资金回笼。

> **问**：为什么报上了却没有流量？

主因是产品核心竞争力不足，然后是赛马机制：审核时你的历史出单量、贡献营业额不够，系统匹配给你的流量自然极少。第一轮赛马之后还有第二轮更严的筛选，两轮都过不了，活动页里根本看不到你的商品。

> **问**：被驳回写“价格不满足”怎么办？

这个驳回的解决方向是让到手价更有竞争力。合规做法是真实标价加真实券：把标价定在真实吊牌价，用店铺券或平台券把到手价压下来，让系统看到的是真实让利。

**分步实操**

1．进“营销活动→9.9特卖/领券中心”选品。

2．先确认商品近期有稳定出单，没有就先做一轮小额推广把数据养起来。

3．设置有竞争力的活动价，同时配一张额度合理的券。

4．主图上传白底图，未上传白底图无法上9.9特卖这类资源位。

5．提交等审核，过审后持续盯动销，转化不够就用场景券补一把。

6．跑完把新增客户用关注券沉淀下来，别让他们只买一次。

**正确做法**

- 报名前先算清楚这一单赚多少、亏多少，把9.9当获客成本而不是销售利润。

- 引流款和利润款分开链接：引流款报9.9，利润款守正常价承接进店流量。

- SKU做真实差异化（不同数量、组合、赠品），让链接有自己的定位。

- 商品上架后尽早报名，新品期拿到标签对冷启动帮助最大。

**常见错误**

错误示范：算下来9.9是倒贴运费，还硬报，想着“先冲销量再说”。

错在哪：越清越亏，而9.9带来的客户对价格极度敏感，很难复购，亏的钱换不回资产。

错误示范：报一次没流量就放弃。

错在哪：9.9的核心逻辑是赛马，第一次没过第二轮筛选，先看主图、券、价格竞争力，优化后再报，而不是换品。

> **【规则提示·2026规则修正】** 原做法（新链接标题加“定制”二字、SKU写“拍前联系客服”、报9.9时填0.99元的建议价和100件库存，审核通过后用入口价把人引到老链接成交）已属不正当低价引流违规。依据：用低于成本、实际不发货或不可直接购买的入口价骗取流量，属于价格陷阱重点治理范围。合规替代：设置真实可发货的低价引流SKU，用真实券后价承接流量，转化环节全部在同一个商品链接内完成。

**实操检查清单**

- [ ] 算清9.9单件的毛利与退货后期望净利

- [ ] 确认商品近期有稳定出单数据

- [ ] 已上传符合要求的白底图

- [ ] 标价为真实吊牌价，让利用真实券实现

- [ ] 引流款与利润款分链接运营

- [ ] 活动后对新增客户发关注券承接复购

- [ ] 不使用“拍前联系客服”类SKU文字做入口价

## 09 断码清仓与五折快抢：清库存不惹纠纷

典型状态：仓库里压着一批断码、过季、临界期的货，想清掉又怕清出纠纷。

> **问**：断码清仓适合什么场景？

三类场景最合适：一是断码尾货，尺码只剩余码或个别码；二是过季商品，款式还有需求但季节过了；三是临界期商品，保质期剩余时间不够走正期活动。

它的门槛低于秒杀，五折快抢这类资源位门槛更低，也常被用来给新品起量冲基础权重。利润很薄，定位是回笼资金，不是盈利。

> **问**：断码怎么清才不惹退换纠纷？

一句话：把缺陷写在明面上。

标题和SKU名称直接写“断码”“随机色”“临期”，不要藏着。买家点进来第一眼就应该知道自己买的是什么。

**分步实操**

1．先把库存按码段盘点：全码齐的、只剩中间码的、只剩极端码的分开列。

2．主推中间码段，极端码（最小码、最大码）单独做低价SKU，定价按“清得掉”倒推，不按成本加成。

3．进“营销活动”，筛选“断码清仓”“五折快抢”这类入口，选品。

4．填清仓价与库存，清仓价不要高于日常价，否则拿不到流量。

5．标题与SKU写清“断码”“随机色”等实际情况，SKU规格文字保持清晰、不缺码。

6．临期、效期类商品按平台要求标注清楚保质期信息。

7．活动前把售后话术准备好，遇到尺码问题第一时间协商。

**正确做法**

- 清仓按码段分层定价，不是全码统一价。全码一个价，最后剩下的是最难卖的码。

- 清仓目标定成“7天内清掉80%”这类可量化指标，达到就停，别拖成常销款。

- 按存货成本算底线：仓储费、资金占用、季节性贬值都算进去，早清比晚清划算。

- “不退不换”这类表述不能随意写，平台的售后规则和消费者权益优先，写清了规格属性才是真正的防纠纷手段。

**常见错误**

错误示范：清仓链接只写“特价处理”，不写断码信息。

错在哪：买家收到发现尺码不对，退款纠纷集中爆发，纠纷退款率一高，活动资格直接受影响。

错误示范：清仓价定得比日常价还高，蹭清仓入口。

错在哪：入口里全是最低价的同类商品，你的价格一比就没有曝光，等于白报。

**实操检查清单**

- [ ] 完成断码库存的分码段盘点

- [ ] 主推中间码段，极端码单独设低价SKU

- [ ] 标题与SKU明确标注断码、随机色、临期信息

- [ ] 清仓价不高于日常价

- [ ] 临期商品的保质期信息按规则标注

- [ ] 设定清仓数量与时间目标

- [ ] 准备好断码纠纷的售后话术

- [ ] 清完即下架，不留常销尾货

## 10 大促：报名节奏、满减规则、价保与大促后的风险

典型状态：大促年年报，年年被驳；或者报上了，跑完一涨价流量就腰斩。

> **问**：大促的报名节奏怎么排？

大促整体周期接近一个月，分三段走：预热期蓄水（引导收藏、加购、发券预告）、正式期爆发（全力推广）、返场期捡漏（收尾与清尾货）。备货和设券要提前2周完成。

> **问**：大促报名为什么总被驳？

**四条高频原因：**

1．价格高于站内或站外同款。

2．价格高于你当前的售价，也就是报名期间偷偷抬价。

3．近30天产出不达标，先提日销再报。

4．领航员分数或商品评分波动未达线。

规则明确：所有SKU的提报价格都要是全网最低价，且不能高于运营审核时该商品的售卖价。报名期间严禁抬价。

> **问**：满减怎么报才不亏？

跨店满返按客单价和利润提报，别照搬系统建议值。

**满减算例**

某款到手价300元，参与“满300减50”，折扣率＝50÷300＝16.7%，买家实付250元。

成本侧：产品成本180元，运费12元，平台技术服务费按0.6%计1.5元，退货率10%摊薄退货成本约3元。

单件净利＝250－180－12－1.5－3＝53.5元，净利率21.4%。这个档可以报。

如果为了抢量把满减做到200减60，折扣率30%，买家实付210元，净利＝210－180－12－1.5－3＝13.5元，净利率6.4%。这个档只能在大促当天冲量时用，连报三天就是缩水经营。

> **问**：大促结束后能直接涨价吗？

不能直接跳回原价。大促亏本冲量之后，结束涨价流量会被腰斩，这是最常见的“跑完就凉”。

**分步实操**

1．大促前30天完成选品和资质准备，提交报名。

2．大促前14天锁产能、备货，确认价格阶梯。

3．大促前7天设好券：店铺满减、商品立减、关注券组合，并在活动前定稿，不要中途改。

4．大促前3天锁库存、开预警、测下单链路。

5．报名期间严禁抬价，已报领券或9.9的品会同步打大促标，不需要重复提报。

6．大促当天控推广预算，投产差不加力，先收再调。

7．大促结束后按计划做价格回落：每次涨3%到5%，间隔2到3天一次，用券托住到手价，不要一步跳回原价。

**正确做法**

- 提前做价格体系布局：不同价格段都留链接，避免大促时“无品可报”。

- 日销好、推广投产稳定的款才报大促，大促是助推器不是救命稻草。

- 券的叠加方案提前模拟一遍，确认叠加后的最低到手价仍在保本线以上。

- 大促的客服、发货、售后预案提前做，爆单当天才不慌。

**常见错误**

错误示范：大促前把价格抬上去，再用满减“打回原价”。

错在哪：这属于虚假折扣，系统按真实成交价核算，抬价既拿不到审核通过，还会被记录。

错误示范：大促期间只报了主推款，其他SKU价格没对齐。

错在哪：大促要求所有SKU都是全网最低价，漏一个低价SKU就整条链接被驳。

> **【规则提示·2026规则修正】** 原做法（用不参与比价的活动入口填高低价规格，把大促资源位卡在原价上展示，页面显示活动价、实际按原价成交）已属违规规避比价。依据：隐藏活动入口原价卡大促属于价格陷阱治理范围，比价系统按规格语义跨店跨平台聚类。合规替代：真实定价加真实让利，用限时限量购和真实券管控到手价，页面展示价与实际成交价保持一致。

**实操检查清单**

- [ ] 大促前30天完成选品与报名

- [ ] 大促前14天完成备货与产能锁定

- [ ] 大促前7天定稿券方案并模拟叠加

- [ ] 大促前3天完成库存锁定与链路测试

- [ ] 报名期间不抬价

- [ ] 所有SKU价格对齐全网最低价

- [ ] 大促当天控推广预算

- [ ] 大促后按3%到5%的梯度回落价格

## 11 报名价被“历史最低价”卡住：怎么核、哪些计入、哪些不计入

典型状态：活动价填得比日常还低，系统还是提示破价，报名被驳。

> **问**：哪些价格会计入历史最低价？

绝大多数降价行为都计入，包括：日常直接降价成交、店铺券后成交、平台券后成交、限时限量购成交、大促满减后成交。

不计入的主要有几类：秒杀价不计入历史最低价；店铺关注券带来的成交价不计入；另外有一部分活动入口在规则里明确标注“不计入历史最低价”，这类入口可以用，但要以报名页的实际规则说明与后台当前活动名称为准。

结论只有一句：历史最低价看的是真实成交价，不看你的标价。

> **问**：怎么核历史最低价才准？

**三个动作同时做：**

1．报名页填价前先看系统提示：多数活动报名页会直接显示该商品的历史最低价和全网最低价，这是最准的口径。

2．双窗口核对：近7天和近30天两个口径都看一遍，取更低的值作为上限。秒杀类活动通常看近7天，大促与部分频道看近30天。

3．导单核对：把近30天的成交订单导出，按单品实际成交价排序，看最低的那一单是多少钱、是什么活动带来的。

**算例**

某款近30天成交记录：日常成交价29.9元共420单，店铺券后26.9元共180单，秒杀场次22.9元共300单，限时限量购24.9元共60单。

计入历史最低价的成交有：29.9元、26.9元、24.9元；秒杀那22.9元不计入。

所以历史最低价＝24.9元。报名价必须不高于24.9元。填25.9元会被判破价，填24.9元刚好过线，填23.9元更稳但要多让1元的利。

按上一场景的成本口径核算：如果保本成本是19.02元，24.9元还能赚5.88元，可以报；如果保本成本是23元，24.9元只赚1.9元，这个活动只能报一轮，不能连续报。

> **问**：历史最低价太高，想清掉怎么办？

只能用真实手段抬高它。

**分步实操**

1．停掉所有会拉低真实成交价的活动，让近30天的成交价自然回升。

2．用组合装、加量规格提升客单价，让真实成交价上移。

3．把造成最低价的那个超低价SKU下架，用新规格承接流量。下架不要用编辑，编辑会改动链接数据。

4．等30天窗口滚过去，最低成交价自然被抬高。

5．在抬高期间，用“不计入历史最低价”的入口做价格展示，不动真实成交价。

6．每两周复查一次历史最低价变化，确认抬升方向正确。

**正确做法**

- 上架定价那天就规划好价格阶梯，别在上架时挂一个超低价再把后面所有活动空间堵死。

- 想打低价标签，用不计入历史最低价的入口，别用日常成交价去做。

- 报活动前把系统的历史最低价提示截图存档，避免规则口径变更后说不清。

**常见错误**

错误示范：新增一个和原来低价SKU一模一样的SKU，只改个名字，用新SKU跑7天低价计划，再把原SKU库存改成0。

错在哪：这是典型的规避历史最低价机制，换文字换图躲比价属于阴阳SKU，在2026被点名为价格陷阱重点治理。

错误示范：把日常价悄悄调高，以为调高标价就能抬高历史最低价。

错在哪：历史最低价只看真实成交价，标价调高不产生任何作用，反而会拉高比价失败率、影响点击率。

> **【规则提示·2026规则修正】** 原做法（复制一个同规格SKU仅改名去跑低价计划、用编辑或删除原规格的方式规避记录、靠改标价抬高历史最低价）已属违规。依据：比价系统按规格语义与真实成交价核算，阴阳SKU、隐藏活动ID原价卡均在重点治理范围。合规替代：用真实差异化提升客单价（不同容量、件数、组合、真实赠品），把真实成交价自然抬高，同时改用不计入历史最低价的合规入口做价格展示。

**实操检查清单**

- [ ] 报名前查看系统提示的历史最低价与全网最低价

- [ ] 导出近30天订单核对真实最低成交价

- [ ] 近7天与近30天两个口径都核对一遍

- [ ] 确认本次报名价不高于历史最低价

- [ ] 用保本成本复核报名价是否仍在盈利区间

- [ ] 抬高历史最低价只走组合装与加量等真实手段

- [ ] 把历史最低价提示截图存档

## 12 报名总被驳回：六类原因与通过率提升方法

典型状态：一个月报了七八次活动，全被驳回，每次原因还不一样。

> **问**：驳回原因集中在哪几类？

六类，覆盖了绝大多数驳回：

1．款式原因：同款过多、在售效果差、过季、近期销量差。处理方式是换品。

2．SKU原因：断码、规格不清、规格复杂、码数窄、随机发货。处理方式是补库存、把规格写清、精简SKU。

3．标题原因：材质不清、规格不清、缺卖点。处理方式是改标题。

4．价格原因：高于同款、高于当前价、破价。处理方式是调价或核对历史最低价。

5．资质原因：类目资质不齐（食品经营许可、美妆备案、品牌授权、数码发票等）。处理方式是补资质。

6．日销与评分原因：近30天产出不达标、评分波动未达线。处理方式是先养日销和评分再报。

> **问**：还有哪些看不见的门槛？

**有四项系统不提示、但会直接拒的隐形门槛：**

一是体验分与领航员：纠纷率、退货率、差评率、发货时效、客服响应等十余项，单项长期偏高会被判风险店铺直接拒。建议综合体验分稳定做到90以上。

二是商品近30天表现：销售趋势、转化率、点击率、评价。长期低迷、转化率低于1%、疑似刷单的链接很难通过。

三是价格校验：需低于近30天最低成交价，也不能高到或低到触发异常预警；库存不足（比如只设10件却报万人团级别的活动）同样会失败。建议活动库存不低于500件。

四是资质与违规：近90天无严重违规（虚假交易、售假、虚假发货），类目资质齐全。

> **问**：怎么把通过率提上去？

核心思路叫“评分超配”。多数活动要求店铺与商品评分高于行业，建议直接做到高于行业更多，让评分永远在资格线之上，而不是每次报名前才临时抱佛脚。

**分步实操**

1．提报前用体验分后台逐项自查，纠纷率、退货率、差评率、发货时效、客服响应五项逐项对着线看。

2．体验分是慢变量，提前1到2个月开始养，别等报名前再救。

3．商品侧：主图750×750以上、无文字水印与牛皮癣、已上传白底图；标题写清材质、规格、卖点；SKU不缺码、不随机发货。

4．价格侧：报名价按近30天最低成交价往下留1到2元余量，不要卡线填。

5．库存侧：活动库存不低于500件，并可提供补货能力。

6．资质侧：类目资质原件扫描存档，报名时直接上传，不要临时找。

7．被驳回后按反馈改，改完隔2到3天再报，不要当天反复提交。

**审核流程与卡点**

审核大致走三步：提交后系统比价初筛约24小时，人工复审约48小时（人工比价、择优排期），通过后排期并提前2天锁定库存。

卡点只有三处：系统比价卡价格、人工复审卡图片与资质、排期卡库存深度与评分波动。被驳回时先判断自己卡在哪一环，再改对应项，不要在价格、图片、资质三件事上乱改。

**与对接运营沟通的话术模板**

“我们这款商品近30天真实成交最低价是X元，本次提报活动价Y元，低于近30天最低成交价，也低于全网同款Z元，价格凭证已备好。现有可发货库存W件，供应商可48小时内补货。资质文件已上传，随时可以寄样。麻烦帮我们看下排期。”

**正确做法**

- 驳回原因整段复制归类，同类问题出现两次就改商品，不要再改文案。

- 图片、标题、SKU、价格四项做成提报前的固定自检表，每次报名前逐项打勾。

- 报名页的价格、库存、规则版本和日期全部截图存档。

- 体验分低的店先做服务侧的整改（客服回复率、发货时效），这是投入产出比最高的项。

**常见错误**

错误示范：被驳以后什么都不改，换个活动继续报。

错在哪：同一个根因会在所有活动里重复触发，报十次驳十次，还浪费排期机会。

错误示范：转化率只有0.5%，硬报万人团级别的活动。

错在哪：人工复审会看商品近30天表现，数据太差直接拒；即使通过，系统也不会给流量。

**实操检查清单**

- [ ] 提报前用体验分后台逐项自查五项核心指标

- [ ] 商品主图、白底图、标题、SKU四项自检

- [ ] 报名价在历史最低价基础上再留1到2元余量

- [ ] 活动库存不低于500件并可补货

- [ ] 类目资质原件已扫描存档

- [ ] 被驳回后按反馈整改，间隔2到3天再报

- [ ] 保存驳回原因归类表

- [ ] 与对接运营沟通时给出完整的价格与库存证据

## 13 竞价活动：资源位是买来的，先把回本线算出来

典型状态：听说有些资源位要靠出价抢，不知道该不该参与、出多少钱合适，参与过的又说亏。

> **问**：竞价活动到底是什么？

部分活动资源位是按出价竞争排名的，比如首页焦点位、频道页坑位这类位置。平台不直接给你定价格，而是让符合条件的商家对同一个坑位出价，价高者上、按时段轮换。

它适合的品很明确：同款多、竞争激烈、靠曝光就能起量的品类，比如标品、日用、低价易耗品。

> **问**：怎么算出价上限？

出价上限只有一个依据：你的保本投产比。

**保本投产算例**

某款售价29.9元，货品成本15元，运费4元，单件毛利10.9元，退货率10%。

保本投产＝29.9÷10.9÷（1－0.1）＝29.9÷10.9÷0.9＝3.05。

意思是每花1元推广费，至少要带回3.05元成交额才不亏。

某个坑位出价200元一天，按保本投产算，它至少要带回200×3.05＝610元成交额。按客单价29.9元算，约21单。

如果这个坑位日常只能给你带来12单，成交额约359元，投产只有1.79，远低于保本线3.05，这个价就不能出。

反过来，如果坑位能带30单也就是897元成交额，投产4.49，高于保本线，可以出，还能加价。

**分步实操**

1．先小出价测位，不要一上来就按心理价位出高价。

2．记录每个坑位的曝光量、点击率、成交额、退货率，连续记3天。

3．用保本投产比算出该坑位的出价上限。

4．实际投产高于保本线的坑位，逐步加价；低于保本线的立刻撤。

5．非黄金时段少出或不出价，黄金时段按保本线上浮20%以内出价。

6．竞价资源位与活动资源位分开记账，不要混在一起判断效果。

7．竞价期间同步盯价格力，坑位要求的价格如果比自己算的保本价还低，直接放弃。

**正确做法**

- 把竞价当成“按效果买流量”，不是“买排名”。排名本身不值钱，能回本的排名才值钱。

- 出价按自己的实际利润算，不用系统推荐出价，改价一次只调0.1到0.2元，一天最多改1到2次。

- 竞价坑位配合活动一起用：活动期上坑位，流量叠加，效率最高。

- 每周做一次坑位效果排序，砍掉后20%的坑位预算。

**常见错误**

错误示范：为了抢首页位置无脑加价。

错在哪：坑位是按天结算的，出价越高越像中标，但成交跟不上就是每天在烧钱，几天就把利润烧光。

错误示范：竞价坑位和秒杀场次同时开，价格体系没对齐。

错在哪：两个入口一个要低价一个有固定价，买家两边比价，转化率被自己拆散。

**实操检查清单**

- [ ] 算出主推款的保本投产比

- [ ] 小出价测位并连续记录3天数据

- [ ] 按保本投产算出每个坑位的出价上限

- [ ] 淘汰投产低于保本线的坑位

- [ ] 黄金时段出价控制在保本线上浮20%以内

- [ ] 竞价与活动的账分开记

- [ ] 每周做一次坑位效果排序

## 14 联合营销：开还是关，先把开票和货款冻结想清楚

典型状态：后台弹出联合营销的开通提示，不知道关了会怎样、开着又有什么义务。

> **问**：联合营销是什么机制？

简单说，就是平台券自动叠加到你的商品上，平台承担一部分券成本，同时给你的商品额外曝光。

路径在“店铺营销→平台优惠”，右侧有“关闭活动”的开关。平台当前对联合营销采取默认开通、可手动关闭的方式，具体以后台实时提示为准。

> **问**：开着和关掉各有什么利弊？

开着的好处：有平台券加持，到手价更低，转化率更好，还能拿到额外的流量加持。

开着的代价：必须给平台开票，不开票会被冻结货款。

中小卖家、平时不靠平台活动吃饭的店，建议关掉。因为券带来的额外单量往往覆盖不了开票和财务处理的工作量，还要占用资金。

> **问**：不开票会怎样？

会冻结货款。冻结额度大约是应开票金额的30%，直接从货款里扣。

开票金额等于平台一个月给你发的券总额。这笔钱和你的交税不重复：买家付90元、平台券10元的情况下，你按90元交税，给平台开票按10元开。

税率按纳税人身份走：一般纳税人6%，小规模1%，免税额度内为0%或3%，以你自己的税务口径为准。

**冻结金额算例**

某月平台发的券合计12000元。若未按时开票，被冻结约12000×30%＝3600元。

若按小规模纳税人1%开票，开票涉及的税额为12000×1%＝120元。

也就是说，为了省120元的开票成本，可能被冻3600元货款。这笔账怎么算都该开。

**分步实操**

1．先在“店铺营销→平台优惠”确认当前是开还是关的状态。

2．判断依据：这个月平台券带来的订单占比是否超过20%，超过就留着，低于就考虑关。

3．决定关闭的，在右侧点“关闭活动”，并记录关闭日期。

4．决定留着的，每月固定一天处理开票，不要拖到月底。

5．走“资金中心→营销结算→结算批次信息”，找状态为已审核通过需要开票的批次。

6．勾选对应批次，提交发票，发票内容为“现代服务-合作服务费”电子普通发票，开好后上传。

7．上传后回系统核对状态是否变为已开票，确认没有再出现待开票提示。

**正确做法**

- 把开票做成固定流程：每月固定日期、固定责任人，别等到被冻结才处理。

- 开票前先确认当月券总额，和财务对一遍数字再开。

- 关掉联合营销之前，先看这个入口带来的流量占比，避免误关掉主要流量来源。

- 券叠加的顺序要留意：新客券的优先级高于场景券，会压制场景券的流量。新链接前期的做法是先用场景券跑起来，跑稳了再加新客券。

**常见错误**

错误示范：开了联合营销，从来没看过开票入口。

错在哪：等发现货款被冻了才处理，资金周转被打断，活动期正好缺现金。

错误示范：为了省事把店铺优惠券全部叠满，认为“券越多越好”。

错在哪：券叠错会互相吞流量，到手价掉到保本线以下，成交越多亏越多。

**实操检查清单**

- [ ] 确认联合营销当前开关状态

- [ ] 评估平台券订单占比再决定开或关

- [ ] 确定每月固定开票日与责任人

- [ ] 核对当月平台发券总额

- [ ] 在资金中心按批次提交发票并上传

- [ ] 发票内容为现代服务-合作服务费电子普通发票

- [ ] 上新链接时先用场景券，跑稳后再加新客券

- [ ] 每月核对一次货款是否被冻结

## 15 新链接起量活动：0销量0评价，从标签类活动开始破局

典型状态：新链接刚上架，零销量零评价，报大活动被驳，开了推广又不出单。

> **问**：新链接该报什么活动？

报低门槛的标签类起量活动。这类活动门槛低甚至零门槛，作用是给链接打标签、激活权重。

常见的有：无门槛新品活动（给“热销标”）、全网低价标类活动（打“全网低价”标，拉转化率）、限量七折类活动（如限量七折100件），以及基础秒杀类活动。活动名以后台当前活动名称为准，路径都在“店铺营销→营销活动”里按标签筛选。

> **问**：起量路径怎么走？

**一条被反复验证过的路径：**

**分步实操**

1．用“机会商品”入口发布同款，上传差异化主图，降低被比价的概率。

2．报低门槛标签类活动，先拿基础销量与评价标签。

3．报全网低价标类活动，把点击率和转化率顶起来。

4．用限量七折类活动冲量，库存设100件，争取1到2天卖完。

5．单量起来后报基础秒杀拿全站流量。

6．再到万人团这类大流量池。

7．单量稳定后逐步把价格调回目标价。

> **问**：新品冲量花多少钱合适？

用“换什么”的逻辑算，不是用“亏多少”的逻辑算。

**冲量成本算例**

某新品日常价29.9元，报限量七折活动价20.9元，成本15元，运费4元，平台技术服务费0.13元。

单件毛利＝20.9－15－4－0.13＝1.77元。

100件合计毛利177元。这100件换来100个真实订单和约50到70条真实评价。

折算下来，每条真实带图评价的成本不到3元。对比投推广买数据的成本，这笔钱花得非常划算。

**时间节奏**

| 时间 | 动作 |
| --- | --- |
| 第1天 | 上架、真实定价加真实券、上传白底图与差异化主图 |
| 第2到3天 | 报低门槛标签类活动，拿热销标或低价标 |
| 第3到5天 | 报限量七折类活动冲量，库存100件 |
| 第5到7天 | 观察自然流量占比，确认链接是否已被系统抓取 |
| 第7天起 | 数据达标再报基础秒杀，第三天后开始小额推广 |

**正确做法**

- 新链接前3天不要开付费推广。初始权重接近0，先让平台抓取数据、跑出自然转化，再开推广。

- 分链接提报：一条链接最多报两个活动，多链接覆盖多个活动。

- 每轮活动结束都优化主图和评价，再报下一轮。

- 起量阶段的新品尽量避开同款比价，用真实差异化（规格、组合、赠品）做出自己的定位。

**常见错误**

错误示范：新链接一上架就开推广，指望推广带来流量。

错在哪：链接权重为0，点击率和转化率都不达标，推广费花出去换不回订单，钱全部打了水漂。

错误示范：新品直接报万人团这类高阶活动。

错在哪：通过率极低，即使通过，基础权重不够，系统也不给流量，白费一次提报机会。

> **【规则提示·2026规则修正】** 原做法（报名某个活动后，系统会把同款竞品的销量和买家秀同步到自己的新链接上，用别人的销量评价做基础数据）已属虚假交易、虚假评价治理范围。依据：平台不会把竞品销量与评价同步给其他链接，靠这种方式制造的基础销量一旦被稽查，会清销量、删评价、扣分限流，严重时封店。合规替代：用多多进宝设置10%到20%佣金做真实破零，包裹卡引导真实带图评价，再用真实活动提报拿标签。

**实操检查清单**

- [ ] 用机会商品入口发布并用差异化主图

- [ ] 上架当天完成真实定价与真实券设置

- [ ] 上传白底图与长图、场景图

- [ ] 第2到3天完成标签类活动提报

- [ ] 限量七折类活动库存设100件并盯动销

- [ ] 前3天不开付费推广

- [ ] 每轮活动后优化主图与评价再报下一轮

- [ ] 全程用真实成交路径积累销量与评价

## 16 活动期间怎么配合：库存、客服、发货、推广四条线一起跑

典型状态：活动刚开始两小时就爆了，客服回不过来、仓库发不出去、库存显示超卖。

> **问**：活动期要盯哪些数、多久看一次？

四个数：动销速度、转化率、剩余库存、推广投产。秒杀类场次每2小时看一次，大促期间每小时看一次。

> **问**：爆了以后怎么处理？

三条动作按顺序做：先加库存（注意有些活动审核通过后只能增不能减），再压客服和仓库，最后加推广预算。

掉量的时候反过来查：价格是不是被比价了、券是不是到期了、库存是不是被锁死、推广预算是不是烧完了。

**分步实操**

1．活动开始前2小时把推广预算加上去，集中在活动款上，非活动款预算压低。

2．活动开始后每2小时记录一次动销、转化率、剩余库存。

3．动销快于预估，立即联系供应商补货，同时检查活动库存能否增加。

4．动销慢于预估，先查价格是否被比价、主图是否被限流、券是否已领完。

5．客服侧按日常咨询量的1.5倍排班，把自动回复和快捷话术全部提前配好。

6．仓库侧提前和快递谈量，争取提前揽收，活动期的订单优先打包。

7．活动结束的次日，把推广预算降到活动期的50%，只保主推款，其余收缩。

**客服话术模板（活动期可直接复制）**

催发货：“亲，您的订单已经在加急处理，今天18:00前会交给快递，单号出来我第一时间发给您。”

规格咨询：“您平时穿L码，这款版型偏大，建议拍M码；不合适我们支持退换，您放心拍。”

价保咨询：“您下单的价格已经是活动价了，活动期内如果还有降价，您可以提交补差申请，我们会尽快处理。”

发货延迟致歉：“非常抱歉，活动期间订单量比平时大，您的包裹预计明天出库。作为补偿，给您补一张5元无门槛券，您下次下单可以直接用。”

**正确做法**

- 活动期最重要的指标是发货时效和客服回复率。48小时内必须完成从订单生成到快递揽收的全过程，3分钟人工回复率维持在不低于85%，自动回复不计入回复率。

- 活动期的价格和库存不要随手改。部分频道活动期间禁止调价、禁止减库存，违规扣保证金并清退。

- 品质退款和纠纷要当场处理，纠纷退款率直接决定活动资格。

- 活动期新增的客户当天就发关注券，把流量变成可触达的老客。

**常见错误**

错误示范：活动期只顾着看销售额，不管客服和发货。

错在哪：客服回复率掉、发货超时，体验分下滑，这次活动赚的钱在下一个月的流量里全亏回来。

错误示范：活动期看到卖得慢，随手把价格再往下调。

错在哪：部分活动禁止调价，调价会触发清退并扣保证金；同时新的低价会被记进历史最低价，把后续所有活动的报价空间压死。

**实操检查清单**

- [ ] 活动前2小时加上推广预算

- [ ] 每2小时记录动销、转化率、剩余库存

- [ ] 客服按日常1.5倍排班并配好快捷话术

- [ ] 3分钟人工回复率维持在85%以上

- [ ] 与快递确认活动期的揽收时效

- [ ] 48小时内完成发货揽收

- [ ] 活动期不改价、不减库存

- [ ] 活动结束次日将推广预算降至50%

## 17 活动后怎么接住流量：价格回弹、承接检查与复盘归档

典型状态：活动一停，流量断崖，前面花的钱全白费；或者跑完不复盘，下次还是同样的错。

> **问**：活动结束后能直接恢复原价吗？

不能一步跳回去，要按梯度回弹。

**分步实操**

1．活动结束当天保留一张小额券，让到手价只比活动价高5%以内，维持3到5天的缓冲期。

2．之后每次涨价控制在3%到5%，间隔2到3天一次，用券把到手价的波动压平。

3．主推款继续投放推广，预算降到活动期的50%，守住坑产不掉。

4．对活动新增客户在7天内发关注券或复购券，激活第一次复购。

5．检查搜索流量承接：活动期的高转化会累积权重，活动后搜索访客应当高于活动前。判断标准是活动结束7天后的搜索访客，如果低于活动前的80%，说明承接失败，要回头改主图和价格。

6．检查推荐流量：活动款的自然流量占比是否上升，只有单一活动页流量说明还没沉淀。

7．复盘归档，把本次活动的完整数据填进复盘模板。

**复盘模板（每月归档）**

| 项目 | 填写内容 |
| --- | --- |
| 活动名称与日期 | 具体频道名与起止时间 |
| 选品 | 报了哪些款、为什么报它 |
| 报名价与实际到手价 | 两个价格都记 |
| 销量与销售额 | 分日记录 |
| 退款率与纠纷率 | 与日常对比 |
| 推广费 | 活动期单独记账 |
| 毛利与净利 | 按全成本核算 |
| 流量结构 | 活动页、搜索、推荐各占多少 |
| 新增客户数 | 活动带来的新客数量 |
| 问题与改进 | 卡在哪一步、下轮怎么改 |

**活动净利算例**

某活动到手价26.9元，卖出1200件。

成本侧：货品成本15元，运费4元，平台技术服务费26.9×0.6%＝0.16元，退款率8%对应的退货损耗按每件0.32元计。单件全成本＝15＋4＋0.16＋0.32＝19.48元。

单件毛利＝26.9－19.48＝7.42元。总毛利＝7.42×1200＝8904元。

推广费2400元。活动净利＝8904－2400＝6504元，净利率＝6504÷（26.9×1200）＝6504÷32280＝20.2%。这次活动达标。

**反推两个价格看底线：**

若活动价压到22.9元，单件毛利＝22.9－19.48＝3.42元，总毛利4104元，减推广费2400元，净利1704元，净利率6.2%，还能做但空间很小。

若活动价压到19.9元，单件毛利＝19.9－19.48＝0.42元，总毛利504元，减推广费2400元，净亏1896元。这就证明了19.9元这个价位根本不能报。

**正确做法**

- 复盘要在活动结束后3天内做完，数据还热的时候做，隔一个月就想不起来细节了。

- 记录坑产和建议价的变化，这是判断下一轮能报什么活动的直接依据。

- 把退货损失、罚款、售后赔付全部计入单件成本，不要只看成交额。

- 复盘结论要能落成动作：下轮改什么价格、换哪张主图、备多少货，写清楚责任人和时间。

**常见错误**

错误示范：活动跑完就恢复到日常价，一分钱过渡都不留。

错在哪：价格跳变会让系统重新评估价格力，自然流量快速回落，活动带来的权重在几天内被抹掉。

错误示范：跑完不算账，只看卖了多少钱。

错在哪：销售额好看的场次可能是亏的，不复盘就会在下一次重复同一个错误，亏两次。

**实操检查清单**

- [ ] 活动结束后保留3到5天的小额券缓冲

- [ ] 按3%到5%的梯度分步回弹价格

- [ ] 主推款推广预算降至活动期的50%

- [ ] 7天内向活动新增客户发放复购券

- [ ] 活动后7天检查搜索访客是否高于活动前的80%

- [ ] 3天内完成复盘表填写

- [ ] 退货、罚款、售后赔付计入单件成本

- [ ] 复盘结论落成下一轮的具体动作

## 18 活动报名的四条红线：碰一条，全年活动资格都可能没了

典型状态：同行告诉你“这样报能保住利润”，你没想清楚就照着做了。

> **问**：活动报名最不能碰的四条红线是什么？

虚假报名价、先涨后补、隐藏活动ID原价卡大促、低价引流链接法。这四条在2026年是稽查重点，都会直接判违规。

另外还有三条同样不能碰的：库存造假、刷活动量、诱导站外交易。

> **问**：为什么虚假报名价违规？

虚假报名价指的是标价和真实成交价严重脱节，再用高标价去衬托活动价。比如实际卖20元的商品，标价写成99元，报名时用99元当“原价”，页面显示“立减79元”。

依据是《电子商务法》关于虚构原价、虚假优惠折扣的规定，以及平台的商品管理规则。被查实的处理包括活动下线、扣分、限制参与营销活动。

合规替代：标价填真实吊牌价，让利用真实券、真实满减实现。真实吊牌39.9元，日常成交29.9元（已含常态券），大促再叠加限时折扣到26.9元，这个26.9元才是计入历史最低价的真实成交价。

> **问**：为什么先涨后补违规？

先涨后补指的是报活动或报补贴前先把标价抬上去，制造“补贴前价格很高、补贴后很划算”的假象。

依据是平台对虚假折扣的认定。百亿补贴商品接受平台价格核验，2026年新版规则把价格门槛表述为“具备较强的价格竞争力”（原来的“不得高于全网最低价”已调整），但先涨后补与价格门槛是两回事：价格竞争力可以慢慢谈，先涨后补是直接违规。系统按真实成交价核算，抬价既过不了审核，还会留下违规记录。

合规替代：用真实低价报名，用真实价格凭证（其他平台同款售价截图）证明价格优势。

> **问**：为什么隐藏活动ID原价卡大促违规？

这种做法是利用某个不参与比价的活动入口，填一个高价规格或者零库存的炮灰规格，把大促资源位的展示价卡在原价上，页面显示活动标、实际按原价成交。

依据是平台对价格陷阱的治理：比价系统按规格语义跨店、跨平台聚类，靠入口差异躲避比价会被判定为规避行为。

合规替代：真实定价加真实让利，用限时限量购和真实券管控到手价，页面展示价与实际成交价保持一致。

> **问**：为什么9.9引流链接法违规？

做法是在新链接标题里加“定制”二字、SKU里写“拍前联系客服”，报9.9特卖时填0.99元的建议价和100件库存，审核通过后靠这个入口价吸引咨询，再把买家引导到另一个链接成交。

依据是平台对不正当低价引流的治理：用不可直接购买、实际不发货的低价入口骗流量，属于价格陷阱。

合规替代：设置真实可发货的低价引流SKU，用真实券后价承接，所有转化在同一个商品链接内完成。

**分步实操**

1．报名前把标价、日常成交价、活动价三个数字列在一张纸上，确认标价有真实吊牌依据。

2．检查页面宣传语：不出现“原价XX元”“划线价XX元”这类没有成交依据的表述。

3．确认活动价是真实让利，不是靠抬高标价反衬出来的。

4．核对所有参与活动的规格，不设置零库存的炮灰规格来卡展示价。

5．检查标题和SKU文字，不出现“拍前联系客服”“定制专拍”这类误导性文字。

6．检查活动库存是否真实可发货，不虚报库存占坑位。

7．活动期的成交额全部来自真实订单，不用自买自卖、不找买手刷量。

8．所有引导都在平台内完成，不在包裹、客服话术里引导站外交易。

**正确做法**

- 把“真实”三个字当成活动运营的底线：真实标价、真实让利、真实库存、真实成交、真实评价。

- 想保住利润，方向是压成本、做差异化、提客单，不是找规则漏洞。

- 差异化要做真的：不同容量、不同件数、不同组合、真实赠品、真实使用场景图。靠改文字躲比价不算差异化。

- 每季度做一次合规自查，把价格、文字、图、库存四项逐条过一遍。

**常见错误**

错误示范：听人说“标价写高一点，报名时折扣看起来才大”，就去改了标价。

错在哪：虚假折扣被查实的代价是活动权限和扣分，一条链接的违规会影响整个店铺的活动报名资格。

错误示范：为了拿到大促资源位，设一个零库存规格把展示价卡住。

错在哪：比价系统按规格语义聚类，炮灰规格会被识别；一旦判定规避比价，轻则掉资源位，重则限制活动资格。

> **【规则提示·2026规则修正】** 以上四条老打法（虚高标价再发券、报补贴前先涨价、隐藏活动入口原价卡资源位、用不可购买的入口价做9.9引流）已属违规。依据：虚构原价与虚假折扣、价格陷阱与不正当低价引流、规避比价是2026年重点稽查方向，比价系统已实现跨店、跨平台、按规格语义实时聚类。合规替代：真实吊牌价加真实券、真实定价加真实让利、真实可发货的引流SKU、真实差异化（规格、组合、赠品、场景图）建价格力。

**实操检查清单**

- [ ] 标价均有真实吊牌价依据

- [ ] 页面不出现无成交依据的划线价表述

- [ ] 活动价是真实让利，不靠抬标价反衬

- [ ] 不设置零库存炮灰规格卡展示价

- [ ] 标题与SKU不出现拍前联系客服之类误导文字

- [ ] 活动库存真实可发货

- [ ] 活动成交全部来自真实订单

- [ ] 全流程在平台内完成，不诱导站外交易
