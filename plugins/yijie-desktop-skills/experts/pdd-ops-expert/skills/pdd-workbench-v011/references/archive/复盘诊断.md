# 复盘诊断　用数据定位病因，再给对应的解药

**本模块导语**：店铺出问题，多数不是你不努力，而是你在治错地方——流量掉了去改详情，转化掉了去加推广费，退款高了去求平台。数据的作用不是记录结果，是帮你把病因锁到一个具体环节上。本模块把拼多多后台的看板、指标口径、判断阈值、诊断顺序全部拆开讲，给你一套从“发现异常”到“锁定环节”再到“开药方”的完整流程。看完你能自己判断：流量是掉了还是被限了，转化低是图的问题还是价的问题，退款高是货的问题还是描述的问题，以及每周每月该复盘的到底是哪几个数。

## 01 数据中心看板这么多，每个看板到底该看什么

典型状态：你每天打开商家后台，点进“数据中心”看一眼成交金额，数字还行就关掉。看板有十几个，不清楚每个看板解决什么具体问题，数据看了很多，问题一个没找出来。

> **问**：后台这么多数据入口，各自管什么，我该按什么顺序用？

**分步实操**

1．打开商家后台→数据中心→实时看板。这里看当天的访客、支付转化率、支付件数、成交金额。定位是“体温计”，用来第一时间发现异常，不做深度分析。

2．进数据中心→流量数据（流量分析）。这里拆访客结构：推荐流量、搜索流量、活动流量、付费流量各占多少，以及搜索词明细、访客人群画像。定位是“来源地图”。

3．进数据中心→商品数据（商品分析）。这里看每一款商品的访客、浏览量、支付件数、支付转化率、退款笔数。定位是“分科室体检”，出了问题先来这里找是哪一款。

4．进数据中心→交易数据（交易分析）。这里看客单价、支付件数、退款金额、退款率、老客占比。定位是“算账本”。

5．进数据中心→行业大盘（行业数据）。这里看类目走势、价格带分布、行业热搜词。定位是“天气预报”，判断市场在涨还是在退。

6．进服务中心→服务数据→店铺领航员。这里看体验分各项与行业排名的对比。定位是“资格证”，排名直接决定能拿多少自然流量。

7．进推广中心→推广报表（计划、单元、关键词三层）。这里看花费、成交金额、成交笔数、投产比。定位是“花钱流水”。

8．进后台的成长与分层入口。这里看店铺成长等级与升级进度。定位是“段位”，等级反映的是真实经营质量，不要指望靠冲单量把它推上去。

9．把上面八个入口按“每小时看、每天看、每周看”三类贴上标签，形成固定的巡查顺序。

**正确做法**

- 一个看板对应一个判断。看板不是用来逛的，逛完不产生结论等于没看。

- 每天只在自己建的“日盯表”里填数，后台各页面只当取数来源，避免每次都要重新翻一遍菜单。

- 实时看板的数据会随当天推进不断变化，判断趋势必须用两天以上的同口径数据，不能拿今天上午的数去比昨天全天的数。

- 每看一个看板，写下一句话结论，例如“今天的搜索流量占比从42%掉到28%”。有结论的复盘才是复盘。

**常见错误**

错误示范：只在实时看板盯成交金额，金额掉了才去找原因。

错在哪：成交金额是链条最末端的结果。等它掉下来，问题至少已经发生一天以上。你要盯的是它的前三层——曝光、点击率、支付转化率。

错误示范：把推广报表当成唯一的数据源。

错在哪：推广报表只覆盖付费流量。自然流量掉了在推广报表里看不出来，你会误判成“花钱不够”，于是一边加预算一边掉自然流量，越投越亏。

**实操检查清单**

- [ ] 把八个看板入口逐个点开，各截图存一份

- [ ] 给每个看板写一句“它管什么”，贴在办公桌或群里

- [ ] 建一张日盯表，字段固定为访客数、支付转化率、客单价、支付件数、退款率、投产比

- [ ] 在领航员页面记下当前各项排名与更新时间

- [ ] 在后台成长与分层入口记下当前等级与升级进度

- [ ] 把日盯表设为每天上午10点和晚上8点各填一次

## 02 每天必看的核心数，和会把你带偏的假指标

典型状态：你每天看的数据不少，成交额、访客数、浏览量都看。但真正决定生意的几个数反而没盯住，还常常被几个“看起来很热闹”的数字骗到，做出错误决策。

> **问**：一天只有十几分钟看数据，哪几个数是必须看的？

> **问**：哪些数是假指标，看了反而误导我？

**分步实操**

1．看访客数（UV）。这是所有生意的分母。访客数不涨，后面所有的优化都是空谈。

2．看支付转化率。路径：数据中心→实时看板或商品数据。支付转化率＝支付买家数÷访客数。访客涨了转化跌，说明来的人不对或页面没接住。

3．看客单价。客单价＝支付金额÷支付买家数。访客和转化都稳住，成交额还掉，一定是客单价掉了，通常来自低价SKU占比上升或凑单失效。

4．看支付件数。件数比金额更真实，能看出一单买几件。件数涨、金额跌，说明你在卖低价组合。

5．看退款率。退款率直接吃掉利润也直接影响体验分。参考警戒线：退款率长期高于20%就要当红灯处理。

6．看推广投产比（付费店必看）。每个计划单独看，不看整体的平均数。整体平均数会被一两个高投产计划拉好看，掩盖亏损计划。

7．看搜索流量的权重曲线。路径：数据中心→流量数据→搜索流量，蓝线高于黄线说明权重健康，曲线贴在最下面说明几乎拿不到搜索流量。

8．把这八个数按“昨天、上周同期、30天均值”三列填进日盯表，只花五分钟。

9．警惕累计成交额。累计值是把前期的高峰一起算进去的，单日已经掉了一半它也未必难看。要看单日、看环比。

10．警惕单独的浏览量（PV）。浏览量涨、访客数没涨，通常只是同一批人多翻了几个页面，不代表来了新客。

11．警惕没有来源的“访客上涨”。访客涨了但支付转化率同步大跌，多半是付费低质流量或活动泛流量冲进来的，这种涨是花钱买的虚胖。

12．警惕曝光量的绝对值。曝光少不一定是权重差，可能是出价低；曝光多但点击率跌，系统反而会判定你的商品不值钱，下一轮缩量。

13．警惕自己被“收藏加购数”安慰。收藏加购只是意向，不等于成交。收藏加购高、支付转化率低，是典型的“想要但没下决心”，属于可救的信号，不是已经赢了。

14．警惕只看整体投产比。整体投产比好看，可能是你在用盈利计划补贴亏损计划。判断标准永远是逐计划、逐关键词看。

15．警惕把系统推荐出价、行业均值当成目标值。这些是参考线不是达标线，你的目标值只能从自己的成本和利润率倒推。

**正确做法**

- 每天固定看这八个数，其余数据每周看一次就够。看多了会分散注意力。

- 判断“好坏”必须有一个自己的基准，基准来源优先级：自己近30天均值→自己上月同期→行业对比数据。三者都没有时，用本模块后面给的通用参考线。

- 任何单一指标异动，都先加两个指标一起看再下结论：转化率异动配点击率，客单价异动配支付件数，访客数异动配流量结构。

- 指标参考线会随类目与季节变化，以后台实时提示为准，不要把一个数字当成全年铁律。

**常见错误**

错误示范：只看成交额，认为成交额没掉就是没问题。

错在哪：成交额是乘出来的结果。分子分母任何一项在恶化，只要另一项在改善，结果都可能暂时好看。三个月后权重掉光，你才发现已经晚了。

错误示范：把点击率高但转化率低当成“流量问题”，去加预算买更多流量。

错在哪：这是承接问题，加流量只会放大亏损。点击率解决“人进不进来”，转化率解决“人买不买”，两件事的药完全不同。

**实操检查清单**

- [ ] 在日盯表里固定这八个数，每天填两次

- [ ] 把30天均值一并算出，作为自己的判断基准

- [ ] 把推广报表按计划拆开，列出每个计划的投产比

- [ ] 打开搜索流量曲线，判断蓝线相对黄线的位置

- [ ] 删掉日盯表里所有不能指导动作的字段

- [ ] 每周更新一次基准值，避免用过期的尺子量今天

## 03 核心等式：流量乘转化率乘客单价，下滑一定出在其中一项

典型状态：看到成交额下滑，你第一反应是“流量不行了”，然后开始加推广费。加了两周，成交额没起来，推广费倒是花掉不少。

> **问**：成交额掉了，到底怎么第一时间判断是哪一项出了问题？

**分步实操**

1．记住等式：成交额＝访客数×支付转化率×客单价。这三项里任何一项下滑，成交额都会掉，且只有这三项。

2．把昨日数据与上周同期写成三列：访客数、支付转化率、客单价、成交金额。用除法逐个算出变动幅度。

3．算例：上周同期访客1200人、支付转化率3.5%、客单价42元，成交额＝1200×3.5%×42＝1764元。昨天访客1100人、转化率3.2%、客单价40元，成交额＝1100×3.2%×40＝1408元，掉了20.2%。

4．继续拆：访客数下降8.3%，转化率下降8.6%，客单价下降4.8%。三项都在跌，说明不是单一环节的问题，优先处理权重更高的那个——这里先查流量来源。

5．如果只有一项跌，路径就清晰了：访客数跌去查流量来源与限流；转化率跌去查主图点击率、详情、评价、价格；客单价跌去查SKU结构、券、凑单。

6．变量过多时用“固定一项”的办法：把客单价按上周同期代入重算，看成交额能不能回到正常，能回到说明主因是客单价，回到一半说明流量也是主因。

7．把这次拆解写进日盯表备注栏，一句话：“成交额-20.2%，主因流量-8.3%与转化-8.6%”。

**正确做法**

- 先算后猜。任何“我觉得是流量问题”的判断，都必须用三列数据验证过才能动手。

- 拆解顺序固定为：先算三项变动幅度，再按幅度大小排序，先动最大的一项。

- 三项同时跌，先查外因（限流、违规、竞品大促、行业大盘下滑），再查内因。外因导致的三项同跌，内因优化救不回来。

- 判断行业因素：打开行业大盘，看类目整体访客与成交趋势。行业整体在跌，你的跌幅只要小于行业，就是相对健康。

**常见错误**

错误示范：成交额一掉就加推广预算。

错在哪：如果转化率或客单价掉了，加流量只是把同样的问题放大。先拆解，再决定钱花在哪里。

错误示范：只对比昨天和前天两个数就下结论。

错在哪：单日波动受时段、天气、活动节奏影响极大。至少用周同期对比，大促期间要用同一个活动阶段对比。

错误示范：把客单价下跌当成小事，认为“薄利多销也是赚”。

错在哪：客单价下跌往往伴随低价SKU占比上升，退货率与运费占比同步上升，实际是利润被吃掉而成交额好看。

**实操检查清单**

- [ ] 在日盯表里加三列：访客数、支付转化率、客单价

- [ ] 每天算一次三项变动幅度并排序

- [ ] 遇到三项同跌，先打开行业大盘核对是不是行业性下滑

- [ ] 把“固定一项重算”的方法存成表格公式，一键套用

- [ ] 每次拆解后写一句话结论存档

- [ ] 禁止在没有写明主因前动用推广预算

## 04 数据掉了，怎么从整体拆到局部，一步步锁到具体环节

典型状态：你知道数据掉了，也知道要拆，但拆到一半就乱了：一会儿怀疑主图，一会儿怀疑价格，一会儿怀疑客服，最后哪个都没改到位。

> **问**：有没有一条固定的链条，让我从店铺整体一路查到具体哪一款、哪个环节？

> **问**：拆到最后一层，怎么保证我改的是真原因，不是瞎改？

**分步实操**

1．第一层，全店口径：把成交额拆成访客数、支付转化率、客单价三项，算出每项变动幅度。

2．第二层，分流量来源：进数据中心→流量数据，把访客拆成推荐、搜索、活动、付费四块，看是哪一块掉的。整体全掉指向权重或限流；单块掉指向那块的规则或投放问题。

3．第三层，分商品：进数据中心→商品数据，按访客数降序排列，看TOP5款里哪几款掉了。爆款掉一个百分点，比尾部款掉百分之十更伤。

4．第四层，分环节：对掉的那一款，把它的展现、点击率、支付转化率、退款率四个数排成一行。这一步决定药方——点击率低改主图，转化率低改详情与价格，退款率高改货与描述。

5．第五层，分人群：进流量数据→访客人群画像，对比访客人群与支付人群的年龄、性别、地域分布。两者错位说明推给了不对的人。

6．第六层，分时间：把掉的那一天切成时段看。如果只是晚上20点到23点的访客掉了，可能是竞品在做直播或秒杀；如果全天均匀掉，才指向权重。

7．排查外因：同时打开商品体检、违规记录、体验分排名、价格力诊断四个页面，每个页面看一眼颜色和提示。

8．把上述六层写成一张诊断单，最后一栏写“结论与动作”。查完不留单，下次还要重查一遍。

9．每层只允许提一个假设，且假设必须能被数据证伪。例如“主图差导致点击率低”，验证方式就是换图后看点击率是否上升。

10．用最小成本验证：改一个变量，观察三天。三天内目标指标没动，换下一个假设。

11．建立对照：改主图的同时不动价格、不动详情，否则无法知道是哪一项起了作用。

12．排除同时段的其他干扰，重要测试不要放在大促、活动期、上新期重叠的日子。

13．记录每次验证的结果，成功与失败的都记。失败的记录能帮你下次跳过无效动作。

**正确做法**

- 拆解顺序永远是“从大到小、从外到内”：全店→流量来源→商品→环节→人群→时段→外因。

- 每一层都要落一个数字，不能停在“感觉”。没有数字的判断不进诊断单。

- 定位结论必须与动作一一对应：一个原因只开一个药方，一次只改一个变量。

- 诊断单第二天要复查效果，形成闭环。只诊断不复查，等于没诊断。

**常见错误**

错误示范：一口咬定“就是主图问题”，直接连换三张主图。

错在哪：三个变量同时改，点击率上去了也不知道是哪张图起作用，降下来了也不知道是哪张图拖的后腿。一次只动一个变量。

错误示范：跳过商品层，直接从全店数据跳到优化动作。

错在哪：全店数据是加权平均，可能掩盖某款爆款的严重下滑。不做商品分层，等于放弃最高优先级的病灶。

**实操检查清单**

- [ ] 打印或新建一张六层诊断单模板

- [ ] 每次异常按六层顺序走完，不在中间跳层

- [ ] 每一层至少填一个数字，不填“感觉”

- [ ] 定位到环节后，把动作写进动作栏并标注验证时间

- [ ] 三天后复查同一指标，把结果填回诊断单

- [ ] 诊断单按月归档，形成自己的案例库

## 05 访客数、商品访客、浏览量、支付转化率、支付件数、客单价分别怎么读

典型状态：后台把一堆指标堆在一起，你分不清“访客数”和“商品访客”、“浏览量”和“访客数”有什么区别，报数的时候张口就错，判断自然也就跟着错。

> **问**：这几个指标口径差在哪，为什么同一个数在两个页面不一样？

**分步实操**

1．访客数（店铺访客）：当天进店的不同人数，同一人多次进店只算一个。这是全店口径，看整体盘子。

2．商品访客：进到某一个具体商品页的不同人数。一个买家逛了你三款商品，你的店铺访客是1，三款商品的商品访客各加1。所以商品访客之和一定大于店铺访客。

3．浏览量（PV）：页面被打开的次数，同一人反复刷新会重复计入。浏览量看的是内容吸引力，访客数看的是拉新能力。

4．读法：访客数和浏览量同步涨，是真人新客进来了；浏览量涨、访客数不动，是老访客在反复对比，属于犹豫不决，考虑做催付和评价补强。

5．支付转化率：支付买家数÷访客数。注意分子是“买家数”不是“订单数”，一个人下两单只算一个买家。想看清一单买几件，要配合支付件数读。

6．支付件数：当天卖出的商品总件数。件数涨、买家数不涨，说明客单价结构在变，通常是组合装或多件优惠在起作用。

7．客单价：支付金额÷支付买家数。注意分母是买家数，不是订单数。同一份支付金额，用买家数做分母算出来的客单价，会比用订单数做分母略高。

8．四个数合起来读一个例子：访客1000人、浏览量2500、支付买家35人、支付件数50件、支付金额1400元。则支付转化率＝35÷1000＝3.5%，客单价＝1400÷35＝40元，人均浏览2.5页，人均买1.43件。

9．遇到两个页面数字不一致：先看页面右上角的统计口径说明和更新时间。数据延迟、剔除退款的时间点不同，都会造成差异。做纵向对比时，只跟同一页面、同一口径的历史数据比。

**正确做法**

- 报数、做表、做复盘时，先写明口径。写“支付转化率（支付买家数÷访客数）”，避免团队各算各的。

- 判断店铺健康先看访客数，判断承接能力看支付转化率，判断货盘结构看客单价与人均件数。

- 页面之间口径不一致时，不争论哪个对，只固定用其中一个页面做趋势，另一个页面只做参考。

- 人均浏览页数长期低于2页，说明你的关联推荐和详情引导没起作用，客单价很难提上去。

**常见错误**

错误示范：把“浏览量”当成“访客数”写进周报。

错在哪：浏览量天然大于访客数，用它算转化率会严重低估真实转化水平，导致你把一个正常链接误判为“转化差”，然后去乱改详情。

错误示范：用订单数做分母算客单价。

错在哪：一单多件时客单价被算低，你会得出“客单价太低，要提价”的错误结论，而真实问题是复购或者连带没做起来。

**实操检查清单**

- [ ] 在日盯表表头写明每个指标的计算口径

- [ ] 每天填访客数、浏览量、支付买家数、支付件数、支付金额五项原始值

- [ ] 转化率与客单价用公式自动算，不手工估算

- [ ] 找出你店铺人均浏览页数与人均件数两个数并记录

- [ ] 固定只在一张表里做纵向趋势，不跨页面拼接

- [ ] 每月核对一次页面口径说明有没有更新

## 06 坑产怎么算，它怎么决定你的赛马晋级

典型状态：你听别人说“要做坑产”“坑产不够报不上活动”，但不知道坑产具体指什么，也不知道自己的坑产是多少，更不知道怎么把它做上去。

> **问**：坑产到底是什么，公式怎么用？

> **问**：坑产和赛马机制是什么关系？

**分步实操**

1．记住公式：坑产＝访客数×支付转化率×客单价。它衡量的是“平台给你一个展位，你能产出多少成交额”。

2．换个说法：坑产就是单坑位产出，也就是这个位置在你手里一天能挣多少钱。平台把坑位当成稀缺资源，只给产得多的商品。

3．算例：访客数1000、支付转化率3%、客单价40元，坑产＝1000×3%×40＝1200元。你想把坑产提到1800元，有三条路：访客提到1500（+50%），或转化率提到4.5%（+50%），或客单价提到60元（+50%）。

4．三条路的成本完全不同。访客靠出价和权重买，转化率靠详情与价格换，客单价靠SKU结构和凑单改。优先选你当前最先能做动的那条。

5．记住杠杆关系：系统估算坑位价值时看的是“出价×点击率”。点击率是乘数，所以点击率提升1个百分点，往往比出价提高10%带来更多、更便宜的流量。

6．打开推广报表，按关键词看点击率排序，把点击率排在前20%的词单独建计划，给足预算。

7．理解底层：拼多多的流量是分层池子。新链接先进小池子做测试，系统给一小波曝光，看你跑出什么数据。

8．判定标准是相对值不是绝对值：系统比的是同坑位、同流量下，你和同类目同价格带竞品的效率。你跑赢，就进更大的池子拿更多曝光；跑输，就压在小池甚至不再给量。

9．所以坑产不是“我比昨天好就行”，而是“我比同价格带对手好”。每周至少做一次竞品对标，把对手的到手价、销量、评价数、主图卖点列成表。

10．冷启动期的核心任务只有一个：用尽一切合规手段，在第一波赛马里跑出达标的点击率和转化率，拿到晋级大流量池的门票。多数链接的生死，在赛马的前几天就决定了。

11．达标判断：点击率对齐类目头部水平，转化率不低于行业参考线，退款率不高于类目均值。任一项明显落后，池子就会缩。

12．不要用“先亏后赚”的思路硬拉坑产。亏本冲量带来的坑产如果靠的是低价，人群标签会被拉到低价人群，后面想提价非常困难。

13．每周记录一次坑产，并拆成三因子填进表格。只看坑产总数，你永远不知道该先修哪一项。

**正确做法**

- 把坑产当周度指标而不是日度指标。单日坑产波动大，周度趋势才有判断价值。

- 提坑产优先动转化率和客单价，这两项不花钱；访客数要花钱，放在最后。

- 提客单价用真实组合装、真实加量、真实赠品，靠的是规格差异，不是换文字换图躲比价。

- 每提一次坑产，同时盯退款率。靠过激低价冲上来的坑产，退款率会一起涨，最后把体验分也拖下去。

> **【规则提示·2026规则修正】** 原做法（用大额虚假订单或“拍大单”补足近期销售额，把坑产数字做上去）已属违规。依据：这属于虚假交易，平台会按虚假交易治理，轻则订单不计入，重则扣分限流。合规替代：靠多多进宝等真实CPS渠道带来真实订单做基础销量，靠真实组合装与真实让利提升客单价，用真实数据把坑产做上去。

**常见错误**

错误示范：只盯坑产总数，不拆三因子。

错在哪：坑产掉了，你可能去加预算补访客，但真实原因是转化率从3.5%掉到2.8%。加预算只会把亏损放大。

错误示范：用大幅降价把坑产冲上去。

错在哪：价格频繁大幅波动会扰乱人群标签，也会被判定为扰乱价格秩序；短期坑产上去，活动空间和利润空间一起被砍掉。

**实操检查清单**

- [ ] 在周报里加一行坑产，并拆成访客、转化率、客单价三因子

- [ ] 打开推广报表，按点击率给关键词排序

- [ ] 把点击率前20%的词单独建计划

- [ ] 每周更新一次竞品对标表

- [ ] 检查每款在售商品的规格是否有真实差异点

- [ ] 每提一次坑产，复查一次退款率

## 07 流量阶段性下滑，三板斧定位法

典型状态：流量不是一下掉光的，是这周掉一点、下周再掉一点，你没当回事，等到掉了一半才发现，已经不知道从哪里查起了。

> **问**：流量下滑了，我用什么顺序查最快？

**分步实操**

1．第一斧，砍规则侧。打开商家后台→商品管理→商品体检，看颜色：绿色是流量正常，红色是即将断流，深红是基本没有流量。再看违规记录里有没有待处理的处罚或预警。

2．第一斧的第二刀，砍体验分。进服务中心→服务数据→店铺领航员，看各项排名。综合排名高于行业30%才算拿到基础资格线，大型活动与优质资源位通常要求高于行业50%，低于行业30%会出现自然流量下降，低于行业10%可能直接断流。

3．第二斧，砍价格侧。进价格力诊断页面，逐SKU看全网对比结果，找出标红的SKU。同时检查优惠券有没有到期、限时折扣是否结束、报名中的活动有没有下线。

4．第二斧的第二刀，看比价。同类目同款对手的到手价是多少，逐个对一遍。到手价是否具备竞争力是流量的基本盘，价格力不足会直接断流，与报不报活动无关。

5．第三斧，砍承接侧。把掉量那款商品的点击率、支付转化率、退款率三个数拉出来，与自己的历史值比。点击率低是主图问题，转化率低是详情与价格问题，退款率高是货与描述问题。

6．三斧砍完还没有结论，才轮到查推广与竞品。看付费计划有没有跑不动、出价是不是明显低于对手；看竞品是不是在大促、上了新低价、做了直播秒杀。

7．三板斧的标准判断链条，直接照着走一遍：

（1）全店流量是否全渠道同跌？是，走第一斧。

（2）只有搜索掉、推荐没掉？走第二斧。

（3）只有推荐掉、搜索稳？走第三斧，重点看主图与视频。

（4）只有付费流量掉？查推广计划与出价，与产品或店铺权重无关。

（5）只有活动流量掉？查活动是否结束、是否被比价下架资源位。

8．把每次排查结果记在诊断单上，重复出现的原因要写进店铺的固定检查项。

**正确做法**

- 顺序固定为规则侧→价格侧→承接侧，不要跳步。规则侧是生死问题，价格侧是资格问题，承接侧是效率问题，先解决生死和资格。

- 每一斧都要留下证据：截图、数字、日期。没证据的判断不进入行动清单。

- 自然流量下滑时优先查规则、价格、体验分三项，这三项决定了系统愿不愿意给你曝光。

- 排查一天内完成，不要拖成一周。流量下滑是衰减过程，越早定位损失越小。

**常见错误**

错误示范：流量一掉先加推广预算，用付费流量填坑。

错在哪：付费只能补访客，补不回权重。如果根因是被比价或体验分下滑，付费流量会越来越贵，最后连投产比都保不住。

错误示范：只看全店总访客，不看渠道结构。

错在哪：全店总量可能因为推荐涨、搜索跌而看起来平稳，实际搜索权重已经在下滑，再拖两周推荐也会跟着缩。

**实操检查清单**

- [ ] 打开商品体检，记录当前颜色

- [ ] 打开领航员，记录各项排名与行业差值

- [ ] 打开价格力诊断，列出所有标红SKU

- [ ] 逐个核对对手到手价，更新对标表

- [ ] 拉出掉量商品的点击率、转化率、退款率三项历史对比

- [ ] 按五条判断链条走一遍，把结论写进诊断单

- [ ] 排查结束当天更新一次日盯表备注

## 08 断流了怎么急救，急救顺序错了越救越死

典型状态：早上打开后台，发现流量几乎归零，搜索访客从几百掉到几十。你心里一慌，先降价、再改主图、再调投产比，一通操作之后流量更低了。

> **问**：断流了，第一时间该做什么、不该做什么？

**分步实操**

1．第一步，先冻结所有动作。停止调价、停止改主图、停止改标题、停止调投产比、停止改SKU。断流状态下每改一次，系统都要重新评估一次，你等于在伤口上再划一刀。

2．第二步，确认是不是真断流。判断标准：核心链接访客降幅超过60%，且连续两天没有回升。只是降20%到30%属于正常波动，不要按断流处理。

3．第三步，查规则侧。商品体检颜色、违规记录、处罚通知，三项一次看完。有处罚先处理处罚，其余动作都排在后面。

4．第四步，查价格侧。价格力诊所有没有标红；券是不是到期了；报名中的活动是不是下线了；有没有被比价判定为价格异常。

5．第五步，查体验分。领航员的排名是不是跌破行业30%。跌破会出现搜索靠后，跌破行业10%可能直接断流。

6．第六步，查付费。付费计划是跑不动还是跑得动但没转化。跑不动是缺人（定向太窄或出价太低），跑得动没转化是流量质量或承接问题。

7．第七步，按类型开药方，不同类型药不同：

（1）违规导致的：先按通知整改或申诉，整改完成后不再动链接，等系统重新抓取数据。

（2）价格力导致的：用真实差异化拉开比价逻辑，比如加量、组合、赠品，而不是裸价对砍。

（3）体验分导致的：集中处理退款与纠纷，把品质退款率与纠纷退款率压下来。

（4）内功导致的：只改一个变量，改完观察三天。

8．第八步，急救动作配合做三件事：老客券刺激复购，精准人群推广加码主推款，产出真实场景短视频挂到链接上。三件事都不改价格，也不改主图。

9．第九步，设定观察窗口。改完不再动，连看三天同一指标的走势，第四天再决定下一步。

**正确做法**

- 断流急救的第一原则是不折腾。多数断流是系统重新评估的结果，频繁操作只会让评估结果更差。

- 每天调价不超过2次，每次只调0.1到0.2元。这个频率是安全区间。

- 断流期间不降价。突然大幅降价会被判定为恶意竞争，反而延长恢复时间。

- 恢复期的新流量要从老客和精准人群来，这两类人转化率高，能快速把链接的有效数据重新撑起来。

- 建立断流记录表：日期、降幅、查到的主因、做的动作、恢复天数。三次以上你会发现自己的店铺有固定的易断点。

**常见错误**

错误示范：断流第一反应是立刻降价三成冲量。

错在哪：平台会判定为扰乱价格秩序或恶意竞争，历史最低价被砸下去之后活动空间也没了，恢复期被拉长，得不偿失。

错误示范：一天之内改主图、改标题、改价格、调投产，把能改的都改一遍。

错在哪：变量全混在一起，就算流量回来了你也不知道是哪个动作起的作用，也没法沉淀成方法。下一次断流你还会慌。

> **【规则提示·2026规则修正】** 原做法（频繁调整价格与出价来“搏一把流量”）已属高风险操作。依据：价格是高压线，频繁改价会扰乱人群标签、触发降权、堵死活动空间。合规替代：价格阶梯提前规划，活动前一次定好；日常用真实券与真实让利做承接，不靠临场砍价救流量。

**实操检查清单**

- [ ] 断流当天先冻结所有改价改图动作

- [ ] 用降幅超过60%且连续两天未回升确认是否真断流

- [ ] 依次查体检颜色、违规记录、价格力、体验分、付费状态

- [ ] 按五类原因对号入座，只执行对应的那一类动作

- [ ] 配合老客券与精准人群推广，不碰价格与主图

- [ ] 设三天观察窗口，期内不做二次调整

- [ ] 把本次断流原因与恢复天数记入断流记录表

## 09 降权的表现与恢复动作

典型状态：流量没有全部消失，但怎么都起不来了：出价加到比对手高还是没曝光，报活动总被拒，搜索流量一直贴在最下面。你说不清这算不算降权，也不知道该等还是该动。

> **问**：怎么判断自己被降权了，而不是单纯的市场淡季？

> **问**：确认降权之后，按什么节奏恢复？

**分步实操**

1．比对大盘。打开行业大盘，看类目整体访客走势。行业平稳甚至上涨，只有你在跌，才是自身问题；行业整体在跌，你跟着跌属于正常。

2．看流量断崖特征。降权通常表现为短时间内流量跌去大半，且各渠道同跌，推荐和搜索一起缩。

3．看搜索权重曲线。路径：数据中心→流量数据→搜索流量，蓝线长期躺在黄线下方甚至贴底，说明搜索权重很低。

4．看商品体检颜色。绿色是正常，红色说明即将断流，深红说明基本没流量。颜色是最直观的降权信号。

5．看活动侧反馈。报名基础活动被拒，或报名通过却拿不到资源位曝光，通常指向资格线问题而不是素材问题。

6．看付费侧反馈。出价已经高于同类目成本，计划仍然跑不动，说明不是钱的问题，是权重问题。

7．综合判定：以上六项里有三项同时成立，按降权处理；只有一两项成立，按效率问题处理，先优化内功。

8．第1天，停止所有扰动动作，把违规与体检问题一次性处理干净。有处罚的按通知整改或走申诉通道，处理完不再动链接。

9．第1天同时启动老客回流。配置老客专享券，力度要能真正刺激复购。老客的转化率天然高于新客，是恢复期最优质的数据来源。

10．第1天到第3天，精准人群推广加码。聚焦高转化人群，盯紧两个指标：收藏加购率与支付转化率。这两项跑赢同类目，系统会重新给量。

11．第1天到第3天，每天产出2条真实场景短视频挂到链接上。视频能同时拉升停留时长与转化率，是低成本拉权重的动作。

12．第3天到第7天，做阶梯动作但不降价：先做限量折扣，间隔48小时再上满减，让价格动作有节奏，避免一次到位砸穿历史最低价。

13．第3天到第7天，做SKU真实增配。加独家赠品或升级组合规格，用真实差异换转化，而不是用低价换转化。

14．第7天做一次全面复查：体检颜色、领航员排名、搜索曲线、坑产三因子，四项对比恢复前的记录，判断是否在改善。

15．恢复期全程遵守一条：每天调价不超过2次，每次幅度0.1到0.2元，绝不做大幅降价。

16．恢复周期正常需要7天左右。三天没动静不要加大动作，先确认数据是不是在缓慢回升，缓慢回升就是有效。

**正确做法**

- 恢复期的核心是“喂好数据”，不是“求平台”。平台看的是你重新跑出来的点击率与转化率，不是你的申诉理由。

- 老客券、精准人群、真实短视频是三个见效最快的动作，都不需要改价格。

- 恢复期间不要上新链接分散资源，把预算和运营精力集中到被降权的主链接上。

- 建立恢复记录：每一次降权的日期、主因、动作、恢复天数。三次之后你能预判自己店铺的恢复曲线。

**常见错误**

错误示范：被降权后立刻大幅降价冲销量，想用数据把权重买回来。

错在哪：低价冲起来的量会被系统判定为低质人群流量，人群标签被拉偏，恢复期结束之后你还要再花一个月纠偏，代价更大。

错误示范：把降权当成“平台针对我”，转而去研究各种规避手段。

错在哪：降权的绝大多数原因是价格力不足、体验分下滑、数据表现差三项中的一项或多项，都是可以量化改善的。找规则漏洞的路径只会带来更大的处罚。

**实操检查清单**

- [ ] 用六项信号交叉验证是否真的降权

- [ ] 第1天完成违规整改与体检问题清理

- [ ] 配置老客专享券并推送

- [ ] 精准人群推广单独建计划，聚焦高转化人群

- [ ] 连续3天每天产出2条真实场景短视频

- [ ] 第3天到第7天按48小时间隔做阶梯动作，全程不降价

- [ ] 第7天做四项复查并记录

- [ ] 把本次降权全过程写入恢复记录表

## 10 退款率口径怎么算，去哪看真实退款原因

典型状态：你看到后台的退款数字，觉得比例不算高。但月底一算账，利润比预期少了一大截。你不知道退款率到底该用哪个公式算，也不知道买家到底为什么退。

> **问**：退款率有几种算法，我该盯哪一个？

> **问**：买家到底为什么退，去哪看真实原因？

**分步实操**

1．第一种算法，按笔数：退款笔数÷支付笔数。这个口径最贴近客服与售后的工作量。

2．第二种算法，按金额：退款金额÷支付金额。这个口径最贴近利润，因为退掉的可能恰好是高价订单。

3．第三种算法，按买家数：退款买家数÷支付买家数。这个口径最能反映体验问题，适合评估品质与描述准确度。

4．三个口径要一起看，只看一个都会被误导。金额口径高、笔数口径低，说明高价订单在退；笔数口径高、金额口径低，说明低价款在退。

5．分类型拆开：发货前退款（买家后悔或催发货）、仅退款（未收到货或不想要）、退货退款（收到货后退）。三类原因完全不同，混在一起看等于没看。

6．算例：某月支付金额60000元、支付笔数1500笔、支付买家1200人。退款金额9000元、退款笔数180笔、退款买家150人。则金额退款率＝9000÷60000＝15%，笔数退款率＝180÷1500＝12%，买家退款率＝150÷1200＝12.5%。

7．再看净额：真实成交金额＝60000－9000＝51000元。用净额算客单价和利润，才是真实的账。

8．提醒自己：不同页面的退款统计口径与剔除时间点可能不同，做趋势必须固定用一个页面的同一个口径，以后台实时提示为准。

9．路径一：商家后台→售后管理→退款/售后列表，逐单看“退款原因”标签，按原因分类汇总数量。

10．路径二：逐单点开“协商历史”看完整聊天记录。标签是买家勾选的，聊天才是真话。买家写“不喜欢”，聊天里往往说“颜色和图片差太多”。

11．路径三：服务中心→服务数据→店铺领航员，看品质退款率与纠纷退款率两项与行业的对比。

12．路径四：评价区与问大家。差评里提到的具体问题，往往就是退款原因的前置信号。

13．把原因归成四类：质量、描述不符、物流、服务。每类算占比，占比最高的那一类当月必须整改。

14．对应药方：质量类去查供应商批次与质检；描述不符类去改主图与详情，把真实尺寸、颜色、配件写清楚；物流类去查时效与包装；服务类去查响应时长与话术。

15．建立退款原因月度台账，把每个原因的笔数与占比列出来，连续两个月看趋势。整改有效的类目会明显下降。

16．对恶意退款、明显薅羊毛的订单留证据走申诉通道，发货环节保留称重与出库记录用于举证。

**正确做法**

- 退款率不是客服一个部门的事。降低退款率最有效的动作在选品和描述环节，不在售后环节。

- 描述与实物必须一致。图片过度美化、规格写得含糊，都是在给退款率加码。

- 售后响应越快，退款升级为纠纷的概率越低。争取协商解决，避免走到平台介入。

- 把退款率当作利润指标而不只是服务指标。退款率每上升1个百分点，等于白卖一批货。

**常见错误**

错误示范：只看退款笔数，不看退款金额。

错在哪：你可能会发现笔数没涨，但利润在偷偷变薄，因为退掉的是少量高价订单。金额口径才能暴露这个问题。

错误示范：只看买家勾选的退款原因标签，不看协商历史。

错在哪：标签是选项，不一定是真实原因。照着标签整改，等于照着错误答案改作业，退款率不会降。

**实操检查清单**

- [ ] 在月报里同时列金额、笔数、买家数三个退款率

- [ ] 把退款按发货前、仅退款、退货退款三类拆开

- [ ] 逐单读20条退款协商历史，记录真实原因

- [ ] 检查领航员里品质退款率与纠纷退款率的行业对比

- [ ] 建立退款原因月度台账，四类占比各记一行

- [ ] 对占比最高的那类原因定一个整改动作与完成时间

- [ ] 用净成交金额重算一次真实客单价与利润率

## 11 有加购不下单，怎么一步步诊断

典型状态：数据里收藏加购不少，支付转化率却很低。买家明明看上了，就是不付款。你加了收藏加购的权重指标，但不知道该从哪一步入手把他推下去。

> **问**：加购高、转化低，从哪几个方向查？

> **问**：具体怎么把加购变成付款？

话术模板：看到您把这款加进了购物车，是不是在犹豫尺码？您平时穿M的话这款建议选M，我们发的是48小时内，运费险也给您买了，不合适可以直接退。

**分步实操**

1．先确认加购率本身正常。加购率低于参考水平，说明问题在点击之后的页面吸引力，而不是在决策环节。

2．加购正常但不付款，按三类原因依次排查。第一类是价格对比：进商品页看买家看到的价格与对手价格的差距，含运费与券后的到手价。

3．第二类是信任不足：数一数评价总数与带图评价数量，读一读中差评。评价太少或差评集中在同一问题上，买家一定会犹豫。

4．第三类是决策摩擦：检查SKU数量与命名是否让人看不懂，规格是否写清楚，有没有尺寸不清、选项混乱、找不到客服入口的情况。

5．第四是运营侧未跟进：后台有没有收藏加购人群的触达工具，有没有配置催付与专属券。加购后24小时是转化黄金窗口，过了就基本流失。

6．打开后台的加购人群与未付款人群，做一次人群特征对比：他们的地域、年龄、消费价格带是什么。人群明显偏低，说明你的商品被推给了价格敏感人群。

7．逐单看10到20个未付款订单的聊天记录，找真实卡点。常见的卡点是问尺码没得到及时回复、运费算不清、发货时效不敢承诺。

8．按查到的卡点开单一药方，三天后复查加购转化率。

9．配置加购人群专属券，券的有效期设短，用时间压力推动下单。

10．客服主动触达未付款买家，话术要落到具体问题上，不要发模板。

11．补齐带图评价。把真实的买家秀和实拍图补上去，优先补在详情页前几屏能看到的位置。

12．把运费、发货时效、退货保障三个信息前置到主图或详情第一屏，消除决策摩擦。

13．检查SKU命名，把模糊的规格名换成能看懂的名称，删掉没人选的无效SKU，减少选择负担。

14．若人群明显跑偏，用精准长尾词建计划，把访客拉回到目标人群。

15．三天后看数据：加购转化率是否上升，若上升就固定这套动作；若没动，回到第三步继续找下一个卡点。

**正确做法**

- 加购不下单是好事，说明商品本身有吸引力。要修的是决策路径，不是商品。

- 优先修信息缺失与摩擦，其次修价格。价格问题改起来最贵，也最容易破坏人群标签。

- 客服响应速度是隐形杀手。响应慢三分钟，加购顾客大概率跑去比价了。

- 把加购转化率单独作为一项周度指标，长期跟踪。这一项改善的边际收益通常高于拉新。

**常见错误**

错误示范：看到加购高就认为商品没问题，直接加推广预算拉更多流量。

错在哪：加购转化率没修的链接，拉进来的新流量一样卡在同一个环节，等于花钱买更多流失。

错误示范：为了促转化直接大幅降价。

错在哪：加购人群本来就是价格敏感度较高的一批人，降价换来的订单会进一步拉低客单价与利润率，还砸低历史最低价，影响后续活动报价。

**实操检查清单**

- [ ] 计算加购转化率并与上周对比

- [ ] 逐个检查运费、发货时效、退货保障三处信息是否显眼

- [ ] 配置加购人群专属券，有效期不超过3天

- [ ] 客服对未付款买家做一轮主动触达

- [ ] 补充带图评价至少10条

- [ ] 清理SKU命名，删掉无人选择的选项

- [ ] 三天后复查加购转化率并记录结果

## 12 竞品监控怎么做，被同行截单了怎么抢回来

典型状态：你发现同一个关键词下，对手的链接排在你前面，价格比你低几块钱，销量还在涨。你的老客也在慢慢流失，但你说不清流失去了哪，也不知道该跟还是不该跟。

> **问**：怎么判断自己正在被同行截单？

> **问**：竞品该看哪些数据，用什么节奏看？

> **问**：确认被截单后，怎么把客人抢回来？

**分步实操**

1．信号一，搜索访客下降但行业大盘平稳。你的排名掉了，说明有人顶上了你的位置。

2．信号二，同一个核心词下，对手链接的到手价低于你5%以上，或者规格相同但赠品更多。

3．信号三，你的点击率没变但访客转化率下降，说明进来的流量被更高性价比的选项分流了。

4．信号四，老客复购周期内没有回来，同时对手在店铺里上了复购券或会员权益。

5．信号五，你的活动报名通过但拿不到曝光，因为同池里有更强力的对标商品。

6．判断链条：行业平稳加搜索访客降，加对手到手价更低，加你的转化率下滑，三条同时成立，基本可以确认被截单。

7．定位到具体对手：在核心词搜索结果里按销量排序，取前三名，逐个打开详情，把他们的到手价、销量、评价数、主图卖点、活动标抄下来。

8．建立竞品对标表，字段固定为：竞品链接、到手价、标价、券后价、近7天销量趋势、评价总数、差评数、活动标签、主图卖点、SKU结构。

9．价格维度：到手价是唯一有意义的比较口径。把标价、券、满减全部算进去，只看标价会得出错误结论。

10．活动维度：看对手商品卡上的活动标签，例如“秒杀”“百亿补贴”“限时折扣”。看标签出现与消失的时间，能反推对手的活动节奏与价格阶梯。

11．内容维度：看对手主图第一张讲什么卖点、详情第一屏放什么、有没有短视频。对手反复在改的位置，通常是他在测试的重点。

12．评价维度：进对手的评价区，按时间排序读最新20条，重点读差评。对手被抱怨的点，就是你可以拿来做真实差异化的点。

13．节奏：每周固定更新一次对标表，每次记录日期。只看一天的竞品数据没有意义，趋势才有。

14．看词维度：用情报工具看对手的成交词和引流词，找出他吃到而你没收到的词，补进自己的标题与推广计划。

15．记录对手的直播与秒杀时间段，避开正面硬碰，选择他不出力的时段做自己的推广放量。

16．第一优先做真实差异化，不做裸价对砍。加量、升级规格、组合套装、独家赠品，让系统认为你和对手不是同一件商品。

17．守利润款，打引流款。用低毛利的引流款去接价格战，利润款守住价格与人群。

18．服务侧发力：把发货时效、退货保障、客服响应做出口碑，用非价格能力留客。

19．老客侧发力：对老客定向发券，缩短复购周期。老客回流是抢回份额最便宜的方式。

20．内容侧发力：产出真实场景短视频与实拍图，把差异化点做成看得见的内容，而不是写在文字里。

21．结构侧发力：把低价款设置为限量、限购，避免低价款吃掉整个店铺的价格形象。

22．复盘侧：两周后看搜索访客有没有回升、竞品价格有没有松动。打价格战没有赢家，只要能守住自己的价格带与利润率，就算守住了。

**正确做法**

- 竞品监控的目的是找差异，不是抄。抄主图、抄详情属于侵权，多次违规会被罚款、扣分甚至封店。

- 参考竞品素材只用于学习与内部对标，对外使用必须用自有或已授权素材。

- 价格战的正确应对是差异化和供应链成本，不是跟着降价。你有成本优势才降价，没有成本优势就换规格。

- 把竞品对标表当成固定资产，团队共用一个版本，每周更新。

**常见错误**

错误示范：对手降价，你立刻跟着降。

错在哪：对手可能只是在大促期间临时让价，你跟着降会砸低自己的历史最低价，活动报价空间被压缩，恢复时人群标签也乱了。

错误示范：只盯销量和价格两个数，不看活动标签和评价内容。

错在哪：对手涨量的原因常常是活动和内容，不是价格。只看价格会让你永远在错误的方向上跟。

**实操检查清单**

- [ ] 建立竞品对标表并固定字段

- [ ] 用所在类目核心词取前三名竞品录入

- [ ] 逐个算清对手到手价，含券与满减

- [ ] 读对手最新20条评价，记录差评集中问题

- [ ] 每周固定时间更新一次对标表

- [ ] 为自家主推款写出至少一个真实差异化点

- [ ] 配置老客定向券，缩短复购周期

- [ ] 两周后复查搜索访客与到手价差距

## 13 人群标签跑偏了怎么诊断、怎么纠

典型状态：你的商品明明是中高价位，系统却一直推给对价格极度敏感的人。访客涨了，转化率跌了，客单价一路走低，推广投产比越来越难看。你改了主图和价格，情况没有好转。

> **问**：怎么确认是人群标签跑偏，而不是价格或主图的问题？

> **问**：标签跑偏了怎么纠回来？

**分步实操**

1．取两组画像做对比。路径：数据中心→流量数据→访客人群画像，看访客的年龄、性别、地域、消费层级分布；再打开成交人群画像，用同样维度看一遍。

2．判断标准：访客画像与成交画像明显错位，就是标签跑偏。例如访客集中在低价敏感人群，成交却集中在另一类人，说明系统推的人不对，成交靠的是少数自然找上门的人。

3．第二个信号，客单价趋势性下滑。不是某一天低，而是连续三周往下走，同时低价SKU占比上升。

4．第三个信号，推荐流量占比上升但支付转化率下降。推荐流量放大标签效应，人群不对，推荐给得越多，转化率掉得越快。

5．第四个信号，付费计划的投产比逐周下降，而点击单价没涨。同样的钱买到的人更不精准。

6．排除法：主图点击率没有下降、价格没有变化、退款率没有异常，三项都正常而转化率在跌，优先怀疑人群标签。

7．找跑偏的来源：近期是不是做过超低价活动、上过极低价的引流SKU、投过泛人群的大范围计划、或者频繁改过价格。这三类动作是标签跑偏最常见的原因。

8．第一步，停掉污染源。暂停泛人群投放计划，下掉或限量极低价SKU，暂停大范围折扣活动。

9．第二步，重建精准入口。用精准长尾词建推广计划，定向到目标人群的年龄与消费层级，出价给足，先把精准人群的点击率跑起来。

10．第三步，用老客回流校正。对历史真实成交的老客定向发券，老客的成交人群画像与你的目标人群一致，这批订单能帮系统重新认识你的商品。

11．第四步，把主图与价格带对齐目标人群。主图里的场景、价格数字、卖点表述都要符合目标人群的认知，图不对，系统还会按图的信号推人。

12．第五步，设置价格锚点。主推款价格不要随波逐流，保持稳定。频繁改价会把已经建好的人群标签重新打散。

13．第六步，用新客券与场景券做结构化让利，而不是全场降价。让不同人群看到不同的真实券后价，既保住了价格形象，又拿到了细分流量。

14．第七步，观察周期至少两到三周。人群标签是慢变量，改三天就下结论会做错决策。每周记录一次访客画像与成交画像的错位程度。

15．第八步，纠偏完成后固化规则：不轻易上超低价SKU，不投无定向的泛流量计划，不在半个月内反复调价。

**正确做法**

- 人群标签是连续买卖行为沉淀出来的，不是开关，只能靠持续的精准成交去养。

- 纠偏的优先级是：先停污染源，再补精准成交，最后才是改素材。

- 客单价是标签是否健康最直观的表盘。客单价稳住了，标签基本是稳的。

- 用真实券做结构化让利，不要用虚高标价再发券，那属于违规，也起不到纠偏作用。

**常见错误**

错误示范：为了快速起量，长期挂一个极低价的引流款在店里冲访客。

错在哪：低价款带来的人会污染整个店铺的人群标签，主推款的推荐流量会被推给价格敏感人群，转化率和客单价一起掉，最后连推广投产比都保不住。

错误示范：标签跑偏之后连续大幅调价，试图用价格匹配人群。

错在哪：频繁调价本身就会扰乱人群标签，还会被判扰乱价格秩序。价格要在上架期就想清楚，不要靠后期反复试。

**实操检查清单**

- [ ] 导出访客人群画像与成交人群画像做对比

- [ ] 记录近三周客单价走势，判断是不是趋势性下滑

- [ ] 暂停泛人群投放计划

- [ ] 对极低价SKU做限量或下架处理

- [ ] 建精准长尾词计划，定向目标人群

- [ ] 对老客发定向券做回流

- [ ] 检查主图场景与目标人群是否匹配

- [ ] 连续三周每周更新一次画像错位幅度

## 14 缺拉新还是缺收割，怎么判断

典型状态：你感觉生意到了瓶颈，但说不清是拉不来新客，还是老客没留住。于是两头都投钱：一边加推广费，一边发券拉复购。月底一算，两头都没效果。

> **问**：怎么判断我缺的是拉新还是收割？

> **问**：拉新和收割分别怎么做才有效？

**分步实操**

1．先看结构。路径：数据中心→交易数据，找到新客数与老客数两项，算出新客占比与老客占比。

2．拆成交额：成交额＝新客数×新客客单价+老客数×老客客单价。四项分别与上周同期对比，看是哪个加数在缩。

3．判断缺拉新：新客数连续三周下降，而老客复购率稳定。这说明你的入口在收窄，需要加大拉新动作。

4．判断缺收割：新客数稳定甚至增长，但老客数占比长期低于两成，复购券、会员、老客触达基本没做。这是典型的收割缺失。

5．判断两头都缺：新客数与老客数同时下降。优先补老客，因为老客的获客成本低、转化率高，见效比拉新快。

6．算一笔账：假设新客获客成本12元、老客复购的触达成本2元。同样花1200元，拉新拿100个新客，按转化率10%算带来10单；老客触达能覆盖600人，按复购率15%算带来90单。这就是为什么老客优先。

7．再看老客的复购周期。日用快消的复购周期通常更短，需要更频繁的触达；耐用品周期长，重点是把老客沉淀到私域或会员体系里。

8．定结论：缺拉新就用推广、活动、内容三条路补入口；缺收割就用复购券、会员权益、老客定向触达补成交。

9．拉新三条路：付费投放（选对计划类型与人群）、活动流量（报匹配的活动拿标签流量）、内容流量（短视频与直播带来的推荐流量）。

10．拉新不看单量看质量：看新客的30天复购率、退款率、客单价。拉来一批只买最便宜款的低质新客，比不拉更伤店铺标签。

11．收割三个动作：老客定向优惠券、复购提醒触达、会员权益与新品优先购。

12．复购券设置要有梯度：老客专属券的力度要明显高于新客券，否则老客没有动力。

13．触达节奏按复购周期来：快消品在预估复购周期前3到5天触达，耐用品在节假日与换新场景触达。

14．收割效果的判断指标是复购率与老客客单价，不是总成交额。总成交额会被拉新掩盖。

15．建一张老客分层表：按最近一次购买时间分成活跃、沉睡、流失三层，对不同层用不同的券与话术。

**正确做法**

- 拉新和收割是两个不同的漏斗，用不同的指标考核。拉新看新客数与新客获客成本，收割看复购率与老客客单价。

- 老客的运营成本远低于新客，任何时候发现老客占比低于两成，都先补收割。

- 复购率是店铺最重要的长期资产。复购高的类目，应该把更多精力放在老客经营上。

- 拉新的质量比数量重要。宁要100个会复购的新客，不要1000个只买一次低价款的访客。

**常见错误**

错误示范：把总成交额当成唯一目标，靠不断拉新掩盖复购为零的事实。

错在哪：没有复购的店铺每天都在从零开始，获客成本会随竞争上升，利润被慢慢吃掉。这是慢性失血。

错误示范：给所有人群发同一张券。

错在哪：新客看到老客价会觉得不值，老客看到新客券会觉得被区别对待。券要按人群分层，各看各的真实价。

**实操检查清单**

- [ ] 算出本周新客占比与老客占比

- [ ] 拆出四项：新客数、新客客单价、老客数、老客客单价

- [ ] 判定缺的是拉新还是收割

- [ ] 建老客分层表，分活跃、沉睡、流失三层

- [ ] 配置老客专属券，力度高于新客券

- [ ] 按复购周期设定触达时间点

- [ ] 每周跟踪复购率与老客客单价两项

## 15 周报月报怎么做，两周期对比找退步

典型状态：你知道要复盘，但每次复盘都是把后台数字抄一遍，看不出问题，也留不下结论。下周再复盘，还是抄一遍数字。

> **问**：周报要写什么，怎么用两周期对比找出退步？

> **问**：月报和复盘模板怎么定，怎么让团队用起来？

算例：到手价29.9元，产品成本8元，快递加包装4.5元，平台技术服务费按类目2.5%计0.75元，售后退款损耗按10%计3元，推广费按投产比4折算7.5元，人工分摊1元，合计24.75元，净利5.15元，净利率17.2%。

**分步实操**

1．周报固定七块内容：成交额与三因子拆解、流量结构、转化与客单价、退款与售后、推广投产比、TOP5商品表现、下周动作。

2．第一块，成交额拆解。列本周与上周的访客数、支付转化率、客单价，算出各自变动幅度，指出主因是哪一项。

3．第二块，流量结构。列出推荐、搜索、活动、付费四块的访客占比，与上周比。付费占比在涨而自然占比在跌，要标红。

4．第三块，转化与客单价。分商品列，找出转化率下降幅度最大的三款，逐款写可能原因。

5．第四块，退款与售后。列三个口径的退款率：金额、笔数、买家数，并排原因分类占比。

6．第五块，推广。逐计划列花费、成交金额、投产比，标出低于保本线的计划。保本投产比≈1÷毛利率。

7．第六块，TOP5商品。每款列访客、转化率、客单价、退款率、利润，给出保留、优化、加投、淘汰的判断。

8．第七块，下周动作。每条动作写清楚：做什么、谁来做、什么时候完成、怎么验证。

9．两周期对比的技巧：不只看上周，还要看“上月同期”和“上一个活动周期的同期”。三种对比各回答一个问题——上周是短期波动吗？月度是趋势吗？活动期是活动效果变差了吗？

10．找出退步项的固定规则：把本周与上周相差超过15%的指标全部标黄，逐个写一句原因。连续两周标黄的指标，进月报的整改清单。

11．月报固定六块：月度趋势、类目对比、利润核算、体验分与合规、结构性改进、下月重点。

12．月度趋势用曲线，不用表格。把成交额、访客数、转化率、客单价四条曲线并排放在一张图上，趋势一眼可见。

13．类目对比：把自己几项核心指标与行业大盘、与对标竞品放在一张表里，标出差距。差距就是下个月的机会点。

14．利润核算：按款算净利，公式为到手价减去产品成本、快递费、包装、平台技术服务费、退款损耗、推广费、人工分摊。负毛利的款当月就要处理。

15．体验分与合规：记录领航员各项排名的月度变化，记录违规与申诉处理情况。这两项决定你下个月能不能报活动。

16．结构性改进：只写三条，且必须是能改变结构的动作，例如换供应商、改SKU结构、调整主推款。不要写“继续优化”这类没有动作的句子。

17．下月重点：写三条，每条带数字目标与负责人。

18．复盘模板沉淀：把“异常处理单”做成固定表，字段为异常现象、发现时间、六层拆解结论、根因、动作、责任人、完成时间、验证结果。

19．复盘节奏固定：日盯核心数，周复盘问题，月定战略，每季度回头看一眼沉淀的模板库，把重复出现的问题升级成固定检查项。

20．让团队用起来的办法：看板共享同一份，口径统一写死在表头，周会只讨论两件事——哪里退步了，下周谁做什么。

**正确做法**

- 复盘的目的不是记录，是产生动作。一份没有动作项的周报等于没写。

- 所有数字必须带口径和对比基准。写“转化率下降”没有意义，要写“支付转化率从3.5%降到2.9%，低于30天均值”。

- 日、周、月三层节奏各有分工：日看异常，周找问题，月定方向。不要用日报的方式做月报。

- 归档要有痕迹。每周、每月各建一个文件夹，按日期命名，方便回看三个月前的判断是不是对的。

**常见错误**

错误示范：周报只抄数字，没有结论和动作。

错在哪：复盘变成记账，问题不会自己消失。下周你还会遇到同一个问题，还要重新查一遍。

错误示范：用单日数据做判断，今天跌了就把全部动作停掉。

错在哪：单日波动受时段与活动节奏影响很大，容易做出过度反应，白白浪费权重积累。

**实操检查清单**

- [ ] 按七块内容建好周报模板并固定字段

- [ ] 每周算一次与上周的变动幅度，超过15%的标黄

- [ ] 每月画一次四指标趋势曲线

- [ ] 每月按款核算一次净利，标出负毛利款

- [ ] 每月记录领航员排名变化与违规处理情况

- [ ] 建立异常处理单模板并投入使用

- [ ] 周会只讨论退步项与下周动作

- [ ] 每周每月按日期归档，保留可回看的历史

## 16 选品数据怎么用：找潜力款、判断市场大盘

典型状态：你上新靠感觉，觉得这款好看就上，上完发现没量；或者看到某个类目热就跟进去，进去之后发现全是低价大卖家，怎么冲都冲不动。

> **问**：怎么用数据判断一个类目值不值得进？

> **问**：具体怎么从数据里挑出潜力款？

算例：成本16元，类目技术服务费2.5%，推广占比15%，退款损耗8%，目标利润率18%。保本售价＝16÷（1－0.025－0.15－0.08－0.18）＝16÷0.565≈28.3元。若类目主流成交价是29.9元，空间就很薄，需要压成本或提客单。

**分步实操**

1．进数据中心→行业大盘，看类目的整体访客与成交走势。曲线在涨说明需求在增，在跌说明行业在退，逆势进去会很吃力。

2．看季节节奏。把去年同期的类目曲线调出来，判断这个类目是常青款还是季节款。季节款要卡在旺季前1到2个月进场准备。

3．看价格带分布。把类目的成交价格带排出来，找出成交集中在哪个区间。你的成本结构必须能落在这个区间里才有戏。

4．找空白价格带。如果成交集中在50元以下和200元以上，而100元到150元这一段几乎没有成交，说明这一段要么没需求，要么没供给，需要用小批量测试验证。

5．看头部集中度。在核心词搜索结果里按销量排序，看前10名占了多少销量。前10名吃掉绝大多数销量，说明是高度集中的红海，新店进去很难分到量。

6．看词的热度趋势。进行业热搜词或搜索下拉框，对比近30天与上一个30天，找热度上升的词。上升词对应的就是增量需求。

7．看类目流量池大小。头部链接的日销如果稳定在几百单以上，说明池子够大，有自然流量可以分。整个类目日销只有几十单，就属于小池子，自然流量很难做起来。

8．综合结论：需求在涨、价格带能落进去、头部集中度可接受、池子够大，四项满足才进。任一项明显不满足，先放着。

9．第一层筛选，看供需。用核心词在站内搜，看在售同款数量与头部销量。同款极多而头部销量集中，说明供给过剩。

10．第二层筛选，看竞品差评。进对标价格带前几名的评价区，读差评，把被反复吐槽的点列出来。差评集中在同一个问题上，那个问题就是你的机会。

11．第三层筛选，看价格空间。你的到手成本与类目主流成交价之间有没有空间。货架价不高于类目极致价的1.2倍才有操作空间。

12．第四层筛选，看利润。算清保本售价，公式为成本÷（1减去平台综合费率、推广占比、损耗率、目标利润率之和）。平台综合费率必须用自己类目的真实费率，常见区间是0.6%到5%，不要套一个想当然的数字。

13．第五层筛选，小批量测款。不压货，先上2到3款，每款给相同的预算和相同的测试周期。

14．测款判断标准：7天内看三个数——访客有没有进来、点击率是否达标、加购率是否高于店铺均值。三项都不达标就淘汰，不要恋战。

15．潜力款的四个特征：点击率不低于同类目水平、加购率高于店铺均值、退款率低于类目均值、算下来利润为正。四个都满足才加投。

16．测款期间不做过度的价格操作。用小额付费拉初始数据，让平台先抓取到你的商品数据，再决定要不要放量。

**正确做法**

- 选品是七分，运营是三分。一个错的款，再好的运营也很难救。

- 判断市场看趋势不看当期热度。当期热度高的类目往往已经挤满了人。

- 找机会的两个方向：需求在涨但供给不足的细分，以及主流产品的差评集中点。

- 所有测款都必须有对照，用相同的预算、相同的周期、相同的指标去比，凭感觉选款等于赌。

**常见错误**

错误示范：看到某个类目榜上有名就直接跟款，不做价格带与利润测算。

错在哪：跟进去才发现成本拼不过头部，只能靠亏损冲量，越冲越亏，最后库存和现金流都被套住。

错误示范：开发阶段只做一次小批量试产就大货铺开。

错在哪：测款数据没跑出来就压货，一旦不成，货压在仓库里，资金周转直接受影响。

**实操检查清单**

- [ ] 打开行业大盘，确认类目走势与季节节奏

- [ ] 排出类目成交价格带，标出空白带

- [ ] 拆解前10名竞品，算出头部集中度

- [ ] 用自己类目的真实费率算一次保本售价

- [ ] 挑2到3款做小批量测款，预算与周期保持一致

- [ ] 7天后用点击率、加购率、退款率、利润四项筛选

- [ ] 淘汰款及时下架，避免占用资源位

- [ ] 通过筛选的款再谈压货与放量

## 17 AB测试怎么做才有对照：测款、测图、测人群

典型状态：你改了主图，流量涨了，于是认为新图更好。但你可能忘了同一周还报了活动、还调了价。到底是谁起的作用，你根本分不清。

> **问**：什么算有效的对照测试，怎么设计？

> **问**：测图怎么做？

> **问**：测款和测人群怎么做？

**分步实操**

1．原则一，一次只改一个变量。改主图就不动价格、不动标题、不动详情、不动推广出价。

2．原则二，样本量要够。单组至少积累到200次点击或30个成交，样本太小，结论就是噪音。

3．原则三，测试周期不少于3天，覆盖工作日与周末。只测一天，可能刚好撞上竞品大促。

4．原则四，不要在大促期、上新期、活动期做测试，变量太多无法归因。

5．原则五，提前写下判断标准。例如“新主图点击率高于旧图0.5个百分点以上才算胜出”，先定标准再看数据，避免事后找理由。

6．记录测试表：测试目标、变量、开始时间、结束时间、样本量、结果、结论、是否采纳。

7．路径：进推广中心，用创意测试功能，同一个商品挂多张主图，让系统轮播并统计各自的点击率。

8．至少准备3张图，每张只突出一个卖点：一张讲价格与规格、一张讲使用场景、一张讲材质或工艺。

9．观察点击率，同时看转化率。有的图点击率高但引进来的人转化差，那类图不能留。

10．数据判断：多张图之间的点击率差异要足够明显才值得换图。差在零点几个百分点以内，属于噪音，不要来回折腾。

11．胜出的图替换到商品主图第一位。替换后一周内不再改，给系统足够时间重新抓取数据。

12．主图视频同样测：同一个商品准备两个版本的短视频，观察完播率与前3秒的跳出情况。

13．测款：同时上2到3条结构相同的链接，规格、价格带、详情框架一致，只有款不同。给相同的预算与周期，比较点击率、加购率、支付转化率、退款率四项。

14．测款的判断标准：加购率与支付转化率排在前面、退款率不低于平均水平的款，进入放量名单。

15．测人群：同一个商品建多个计划，每个计划只改定向条件，例如只改年龄层、只改消费层级、只改地域。

16．每个计划单独设预算上限，避免一个计划吃掉全部预算，导致其他计划样本不足。

17．比较各计划的点击率、转化率、成交成本。转化率与成交成本综合最优的人群，作为主投人群。

18．人群测试要注意人群重叠。多个计划定向高度重叠时，它们会互相争抢流量，结论不可用。建计划时把定向范围拉开。

19．测试完成后不要马上删掉输的计划，先降预算观察三天，确认稳定之后再做取舍。

**正确做法**

- 测试的本质是控制变量，不是为了多改几次。变量越少，结论越可信。

- 测试结果无论成败都要留档。失败记录能帮团队避开重复的无效动作。

- 每次测试结束后只采纳一个动作，不要一次把多个测试结果同时上线，否则又变成混合变量。

- 测试的环境要稳定：竞品没有大促、你的店铺没有活动冲突、预算没有中断。

**常见错误**

错误示范：换主图的同时调了价格、报了一个活动，然后说新主图效果好。

错在哪：三个变量同时变，结论无法归因。以后你还会重复这种“看起来有效”的错误动作。

错误示范：只测一天、样本只有几十次点击就下结论。

错在哪：数据量不足时的差异基本是随机波动，据此换图、换人群，会把本来跑得好的链接改坏。

**实操检查清单**

- [ ] 建一张测试记录表并固定字段

- [ ] 每次测试前写下判断标准

- [ ] 检查测试期间没有活动与大促重叠

- [ ] 单组样本累积到200次点击或30个成交再做判断

- [ ] 测图至少准备3张图，每张只讲一个卖点

- [ ] 测人群建3个以上定向差异明显的计划

- [ ] 测试结束后只上线一个胜出动作

- [ ] 把全部测试结果归档，含未采纳的方案

## 18 让AI辅助诊断店铺，要提供什么信息、怎么提问

典型状态：你把“我店铺流量掉了帮我看下”这句话丢给AI，得到的答案是一堆正确但没用的建议。于是你觉得AI诊断不靠谱，还是回去凭经验拍板。

> **问**：要让AI给出能落地的诊断，我需要准备哪几类信息？

> **问**：怎么提问，才能拿到有判断链条的答案？

**分步实操**

1．第一类，店铺与商品背景。类目、客单价区间、主推款数量、店铺当前分层等级、主要流量来源。这几项决定AI判断的基准线。

2．第二类，核心指标的两周期数据。访客数、支付转化率、客单价、支付件数、退款率、推广投产比，给出本周与上周两组值。

3．第三类，流量结构数据。推荐、搜索、活动、付费四块的访客占比与变动幅度。

4．第四类，分商品数据。TOP5商品的访客、转化率、退款率、利润，以及各自近两周的走势。

5．第五类，外因信息。同期有没有报活动、有没有调价、有没有上新、大促节奏是怎样的、行业大盘是涨是跌。

6．第六类，已经做过的动作。这周改了主图没有、调了出价没有、发券没有。不写清楚，AI会把你的动作当成噪音。

7．把六类信息整理成一段结构化文字，不用长篇描述，用“字段：数值”的格式，AI读取效率最高。

8．提问模板一，定位归因：这是我的两周期数据（附数据），请按成交额等于访客数乘支付转化率乘客单价拆解，告诉我主因是哪一项，并给出下一步要查的两个页面。

9．提问模板二，环节诊断：我的支付转化率从3.5%降到2.8%，点击率没变、退款率没变，请列出三个可能导致这个结果的环节，并说明每个环节我怎么用后台数据验证。

10．提问模板三，阈值判断：我的退款率是18%，类目均值是12%，请告诉我应该优先改哪一类原因，以及整改的先后顺序。

11．提问模板四，动作排序：我手上可以做的动作有改主图、调价、补评价、加投放预算、发老客券，请按投入产出比排序，并说明每个动作的观察周期。

12．提问模板五，写复盘：这是我本周的数据与上周对比（附数据），请按七块结构替我写一份周报草稿，动作项要带责任人和完成时间。

13．提问纪律：一次只问一个问题。一次问五件事，你会得到五段浅答案。

14．追问纪律：拿到第一轮答案后，对不确定的结论继续追问验证方式。例如问“你判断是人群标签跑偏，我该去哪个页面、看哪两个画像来确认”。

15．校验纪律：AI给的每一个阈值与规则，都要回到后台核对。页面口径会变，规则会更新，以后台实时提示为准。AI是加速器，不是判官。

**正确做法**

- 数据越具体，答案越有用。给出数字、给出对比、给出你已经排除的可能，AI才能跳到下一步，而不是从零讲一遍常识。

- 把AI当诊断助手而不是决策者。最终决定权在你手上，你要对库存、现金流和价格负责。

- 每次诊断后把结论整理成动作项，落到人、落到时间，再进复盘表。诊断不落地等于没做。

- 涉及平台规则的变化，以商家后台的官方公告与实时提示为准，不要只依赖单一来源。

**常见错误**

错误示范：不给数据，只描述感受，问“我店铺最近不行了怎么办”。

错在哪：没有数据的诊断只能输出通用清单，你拿到的都是你早就知道的常识，白花时间。

错误示范：直接把买家的姓名、电话、地址粘贴给外部工具做分析。

错在哪：买家个人信息受法律保护，泄露会被处罚。分析时只提供聚合后的统计数字，绝不上传个人身份信息。

**实操检查清单**

- [ ] 按六类信息建一份“诊断信息包”模板

- [ ] 每次提问前把两周期数据填进去

- [ ] 一次只提一个问题，问完再追问

- [ ] 对AI给出的每个阈值回后台核对一次

- [ ] 把诊断结论转成带责任人与完成时间的动作项

- [ ] 只上传聚合统计数字，不上传任何买家个人信息

- [ ] 每次诊断后把结论归档进诊断案例库
