# 界面交互验收
每个输入有label；icon-only操作有可访问名称；语义button而非可点div。focus-visible可见，键盘Tab顺序顺畅；弹窗原生dialog.showModal提供焦点约束、Escape关闭、关闭后回到触发按钮。表单错误关联输入、role=alert或aria-live；成功消息可见，不依赖颜色。空结果可清除筛选、错误可重试；权限不足不提供假的成功路径。
至少1180×760和390×844，亮/暗分别检查主内容、导航、工具栏、弹窗；读document滚动宽度判断意外溢出，表格局部滚动可以且应明确。文字不裁剪核心信息。长标题与空数据正常渲染。图片本地存在且loaded，字号和对比度按当前设计token；尊重prefers-reduced-motion，不持续晃动/闪烁。
真实浏览器点操作并观察DOM/页面结果；记录console error/warn和失败资源，截图必须来自实际页面。静态解析不会发现事件未绑定/布局溢出/焦点问题，不能替代这些步骤。
