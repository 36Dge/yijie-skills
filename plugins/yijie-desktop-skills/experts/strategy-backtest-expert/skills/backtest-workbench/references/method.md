# 交易与收益口径

顺序：上日信号→本日开盘按可成交和持有期决定成交/取消→本日收盘生成下一session信号→现金+持股×本日收盘计权益。SMA严格检测前后差由非正转正/非负转负，不把持续状态当新交叉。预热只计算均线。预算按当前开盘价格加滑点、比例费与最小费取可负担整lot；没有未来收盘参与数量计算。

买费=max(min_fee,买入额×买费率)，卖费同理，卖税=卖出额×卖税率；滑点体现在买卖成交价中，fees_and_tax不重复计入滑点。净PnL=卖出净收入−含买费的买入总成本；net_return=净PnL/该买入成本。现金逐笔勾稽，期末权益−初始现金=已实现净PnL+未平仓含买费浮动PnL。期末无强平，无虚构卖费或当日T+1卖出。

第一天收益以initial_cash为分母，最大回撤也包含初始现金；年化天数由用户明确annual_sessions给出，样本不足一年不展示年化与Sharpe。Sharpe为日收益减显式年化无风险率转换的日利率，再除样本标准差乘sqrt(annual_sessions)，零波动不可用。没有交易的胜率不可用，不能写0%胜率。

未模型化：撮合队列、成交量容量、市场具体费用上限、最小报价单位、复权/公司行为、现金利息、复杂组合或事件统计。当前成分回放过去的生存者偏差不能靠程序消除；universe_selection必须披露选择来源和时点。
