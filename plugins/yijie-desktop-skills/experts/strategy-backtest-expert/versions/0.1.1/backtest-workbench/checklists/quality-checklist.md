# 验收

- 来源、日期、单位和假设明确，合成数据标示。
- 关键金额、缺失项与零值独立复算。
- 真实程序退出成功、结果文件可读，receipt与实际字节一致。
- 另存更新不覆盖原输入/结果。
- HTML章节/筛选实际交互，文件系统应用打开。
- 账号不足的线上NOT RUN；不冒称高级能力或Native Artifact。

## 更新比较的确定性交付
用户要求更新时必须传 --previous-input <上一版/input.json>。程序以当前计算器重算两份输入，生成 previous-input.json、comparison.json、change-note.md 并纳入receipt；不可重写这些程序产物，不伪称旧计算器版本复现。比较须同标的、币种、区间和价格口径。
研究说明与最终回复直接引用生成的change-note.md，不重新手写差异表或心算；缺任一数值时差值也是N/A，不把null-null写成0。上版非正时相对变化不可用。策略与费用同时改变不把差异归因于某一因素；不能引入输入、输出或方法中不存在的字段/术语。其余派生数字必须另存实际执行的计算及结果，否则省略。
