# M04 图片、详情与视频素材

## M04-01 素材发布前检查

状态：incomplete；原稿：578–592、607–611、624–631、738–749、1951–1961。

输入：当前类目素材规范、商品真实照片/规格、可用授权说明与拟发布位置。

1. 先区分首图、辅图、SKU 规格图、详情图和视频封面；不同位置不要共用一套未经确认的限制。
2. 按用户提供的当前规范核对尺寸、比例、格式、大小、背景和文字区域；原稿缺规格矩阵，不补造固定尺寸表。
3. 将每张图片关联到真实商品或规格，检查颜色、数量、配件和包装是否造成误解。
4. 标记待补的素材来源、模特/品牌使用权、认证与效果依据；没有证据不能用图像处理制造背书。

输出：素材位置、用途、可验证事实、问题、待核规则五列。

待核实：当前类目规格、标识和 AI 内容要求；全球购限制不自动推广为全部京东店型。

## M04-02 主图和详情的测试计划

状态：reviewed-reference；原稿：593–623、651–660、721–727、1963–1976。

输入：流量来源、现有曝光/点击/成交、目标人群、可确认卖点和库存状态。

1. 先检查流量是否匹配目标用户；不因转化下降就同时改标题、价格、所有图片。
2. 选择一个假设，如“尺寸信息不清导致咨询多”，做只改变该表达的素材版本；保留原图与修改日期。
3. 在产品支持的正常测试方式下比较同一流量口径和观察窗口。样本过少、活动/价格同时变化时不要下因果结论。
4. 同时看点击与后续成交/退款；点击高但误解增多的图不算优胜。

输出：假设、单变量、版本差异、比较口径和停止/回退条件；不保证固定提升比例。

待核实：后台测图能力和适用限制；不把“某时段换图必不降权”作为事实。

## M04-06 商品视频与信息一致性

状态：conflicted；原稿：671–720、758–776、1546、1996–2030。

输入：视频用途、真实商品、素材来源、是否含生成内容、当前发布规范。

1. 检查视频里展示的型号、功能、配件和链接商品一致；把实际演示与示意效果明确区分。
2. 核对画面、声音、字幕是否清楚，价格/活动信息是否仍真实；去掉无依据的功效与承诺。
3. 原创、授权或生成素材分别标来源。原稿对 AI 生成与标注说法不同，未核实当前规则前不说一律允许/禁止。
4. 发布后按用户提供的观看、点击与成交数据比较内容，不靠搬运数量或无依据视频数量门槛判断效果。

输出：视频逐项核对表、待改镜头/字幕、待核实事项；只提供草稿，不上传发布。

待核实：AI 标注、视频时长、版权、关联商品和撤回能力。
