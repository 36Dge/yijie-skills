# M14 达人合作与 CPS

版本：0.1.3；来源：jd-kb-user-provided；政策核验：NOT RUN。

## M14-01 选品与达人匹配

状态：reviewed-reference；原稿：1695–1711、2281–2282。

输入：商品受众/用途、可证明卖点、库存/售后、用户提供的公开达人内容和合作方式。

1. 先看达人日常内容与商品目标用户是否匹配，区分适合演示、讲解、对比或使用体验的表达方式。
2. 评估真实供应链承接：样品、库存、交付、退换货与素材支持，而非只看粉丝数。
3. 记录合作形式、内容交付、使用权、佣金/服务费与披露要求的待确认项；不自动联系达人。
4. 同一商品与不同达人分别写测试假设和观察口径，不能用泛平台榜单替代京东适配证据。

输出：候选匹配表、合作前问题清单、淘汰理由和小范围验证条件。

待核实：达人/商家实际资格、合作披露、内容使用权与平台功能。

## M14-02 佣金与样品成本

状态：reviewed-reference；原稿：1712–1724、2284–2291。

输入：实际售价/收入、商品与履约成本、退货、佣金基数、样品/服务费、广告与结算条件。

1. 将按成交结算费用与固定费用分开；核对佣金是否按实付、是否扣退款、谁承担优惠。
2. 用用户的销量范围估算贡献，样品和服务费分摊到可能成交量；销量不明时给情景表，不保证某佣金必有量。
3. 合同中明确交付内容、验收、授权使用、结算与未履约处理；不以未经确认的历史 T+1 为付款依据。
4. 初次合作控制样品投入，由用户决定数量；回看真实交付和成交，再决定是否继续。

输出：费用变量、情景计算、合同待确认项与合作复盘表。

待核实：京东联盟/CPS 当前入口、归因、佣金和结算规则；原稿 verify_required 的项目仍未核验。

## M14-04 MCN 入驻资料不足时

状态：incomplete；原稿：1725–1726、1753–1754、2290–2291。

输入：拟申请主体、业务目标和当前官方申请说明；没有说明时不要求用户先提交敏感资质。

1. 明确告知原稿该节为残缺内容，不能据此还原 MCN 入驻条件、数量门槛、保证金或完整流程。
2. 可以先整理准备问题：主体资格、达人管理、佣金分配、内容权利、结算与退出，留待官方资料逐项回答。
3. 用户提供当前申请说明后，按“要求→已有材料→缺口→责任人”整理，不把联盟普通推广资格等同 MCN 资格。
4. 涉及站外投放或不同产品线，先核对业务名称与适用规则，不能从缩写猜协议。

输出：资料不足说明、可继续的准备清单、需要用户提供的最小官方页面信息。

待核实：全部具体准入与结算条款。本场景的价值是避免误填与盲目承诺，不伪造完整入驻教程。
