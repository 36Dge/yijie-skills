# M08 推广投放诊断

版本：0.1.3；来源：jd-kb-user-provided；政策核验：NOT RUN。

## M08-01 选择工具前先统一口径

状态：conflicted；原稿：1065–1094、1140–1150、1171–1181、1769。

输入：当前后台工具/计划名称、店型、主推 SKU、营销目标、可用数据和预算边界。

1. 以用户当前页面实际可选项为准整理工具名称、目标、定向、计费和归因方式；旧名称只标历史对应，不能声称仍可新建。
2. 将明确搜索需求、泛人群探索、已访问人群触达等不同目的分开；先确认是否适合商品和数据成熟度。
3. 广告结果按展示、点击、直接/间接成交和退款拆口径；归因收入不等同新增收入。
4. 缺利润或履约条件时先补 M01-03/M06-01，不给“新店直接照抄”的预算/出价。

输出：工具比较维度与需要用户补充的实际设置；不启动广告。

待核实：工具迁移/下线、投放范围、赔付与补贴规则；原稿历史入口和固定参数不作为当前事实。

## M08-03 关键词、人群与效率排查

状态：reviewed-reference；原稿：1095–1123、1152–1165、2134–2150。

输入：同一时间窗口的关键词/人群/地域/时段花费与转化，说明统计延迟。

1. 按“花费高低×有效转化高低”排序，优先检查高消耗无匹配需求项；不能只用点击量决定删除。
2. 查看搜索词与商品实际用途是否匹配，区分关键词相关性问题和页面无法承接问题。
3. 对有成交的词核算贡献与退款；对少量样本项保留观察，不从一次未成交推出永久无效。
4. 人群、地域、时段分别比较，避免同时调整导致无法归因；建议都带观察条件和回退标准。

输出：问题项、证据、建议动作、影响与复查窗口；出价由用户根据成本和平台能力确定。

待核实：DMP、人群权限和调价机制；原稿百分比、基础出价与关键词数量只是未核经验，不复制为默认参数。

## M08-05 手动与智能计划边界

状态：conflicted；原稿：1124–1139、1176、1760、1769、1805、2093、2123–2126。

输入：同一 SKU 当前计划清单、实际投放产品、后台冲突提示、计划创建时间与当前官方说明。

1. 原稿同时存在双层投放教程、同 SKU 二选一，以及升级后可与其他产品线同投的说法；先说明不能由这份资料裁定现行规则。
2. 把计划逐行列为 SKU、产品名称、目标、是否在投、预算、后台提示。分清“同 SKU”“全店中包含该 SKU”和不同产品线。
3. 请用户提供适用产品当前帮助条款或脱敏冲突提示，再按这些证据比较；没有材料时保留待核，不建议直接双开/关闭。
4. 即使技术允许并行，也需确认预算和归因重叠；不能将两个报告的归因成交相加当净增量。

输出：冲突说明、核实清单、各方案成本/可控性比较；不做后台开关操作。

待核实：同投限制、SKU 排除与归因口径。本包无“2026正解”式确定结论。
