# M02 开店入驻准备

版本：0.1.3；来源：jd-kb-user-provided；政策核验：NOT RUN。

## M02-01 选择店型与准备资料

状态：incomplete；原稿：169–180、214–239、328–338。

输入：主体类型、品牌关系、目标类目、供货/仓配能力、希望采用的平台合作模式。

1. 先区分自营供货与商家自运营目标，列出谁持库存、谁定价、谁履约和谁承担售后。
2. 按当前官方申请页逐项建立“要求材料/已有材料/有效期/缺口/责任人”表；原稿未提供完整十种店型表，不按模型记忆补齐硬性资格。
3. 对品牌关系画授权链：权利人→授权方→申请主体，核对名称、类目、地域、期限与转授权权限。
4. 对特殊类目单列许可、检测、标签和经营范围核对项；只标应核查的类别，不替代资质审核。

输出：候选店型比较与资料缺口表；不保证审核通过。

待核实：资格、资金、税务身份、保证金、申请通道和当前开放类目，须以适用店型当时的官方申请要求为准。

## M02-02 材料被退回后的定位

状态：reviewed-reference；原稿：181–204、256–274、1822–1829。

输入：脱敏退回原因、文件类型、当前申请页要求。不要索取完整身份证号或其他非必要信息。

1. 将退回原因分成可读性、主体不一致、有效期、授权链、检测范围与类目不匹配，逐条对应材料。
2. 检查扫描完整、文字清楚、文件页数正确，证件名称与申请主体一致；签章要求直接对照当前页面，不能概括为所有文件一律同种盖章。
3. 质检文件核对产品型号、检测项目、出具机构和日期；缺检测不能靠修改图片补足。
4. 准备更正说明：原问题、真实更正材料、仍需官方确认的问题，再由用户正常提交。

输出：退回项→证据→修改责任人→再次提交前检查，避免重复交同一材料。

待核实：各类材料的有效期限、检测项目及补件机会，不从原稿复制固定天数或成功率。

## M02-03 签约与开店成本核对

状态：conflicted；原稿：205–213、240–255、302–340、1834–1850。

输入：合作合同/报价中的脱敏费用与结算条款、预期销量范围、库存和周转能力。

1. 将押金、一次性服务费、交易扣费、广告预算、仓配/退货成本和可退金额分列；押金是资金占用，不等于绝对可全额退回。
2. 对自营供货逐项核对价格管理、促销跟价、毛保/返点、发票、账期、损耗和退换货责任。
3. 用正常销量、较低销量和较高退货三种用户自定假设查看现金流；合同没有写明的收费标为待确认。
4. 开店后按 M01-01 完成基础设置再上架，不以更换主体规避已有违规问题。

输出：合同问题清单和现金需求分项，不给法律或税务结论。

待核实：原稿对自营申请入口与费用存在差异；具体账期/费率/资格只能从适用合同和当前官方要求确认。
