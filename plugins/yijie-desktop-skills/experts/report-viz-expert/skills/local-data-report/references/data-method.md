# 数据口径与选图
记录是CSV表行或JSON对象数组。JSON数值建议用十进制字符串保留精度；null/空串是缺失，0是真零。原字段全部保留；单项数值绝对值≤10亿、最多6小数，汇总用十进制定点数。图坐标用数值，原表和统计记录保留真实数值。
配置dimension为非空且唯一的类别列；series为1–8个实际存在的指标列，共用明确unit。缺少某条记录的指标保留缺失，若整个指标列不存在则是配置错误，不能当全缺失。原始标签重复须显式确认如何聚合/建立唯一标签，脚本不默聚合。报价日期/月份等先由用户明确排序才画折线，普通类别画分组柱。
图表每30条一页，不丢余下记录；全量数据表不按TOP-N截掉原文。最多1000行，超过时先设计有清单的分报告，别静默裁剪。不同单位拆报告，不能混算。负数有效，柱图基线含0；null不连线。
摘要列已知值合计、已知/缺失数量、最小/最大；有缺失只能称小计。只有全缺失时sum=null，不能0。增长率基期为0或未知则不可计算；不得从描述性统计推因果/市场规模。没有足够证据就不强凑5–7条结论。
