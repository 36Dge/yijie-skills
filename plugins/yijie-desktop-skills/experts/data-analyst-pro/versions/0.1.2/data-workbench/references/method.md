# 统计与事实边界
所有统计针对清洗后保留行。数值valid才参与；missing与invalid分开计数。known_sum不是缺失值的估计；空组或全缺值sum=null，不是0；真实0正常参与。样本方差用n−1，n<2不可计算，n=1均值仍可计算。Type7分位数：排序后位置(n−1)p，线性插值。Decimal精度50，输出28有效数字；报告图表用浏览器Number展示，精确复算以JSON十进制值为准。
分组/趋势独立记录有效n/总n，不能将仅有效行合计写成全部业务收入；日期窗口外仅从趋势排除。描述分布不等于异常的业务原因，重复ID可能是多笔交易，需要语义确认。无假设检验、显著性、因果、A/B提升、训练预测或模型评估。本地工具的正确执行不提供这些证明。
结论每条带源文件/字段/行号或分析路径，并列覆盖率、样本限制、待确认口径。独立手算小样本合计、均值和去重行数，再对比复算包；不把脚本自己的回执当作独立验收。
