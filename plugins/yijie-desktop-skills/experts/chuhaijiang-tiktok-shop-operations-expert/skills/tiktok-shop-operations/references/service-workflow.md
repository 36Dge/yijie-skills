# 出海匠服务与授权流程
易界连接器中的出海匠使用固定官方HTTP MCP和OAuth；真实授权与业务可用性本轮尚未验收。2026-10-16公开元数据审计发现：资源声明的授权服务器地址带末尾斜杠，授权服务器issuer不带；现有严格匹配会拒绝。需服务方修正后另行验证，不能自行改地址或放宽校验。授权未成功时使用用户报表路径，不能声称已连接。公开授权元数据只声明mcp.full，不能称供应商只读授权。令牌由既有连接器安全存储处理，角色与模型不接收原始凭据。

用户先在易界连接器完成授权，完整工具发现与资格检查后明确启用，再从对话添加菜单选择出海匠。未选择/未资格化时不调用。资源已准备只表示本地专家文件就绪。实际工具可能经易界网关命名；按当前schema及说明识别服务/功能，不使用WorkBuddy专属mcp前缀、proxy_call或connect_cloud_service。

原包social_accounts/list、social_seller/daily_report、shops_overview、products/product_detail、social_analytics只用于辨识需求，不是可直接调用的已冻结协议。以本轮发现的真实工具/参数为准，未经schema确认不补字段。先只读账号列表确认数值ID与卖家身份；没有卖家账号时确认地区类型，再按实际schema请求授权入口。源包地区有cross-border/domestic/mx-local/local-jp/local-eu，但不能把这些静态枚举当供应商当前事实。可信店铺持有人自行完成授权，随后重新确认实际列表。

仅用户指定自有店铺与期间进入经营查询；达人/橱窗不能替代卖家。账号列表、查询及授权链接请求均走现有逐次审批，不因为工具宣称只读而跳过。返回数据范围、可用日期与币种要保留。

ready/成功且有实际数据才分析；generating记录原状态，不自动重复daily_report；超时或unknown保留原操作并使用产品已有原操作恢复，不新建请求猜成功。每次调用可能计费，追加请求/日期/店铺范围须用户明确。认证失败引导正常重新连接，资格/schema变更重新发现并由用户显式启用；不自动换endpoint、模型、账号或权限。

本组不执行发布、回复、私信、隐藏、删除、解绑、改价、库存写入、履约和广告操作。不承诺当前通用连接器支持所有原包外部动作；destructive工具仍受既有机器拒绝规则。没有用户明确平台写意图时只给草稿和建议。
