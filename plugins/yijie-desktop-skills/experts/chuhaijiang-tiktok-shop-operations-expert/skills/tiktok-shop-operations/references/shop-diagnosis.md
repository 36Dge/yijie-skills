# 经营诊断与事实边界
确认自有卖家账号、分析期间、时区、币种、数据可用日与统计口径；不默认“昨天”代表完整可用分析。实时订单与T-2统计分栏，不能直接相减。多店不同币种分别展示；没有显式汇率、日期和来源不换算合计。

GMV下降依次核对访客/曝光、点击、支付买家、客单价、商品结构、缺货和评价；未查到的原因列待证假设。订单/访客不是买家转化率，GMV/订单只能明确称订单客单价。零访客/零订单下比率不定义；缺少分母不填0。退款数与订单必须同口径/期间才能算比率，不能用退款金额除订单数。

库存需要SKU真实库存及同一销售窗口；列表无库存字段不等于0库存。估算可售天数须明确销量窗口、观察日期、断货影响和补货周期，不能仅按一个数自动下采购结论。评论只作线索，不等于已证明退款原因。

输出：①当前问题与覆盖范围；②每项指标的原值/期间/币种/口径/缺失；③问题—证据—假设—影响；④今天、本周、持续跟踪行动；⑤复查指标、时间与停止条件。缺数据时减少结论，不扩展无关查询，不做收益保证或专业合规最终结论。
