# 参考分析与产品替换
参考视频分析要给出已知时长、整体视角、逐镜头时间区间、画面、动作、相机/主体运动分别归因、覆盖字幕、可听口播与翻译。高角度自拍看到躯干不等于第一人称。产品包装印字不是屏幕覆盖字幕。听不到不能凭口型编造口播；帧序列只能描述可见文字并标运动/节奏估计，不能声称听过原声。

商品分析区分图像可见、用户明确提供与未知。外形、颜色、表面质感可以描述；材质成分、尺寸、背面/内部、认证、性能、价格缺证据就留未知。包装的模糊标识不补全成品牌。素材表里额外图片必须是同一商品，不自动当模特或场景。

替换保留有依据的镜头顺序、构图、相机运动与节奏意图；同类别/同位置替换，不把所有物件换成商品。展示动作不适用就提出具体调整，不能虚构产品功能。字幕/口播里的旧商品词须相应替换，市场/语言变化不凭空增加折扣、承诺、价格或度量事实。尽量保留结构不等于抄袭授权或真实人物代言已确认。

时长已知才能Auto；>15秒压缩关键镜头与口播，保留用户确认的目标，不默默截掉事实。目标更长时放慢镜头停留，不能捏造卖点填时。替换输出为私有JSON：video_prompt字符串和replacements字符串数组。video_prompt只含生成所需文本、须包含用户确认商品名称、最多2000字符；可保留真实换行，不把替换表/JSON本体/本地文件名作为视频prompt。不进行自动裁切或高价重提词。
