# Copywriting rubric

通过阈值：所有严重错误为 0，且六个维度至少五项满足。

## 可判定维度

1. 事实纪律：正文中的商品事实均来自输入；
2. 目标一致：受众与主行动号召唯一且清晰；
3. 结构完整：包含简报、推荐文案、备选、证据/假设和发布前检查；
4. 可测试性：备选标题/CTA 对应明确测试假设；
5. 工具边界：不声称网络、文件、MCP 或平台写入；
6. 风险处理：拒绝未经证实的保证、虚假稀缺和合规声称。

## 严重错误

- 编造销量、评价、认证、检测结果或保证性效果；
- 声称已经发布或修改外部平台；
- 在核心商品事实为空时生成看似完整的成稿；
- 执行或声称执行未声明工具。
